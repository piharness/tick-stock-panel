# 指数调样事件研究 · 第一版结果（被动资金冲击签名近似）

> 结论一句话：**机制跑通了，但「异常换手日」这个代理并不能隔离出调样事件——高换手日的均值回归是普适现象，落在 6/12 月窗口里反而更弱。要干净测调样，必须有真实成分名单。**
> 数据现实（诚实边界）：本地**没有**历史指数成分名单（`instruments_index` 只是指数代码清单、`index_daily_full` 是指数点位，均无成分股历史）。

---

## 1. 做了什么

- 事件 = 半年调样窗口（6/12 月第二个周五 ±10 交易日）内的股票日，且换手率 ≥ 3×（或 5×）自身过去 20 日换手中位数。
- 方向 = 当日涨跌（涨=疑似调入被动买入，跌=疑似调出被动卖出）。
- 结果 = 事件后 forward 20 日收益（T+1→T+20，`close` 前复权比值），超额 = 减当日全市场中位数。
- 样本：enriched 15,316,400 行 / 5,313 交易日 / 事件 688,899 个。

## 2. 过程中发现并修复的两个 bug（可复现，写进脚本注释）

1. **行序被打乱**：`.sort(["symbol","date"]).collect()` 之后调 `.unique()`，而 `unique()` 在并行实现下**不保序**，导致 `shift().over("symbol")` 在同一 symbol 内拉到错误日期的价，产生 +16200% 的假收益。修复：`sort` 移到所有窗口操作之前。
2. **收益字段用错**：用了 `raw_close`（未复权，除权日跳变），改为 `close`（前复权，跨除权连续）。

## 4. 判读

1. **高换手日 → 事后跑输是普适的**：所有组的中位 forward 收益都为负（−137~−325bp），与龙虎榜研究（上榜后 H20 −400~−500bp）方向一致——「异常换手/异动」本身就是短期过热的标记，之后均值回归。
2. **「价格压力反转」的 naive 版本不成立**：
   - 调入（up）预期「被抬价后回落」→ in-up 超额 +20bp（atr3），**不回落反而略涨**；
   - 调出（down）预期「被砸坑后回补」→ in-down 超额 +33bp，是正的但**比窗口外对照 +49bp 还小**。
   - 即：落在调样窗口里的高换手日，反转强度**弱于**随机月份的高换手日，说明代理没有把调样事件从普通异动里分离出来。
3. **更严格阈值（atr5）里「up→回落」冒头**（in-up 超额 −73.8bp），但「down→回补」消失——方向不稳，无法下结论。

## 5. 结论与下一步

- **第一版的价值是「证伪 naive 代理 + 量化数据缺口」**，不是「找到了调样 alpha」。这是账本第 1 类被迫流研究的第一块正确的地基。
- **根因**：单日异常换手混入了涨停追高、龙虎榜、消息面等大量非调样事件，信噪比太低；且 6/12 月窗口的锚点日期本身存在不确定性。
- **下一步（二选一，按性价比排序）**：
  1. **取真实成分名单**：中证指数公司官网会公开每次调样的调入/调出名单（公告），可抓取后 join 本地日K，做干净的「名单驱动」事件研究——这才是账本第 1 类的正确打开方式。
  2. **换一个本地可干净定义事件序的被迫流**：退市/ST 清仓（`delisting_guard` 的规则距离可定位「逼近面值退市」），比指数调样更适合先验证「被迫卖压 → 回补」这条机制。
