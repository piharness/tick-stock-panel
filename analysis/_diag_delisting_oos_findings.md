# 退市「浅跌破面值」信号样本外验证（闸门 2）

> 结论一句话：**「保壳」这笔交易，被 2020 退市新规杀死了。** 信号本身是真的（回撤深度→退市概率的单调关系跨时间稳定），但它是一个**风险信号**，不是**收益信号**——条件化后，60 日口径下浅跌端 EV 也是负的。第一版的 +970bp 是「20 日窗口 + 2020 前 regime」的产物，60 日重算后消失。

---

## 1. 三个子测试

1. **扩样本**：事件阈值 1.0 / 1.2 / 1.5 元（1.2/1.5 捕获更早的保壳阶段，浅跌事件更多）。
2. **时间样本外**：2020 退市新规前（<2020-01-01）vs 后。
3. **更保守**：60 日退市率（20 日会漏掉「先回补、之后才退市」的延后退市）。

## 3. 判读

1. **「回撤深度 → 退市概率」是稳定、单调、跨 regime 成立的真信号**：无论 pre/post2020、无论哪个阈值，深跌端退市率 71~93%、浅跌端 6~22%。这一半在样本外**活下来了**。
2. **但「浅跌 → 正 EV」没有活下来**：60 日口径下，浅跌端（−30~0%）post2020 的修正 EV 全部为负（−347 ~ −4,376bp）。第一版的 +970bp（peak60<1.5 元、20 日）是**双重假象**：20 日窗口漏掉了「先回补、第 40 天才退市」的延后退市 + 特定的 peak 切法。
3. **真正的故事是 regime 切换**：pre2020 中等回撤（−70~−30%）的桶是 **+1,500~+1,800bp 正 EV**（壳价值真实、保壳有效）；post2020 同样的桶变成 **−1,300~−4,200bp**。**2020 退市新规 + 2024 国九条把壳价值打没了，保壳从「稳赚」变成「送死」。**
4. 与外部证据互洽：川财证券陈雳「壳价值快速消退，炒作垃圾股、ST 股保壳博弈的旧模式风险显著加大」（2026-09）。

## 4. 结论

- **闸门 2：候选 edge 被证伪。** 「买浅跌破面值」不是正 EV 交易——信号是真的（能预测谁会退市），但它只值一个用途：**风控排除**（远离所有跌破面值的票，尤其是深跌端），不是买入理由。
- **这条被迫流（退市/ST 清仓）的最终结论**：moat 真（机构确实不能碰）、edge 负（即便条件化、即便浅跌、即便 60 日口径，post2020 无正 EV）。「约束集真空 ≠ 正期望」在这个案子里被**证成了定理**——真空 + 最优条件化，仍然负。
- **方法论沉淀（重要）**：这次样本外验证的价值在于——第一版 20 日 +970bp 的漂亮数字，在 60 日 + 时间切分后现出原形。**正 EV 候选必须过「更长持有期 + 跨 regime」两道，否则就是 regime 假象。** 这一条与记忆里「T+2 残差作废」「打板溢价 17 年无趋势」是同一个母题的第三次出现：**A 股的短线/困境反转类「alpha」，几乎都是制度窗口的投影，制度一改就归零。**
