## 0. 被复核对象的算术是对的

提交 `0aa0387` 在，三个产物齐全；报告里的 24,437 / 356 天 / 2025-11-13 全市场涨停 90 只 /
龙虎榜 recall 31.1% / precision 80% / 旧口径 r0ex +209bp 全部可复现。
问题不在算术，在三个前提。

## 1. 前提一：涨停档位用 `instruments.name` 判 ST（快照名 ≠ 历史名）

`instruments.parquet` 的 name 是**当前快照**，不是当日名称。ST 状态会变，而主板 ST 的涨停是 5%。
方向双向错：现名无 ST 但当时是 ST（按 10% 算 → 5% 涨停全漏）；现名 *ST 但当时不是（按 5% 算 →
10% 涨停全漏）。

把档位改成**价格自证**（用最高价落在哪个涨停价上认档，按板块约束候选集：
主板 {5%,10%}、创业/科创 {20%}、北交所 {30%}），且涨停价基准用 `prev_raw / ex_factor`：

| | 旧口径 | 价格口径 |
|---|---|---|
| 事件数（同窗口过滤） | 24,437 | 28,019 |
| 旧口径漏报 | — | **3,676 条 = 13.1%** |
| 旧口径误报 | 94 条 = 0.38% | — |

漏报的 3,676 条里，5% 档 2,176、10% 档 1,479 —— 即 **97% 是 ST 名称错配**。
只漏不误，所以旧事件集是"干净但有系统缺口"，缺口集中在 5% 板（小市值/ST/摘帽股）。

## 2. 前提二：朴素 t（日频自相关）

事件按日聚合成截面均值后，天数才是 n（这点原实现是对的）。但日频序列自相关明显，
朴素 t 高估约 26%：r0ex 40.5 → HAC(t, lag=5) 32.3。结论不受影响，报数应改口径。

## 3. 前提三（决定性）：R0 条件在「收盘封住」，而这是 15:00 才知道的事

R0 的总体是**收盘在涨停价**的股票。盘中挂涨停价买入的人，面对的是「触及涨停」的全集。
按板块约束重算，触及全集 n=45,682，其中：

| 子集 | n | 以涨停价为买价的隔夜收益 R0 | HAC t |
|---|---|---|---|
| 盘中有成交窗口·**收盘封住** | 26,022 | **+163bp** | +24.0 |
| 盘中有成交窗口·**炸板** | 17,663 | **−444bp** | −52.2 |
| 有成交窗口（混合＝机械规则） | 43,685 | **−83bp** | −12.9 |
| 触及但无窗口（一字板，买不到） | 1,997 | +667bp | +42.9 |

- **炸板占可成交触及 40.4%**；收盘封住的股票里只有 7.1% 是全天封死（其余 93% 盘中都有成交窗口）。
- 所以"买不到"不是主要矛盾（93% 有窗口），**"买到了但后来炸板"才是**：混合期望 −83bp。
- 机械规则下成交概率与收益**反向**：能成交的时刻正是卖压出现、要炸板的时刻。

结论：被复核报告"打板 R0 是稳的（+124/+202bp，t=24）"是**事后条件**的描述，不是可执行量。
放回盘中时点，同一规则期望为负。报告担心的"成交率不可测"方向对、机制错：
真正要预测的不是"能不能成交"，而是"**会不会回封**"。

## 4. 两个新发现（原报告没有的）

**涨停断点**：按 T 日涨幅分箱，主板（n_days=356，截面均值减全市场非涨停等权）

| T 日涨幅 | n | r0ex |
|---|---|---|
| 6~8% | 12,182 | −65bp |
| 8~9.5%（未封上） | 2,477 | **−91bp** |
| ≥9.5%（封住） | 25,136 | **+201bp** |

在涨停处有 **+292bp 的不连续跳变**，且曲线在 6% 以上单调走坏。所以：
(a) 打板不是"强度"的连续外推，"封住"是机制性的状态变量；
(b) 想用"买 8~9% 的强势股"替代打板，收益恰好是负的 —— 替代路径已证伪。

**连板高度单调**（r0ex）：首板 +172 → 2板 +294 → 3板 +351 → ≥4板 +405。
接力（r1ex）只在低位板为负：首板 −36(t=−4.9)、2板 −36、3板 +15(ns)、≥4板 +24(ns)。
按档位：5% 板 r1 **+21bp (t=1.56)**、10% 板 −41bp(t=−5.2)、20% 板 −11(ns)、30% 板 −370bp(n=137)。
即"接力一律为负"不成立，它是 10% 主板现象。

## 5. 由此得到的可证伪判据（替代"下一步测成交率"）

只做预测为"回封"的单子，盈亏平衡命中率：

p·163 − (1−p)·444 = 0 → **p = 73.2%**（20bp 成本 → 76.4%）

而基准回封率 = 26,022 / 43,685 = **59.6%**。所以 GP 线（封成比/封单量/开板次数）的
唯一正当任务是：**样本外把回封命中率从 59.6% 提到 73.2% 以上**（+13.6pp）。
达不到 → 这条线不能立项；达到 → 才有资格谈容量。

  到收盘的路径依赖。
