# 退市「跌破面值」的条件化：价格路径能否 ex-ante 区分幸存/退市

> 结论一句话：**价格路径能显著区分。** 无条件买跌是价值陷阱，但「浅跌破面值」（最近 60 日最高价 <1.5 元、回撤 <30%）的股票退市率仅 9.7%、修正后 20 日 EV **+970bp**；「深跌」（从 >3 元摔下来、回撤 >70%）退市率 78.5%、EV **−8308bp**。这是一个有经济机制（**面值保卫战 / 保壳**）的正 EV 候选，但样本小、且退市股覆盖完整性未独立核验，**是候选不是定论**。

---

## 1. 方法

- 事件：首次跌破 1 元（同上一版，268 只，生存偏差已修正）。
- 条件变量（全部 ex-ante，用事件日前数据）：
  - `ret_pre60`：跌破前 60 日累计跌幅（急跌 vs 阴跌）
  - `peak60`：跌破前 60 日最高价（从多高摔下来）
  - `dd_from_peak60`：跌破时距 60 日高点的回撤幅度
- 结果：20 日 forward 收益（修正口径：退市 = −100%）。

## 2. 结果（20 日 forward，bp）

| 条件 | 分桶 | n | 退市% | 修正均值 | 中位 |
|---|---|---|---|---|---|
| 从多高摔（peak60） | 1.0~1.5 元 | 31 | **9.7%** | **+970** | **+625** |
| | 1.5~2.0 元 | 81 | 27.2% | −3,278 | +204 |
| | 2.0~3.0 元 | 76 | 48.7% | −5,296 | +317 |
| | >3.0 元 | 79 | **78.5%** | **−8,308** | −105 |
| 回撤（dd_from_peak60） | −30~0% | 17 | 11.8% | +1,755 | −309 |
| | −100~−70% | 81 | 82.7% | −8,803 | −4,343 |
| 前 60 日跌幅（ret_pre60） | −30~0% | 35 | 14.3% | −1,341 | −619 |
| | −100~−70% | 69 | 84.1% | −8,834 | −2,584 |

## 3. 判读

1. **退市率对「跌得多深」单调**：从 1.0~1.5 元摔下来的，退市率 9.7%；从 >3 元摔下来的，78.5%。三种条件化给出同一个故事——**跌得越深，越接近死亡，退市率越高**。
2. **唯一的正 EV 端 = 浅跌破面值**：`peak60 < 1.5 元` 这一桶，修正均值 +970bp、中位 +625bp，且退市尾风险只有 9.7%。经济机制清晰：**面值保卫战 / 保壳**——股价逼近 1 元时，大股东增持、公司护盘、市场博弈「不退市」，把价格顶回 1 元上方（对所有人都是损失最小化）。这正是 A 股低价股里广为人知、但从未被生存偏差修正过 EV 的现象。
3. **深跌端是负 EV 的死亡螺旋**：从高位崩到 1 元下方，说明基本面已崩（不是「暂时错杀」），78% 退市，EV −83%。
4. **财务条件化不可行（硬约束）**：跌破 1 元的 268 只里只有 65 只有年报财务，其中 **48 只是幸存者**——财务数据（东财补全）与价格数据同源、同样只覆盖在市股。用它条件化会把生存偏差重新引入，故本版只用价格路径（全 268 只覆盖）。

## 4. 结论：候选 edge，不是定论

- **机制成立、方向单调、生存偏差已修正** → 这是一个**正 EV 候选**：「面值保卫战」。
- **但它距可交易还有三步验证**，缺一不可：
  1. **退市股覆盖完整性**：9.7% 的退市率建立在 `stock_gap_daily` 的 154 只退市股之上；若历史退市名单有遗漏，真实退市率更高、EV 会缩水。需对交易所/东财退市板块的**完整退市名单**核验。
  2. **样本量**：正 EV 端 n=31（回撤桶更小 n=17），需扩样本（1.2 元、1.5 元阈值合并，或更长历史）做样本外验证。
  3. **流动性与容量**：1 元股绝对价低、流动性差，「保壳」反弹由大股东增持 + 散户博弈驱动，容量受限——这对「归你」的 moat 是好事，但必须先测真实可成交规模与滑点。
- **方法论沉淀**：这条线完整走了一遍「无条件（−49%）→ 条件化（+970bp 候选）」，证明了 **「约束集真空 ≠ 正期望」这句话的下一句：真空 + 正确的条件化 = 可能翻正**。结构优势不是「买跌」，是「只买浅跌、避开深跌」——而这恰恰是只有能持有丑标的、能算清尾部的人（你）才做得出的区分。
