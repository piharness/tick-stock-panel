## 1. 口径（写死，不随结果调整）

| 量 | 定义 |
|---|---|
| 事件 | 收盘价 == 该板块涨停价（按 60/00/002 主板 10%、300/301/688/689 20%、43/83/87/88/920 30%，主板 ST 5%），价格四舍五入到分 |
| R0 打板 | `open(T+1)/close(T) - 1`，即 T 日以涨停价买入、T+1 开盘卖出。**假设能排到队，是乐观上界** |
| R1 接力 | `open(T+2)/open(T+1) - 1`，即 T+1 开盘买入、持有 1 个交易日 |
| R2 日内 | `close(T+1)/open(T+1) - 1` |
| 复权 | `kline_daily` 是未复权原始价，跨除权日乘 `adj_factor.ex_factor` |
| 超额 | 同日全市场非涨停等权同口径 |
| 成本 | 双边 15bp（假设值） |
| 可成交 | T+1 开盘价 < T+1 涨停价 |

## 2. 事件源诊断：龙虎榜不能当达板源

实测 2025-11-13：

- 全市场涨停（日线口径）**90 只**
- 龙虎榜 `all` 榜 70 行 / 唯一 **64** 只
- 龙虎榜中涨幅等于板块涨停幅的 **35** 只，与日线交集 **28** 只
- ⇒ **recall = 31.1%**，precision = 80%（35 只里 7 只日线判非涨停：000908/002691/002713/002868/600340/603813/920252）

结论：用龙虎榜当达板事件源会丢掉 69% 的样本，且丢的是系统性的那部分（未触发异动披露标准的涨停）。
**原方案「240 天龙虎榜」在事件集定义上就是错的，无论后面怎么算。**

## 4. 决定性交叉表：T 日封板形态 × T+1 可成交性

「全天封死」= 当日最低价即涨停价；「开过板」= 盘中有低于涨停价的成交。

| 格子 | n | 占比 | R0 超额 | R1 超额 | R1 单笔中位 |
|---|---|---|---|---|---|
| 全天封死 \| T+1 可买 | 715 | 2.9% | +372.1bp (t=17.7) | **-148.4bp (t=-3.5)** | -2.11% |

## 5. R0 的稳定性（打板自身）

- 7 个季度全为正：+241 / +248 / +231 / +199 / +183 / +167 / +197 bp，t 全部 > 9.5
- 4 个板块全为正：主板 +206 (t=42.9)、创业板 +236、科创 +271、北交 +142 (t=2.1)
- 有单调衰减：2025Q2 +241bp → 2026Q3 +167bp

## 6. 结论

1. **接力线可以关掉**：任何你能买到的情形，R1 都显著为负（-51 至 -148bp/日，t 在 -3.5 到 -6.0 之间）。
   涨跌停次日的溢价在**开盘那一刻就已经付完了**，接力者支付的是全部溢价。
2. **打板线不能关，但也不能开**：R0 稳定为正（+124 至 +209bp），可它依赖一个日线测不出的量——
   **T 日涨停价的成交概率**。而成交概率与封板强度负相关：封死组 R0 +977bp 却买不到，开过板组 +124bp 才买得到。
3. **所以 GP 线的命题要改写**。原命题「封成比高 → 收益高」是错的，方向反了：
   封成比高意味着**买不到**。正确的命题是「封成比 → 成交概率」，再在可成交约束下最大化条件收益。
   而 GP14/15/22/24 四个字段里**没有成交率**，回答不了这个问题。

## 7. 局限（都会让结果偏乐观）

- 数据是存活快照（5,581 只），退市股不在 → 亏损样本缺失
- 只有 367 个交易日（分区自 2025-05-07 起），单一市场环境；2026Q4 仅 20 天
- R0 的 +124bp 与「打板实盘难赚钱」的常识冲突，最可能的解释就是成交概率的逆向选择——而这正是未测项
- 15bp 成本是假设值，未含涨停价排队的隐性成本

## 8. 下一步（若继续）

唯一未验证且值钱的一环是 **封成比 → 实际成交率**。这需要实盘小单试买或委托队列数据，
不是再加一个 GP 字段能解决的问题。在此之前，任何基于 GP 封成比排序的回测都只是把
「买不到」的收益记进了账。
