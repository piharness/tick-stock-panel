# 外部方法论档案库（method dossiers）

> 目的：把"别人怎么做"从**叙事**降级成**可检验的主张**，再按证据等级供下游策略讨论引用。
> 这里不放结论，只放**判据、冲突位置和失效机制**。

## 为什么需要它

策略失效很少因为"方法写错了"，多因为三件事：收益来源被挤没了、容量吃不下、制度把可行集改了。
一个外部方法论如果不带这三项标注，读它只会得到**错误的精度**——一堆看起来可执行的阈值。

所以本库的产出不是"某人说了什么"，而是六元组：

```
主张 → 机理 → 隐含假设 → 证据等级(A/B/C) → 失效机制标签 → 本仓库判决或待测编号(T*)
```

## 证据等级

| 等级 | 含义 | 引用方式 |
| --- | --- | --- |
| **A** | 本仓库用自有数据独立复现：有脚本、有判据、有 N | 可直接当结论用，须带 `docs/` 路径 |
| **B** | 公开史料/公告/监管文件可核，但本仓库未复现 | "事实可信、机理未验" |
| **C** | 教学演示参数、行业口头共识、不可核叙事 | 只能当假设源，**禁止当参数** |

冲突时的优先关系：**A > B > C**，不按"谁更权威"。

## 失效机制标签（五选一或多选）

| 标签 | 一句话 | 可检测统计量 |
| --- | --- | --- |
| 拥挤 | 同一信号使用者增加，α ∝ 1/N | 分位数价差逐年斜率、信号间相关上升 |
| 容量 | AUM↑ ⇒ 冲击成本↑，且成本对 1/V 凸 | 换手×ADV、盈亏平衡成本线、成交率 |
| 制度 | 税率/T+1/涨跌停/券源/新规改变可行集 | 规则变更日事件研究（须带安慰剂） |
| 摩擦结构 | tick size、拆单算法改变微观信噪比 | 单笔金额分布、成交笔数、有效价差（需 L2） |
| 尾部约束 | 杠杆与止损同质化 ⇒ 波动率内生 | 跌停家数占比、融资余额、大小盘价差加速度 |

## 入库门禁：四问

任何外部方法论要进本库，必须先答完这四问；答不出就标 C，并写明"缺什么"。

1. **数据是否存在？** 我能构造出检验它的面板吗？（不能 ⇒ C，且注明缺哪一层：L2 / 产品净值 / 持仓）
2. **能否做匹配对照？** 能不能只让被检验的那一维变、其余特征按住不动？（不能 ⇒ 只能做相关性，不能做因果）
3. **容量多大？** 目标资金下，一个 bar 能吃多少 ADV 而不改变价格？（答不出 ⇒ 不许谈年化）
4. **失效机制可检测吗？** 它会在哪个统计量上先露头？（答不出 ⇒ 这是信仰，不是策略）

## 写作约定

- 一条主张一个编号（`C1…Cn`），编号在档案内**永不复用**；作废用 `~~C4~~ 作废：原因`。
- 引用只写 `[HF-2026/C7]`，不写"视频里说"。
- 任何"数字"必须带聚合口径、N、样本区间；不给这三项的数字一律视为修辞。
- 不写新回测结论进档案；回测结论进各自的 `docs/*.md`，档案只放指针。
