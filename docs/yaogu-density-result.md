# 月度妖股密度 regime：判决

> 2026-11-25。预注册 `docs/yaogu-density-prereg.md`（跑数前冻结）。
> 脚本 `analysis/_yaogu_density_regime3.py`（主）、`_yaogu_density_verdict.py`（判据+稳健性）。
>
> **判决：不成立。四条预注册判据只过一条。**
> 密度不是开关，是放大器——而且放大得不够。

## 1. 主结果

面板 214 个月（2009-02 ～ 2026-11，HOT 分位需要 36 个月历史）。
组合 = 上月末「过去 20 日平均换手」top 20% 等权，持有一个月，扣全市场等权。

| 上月 HOT 分位 | Q1（最冷） | Q2 | Q3 | Q4 | Q5（最热） | Q5−Q1 |
|---|---|---|---|---|---|---|
| 组合月度超额 | **−0.85%** | −0.71% | −0.37% | −1.17% | **−1.86%** | **−1.01%** |
| n | 43 | 43 | 42 | 43 | 43 | |

读法：**五个分位全为负。** 追高换手在任何密度环境下都跑输等权市场，
密度只是把亏损从 −0.85% 放大到 −1.86%。方向对，量级不够。

## 2. 四条判据

| # | 判据 | 实测 | 判决 |
|---|---|---|---|
| P1 | Q5−Q1 的 NW t ≤ −2.0 | **t = −1.47** | ✗ FAIL |
| P2 | block bootstrap 95% CI 全负 | **[−2.41%, +0.37%]**，含 0 | ✗ FAIL |
| P3 | 控过去市场收益后 b 的 t ≤ −1.5 | **−1.01 / −1.21** | ✗ FAIL |
| P4 | 安慰剂 p < 0.05 | **p = 0.004** | ✓ PASS |

**一处必须说清的张力**：连续斜率（`EX ~ HOT_q`）的 NW t = **−2.13**，看起来过线；
但预注册固定的是 Q5−Q1 的分组差，t = **−1.47**。两者不矛盾——斜率用了 214 个观测的秩序信息，
分组只用了两端 86 个。**按预注册判据，FAIL。** 如果事后改口说「其实斜率过了」，
就是拿功效差异当结论差异，这是本项目明令禁止的事。

更进一步：斜率在控制 `MKT_{m−1}` 与 `MKT_{m−3..m−1}` 后掉到 −0.73（t=−1.01）。
说明那点斜率信息里有一半是「过去市场涨得好 → 现在密度高 → 高换手继续涨」的动量残影。

唯一 t=−2.52 的 E 是含前视的全样本分位——这正是「看起来显著的那个版本恰好是不能用的那个」。

## 4. 三个错，都值钱

1. **v2 前视**：`heat` 取月末换手、`r` 取当月收益 ⇒ 用月末状态筛出「本月已经涨过」的股票。
   结果 +3.1%/月、17 年全正、t=+2.63，方向与预注册假设**相反**且「显著」。
   这是 §1 母题「同一真相两个定义点」的第 N 次复发：**状态与收益必须错开一期**。
2. **v1 合并**：把个股-月面板 merge 进月度面板 ⇒ 68 万行假样本，t 值算到 ±67。
   `merge` 前必须检查行数是否守恒。
3. **诊断脚本排序键**：`row_number() over (... order by close)` 当成「首日」，
   得出月度收益 +25% 的荒谬值。**窗口函数的 order by 必须与被定义的序一致**，
   这类错不会报错，只会给出看起来很厉害的数。

判据：任何月度/事件研究，跑完先问「这个 t 值对应的样本行数，等于我预期的月份数吗」。

## 5. 判据级结论

- **密度这个方向关闭。** 它不含可用的增量信息；把「高密度月份回避高热度股」当择时器，
  相比「无条件回避高热度股」没有统计学上站得住的改善。
- **真正的结论是无条件的**：上月末换手 top 20%，下月跑输等权 **−1.08%/月 ≈ −12.2%/年**，
  2009-2026 每一年都为负。这与 `footprint-20d-significance.md`（热度 top −20.4%/年）、
  `youzi-strategy-audit.md`（首板 −31bp/2日）、`early-entry-ignition.md`（+3% 追入 2 日期望 −0.56%）
  是同一件事的第四次独立验证。
- **密度仍可作描述性指标**（它确实标记了 2007-05 / 2015-06 这类位置），
  但描述性 ≠ 可交易。把它写进看板的「市场状态」栏可以，写进信号池不行。
