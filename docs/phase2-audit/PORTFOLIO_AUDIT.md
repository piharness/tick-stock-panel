# 组合审计 · 15 个滚动 cohort

**组合口径**：15 个滚动 cohort，每个占 **1/15 资金**；cohort 内等权买入当日全部可成交信号；d+1 开盘买、持有 15 个交易日、收盘卖；空仓日现金收益 0；双边成本 0.15%。
**基准口径**：**同一 15-cohort 结构、同一买入/卖出时点、同一等权规则**，但 cohort = 当日全部 `basic_ok` 股票（约 1,100 只）。这是唯一可比的口径——用"每日再平衡等权指数"当基准会算出 −48% 的假超额。
**样本**：2018-08-24 → 2026-11-02，2,057 个交易日（8.16 年）
**脚本**：`analysis/_audit_p2_portfolio.py`；净值 `data/.scratch/p2audit/portfolio_nav.csv`；月度 `portfolio_monthly.csv`

## 1. 总览

| 指标 | 策略 | 基准 |
|---|---|---|
| 累计收益 | **+96.8%** | +21.0% |
| 年化（CAGR） | **+8.65%** | **+2.36%** |
| 年化波动 | 20.34% | 22.02% |
| Sharpe（rf=0） | **0.510** | 0.217 |
| 最大回撤 | **−29.32%** | −42.14% |
| 超额 Sharpe（日超额） | **0.693** | — |
| 年化超额（算术，日差×252） | **+5.60%** | — |
| 累计相对收益 | **+62.6%** | — |
| Beta（对基准） | **0.859** | 1.000 |
| 相关系数 | 0.930 | — |
| CAPM alpha（年化） | **+6.27%** | — |
| 信息比率（IR） | **0.693** | — |
| 日胜率（超额 >0） | 49.4% | — |

**Sharpe 口径**：`日均收益 / 日收益标准差 × √252`，无风险利率取 0。若取 1.5% 无风险利率，绝对 Sharpe 降至约 0.44；超额 Sharpe 不受影响（rf 在分子里被抵消）。

> **beta 0.859 + corr 0.930**：这个组合不是"低相关 alpha"，而是**高 beta 的市场暴露 + 一层选股偏移**。8.65% 的绝对年化里，约 2.0pct 来自市场 beta，6.3pct 来自 alpha。

## 5. 暴露

### 行业（按持仓市值加权，日均）

90 个行业，HHI = **0.018**（相当于 55 个等权行业，极度分散）。

| 行业 | 权重 |
|---|---|
| 证券 | 5.10% |
| 汽车零部件 | 4.08% |
| 银行 | 3.78% |
| 电力 | 2.83% |
| 化学制药 | 2.81% |
| 军工装备 | 2.55% |
| 中药 | 2.37% |
| 化学制品 | 2.34% |

单一行业不超过 5.1%，不构成行业押注。但**证券 + 银行合计 8.9%**，在金融行情里会放大 beta。

> **PIT 缺陷**：行业用的是同花顺**当前**分类快照，不是历史分类。2019 年的行业归属可能与现在不同，尤其是重组过的公司。这个偏差对"是否行业中性"的判断影响小（HHI 极低），但对逐年行业归因不严谨。

| 项目 | 值 |
|---|---|
| 单边年换手 | **10.37×** |
| 双边年换手 | **20.73×** |
| 平均并发持仓 | **137.8 只**（中位 115，P90 272，最大 423） |
| 资金利用率 | **93.9%**（近 3 年 98.3%） |
| cohort 数 | 1,932 |

逐年单边换手：2018 5.4×、2019 14.8×、2020 12.6×、2021 11.3×、2022–2024 11.3–11.5×、2025 9.1×、2026 6.2×。

**138 只并发持仓 × 每只 0.72% 资金**——这不是一个"选 10 只票"的策略，而是一个**高度分散的 100+ 只组合**。好处是单票风险极低；坏处是：
1. 每只仓位很小，交易成本被固定费用主导；
2. 需要 138 个券商的交易通道/算法执行能力；
3. 单只 0.7% 的仓位意味着**任何单票研究都不重要，只有横截面的筛选规则重要**——这与"温和 ramp 是个股形态"的叙事有张力。

## 8. 与原报告 +8.69% / −29.3% 的对照

| 项目 | 原报告 | 本次审计 | 差异原因 |
|---|---|---|---|
| 绝对年化 | +8.69% | **+8.65%** | 严格成交剔除 29 笔开盘涨停 |
| 最大回撤 | −29.31% | **−29.32%** | 一致 |
| 平均信号/天 | 9.78 | 11.03（可成交） | 剔除规则不同 |
| 基准 | 未定义（原报告明确弃用日频基准） | 同结构 15-cohort 等权基准 +2.36% | 新增 |

**原报告的 +8.69% 可以复现。** 但它当时没有基准，所以"8.69% 是好是坏"无法判断；补上同结构基准后是 **+8.65% vs +2.36%，alpha 6.27%/年、IR 0.69**。

## 9. 组合层结论

| 项目 | 判定 |
|---|---|
| 绝对收益 | +8.65%/年，但 beta 0.86，其中约 2pct 是市场给的 |
| 超额收益 | +5.6%/年（算术）、IR 0.69——**中等偏弱，不是强 alpha** |
| 回撤 | −29.3%，水下 33 个月 |
| 月度 | 52% 胜率，6 连亏，收益集中在少数月份 |
| 分散度 | 138 只并发、90 个行业、HHI 0.018——过度分散 |
| 换手 | 10.4× 单边，成本敏感 |
| 2019–2020 | **跑输基准 10.5pct** |

> 组合层能支撑的结论是："这是一个**高 beta、中等超额、极度分散、成本敏感**的选股偏移"，不是"稳定 alpha 机器"。它作为绝对收益产品不合格（水下 33 个月），作为增强型/相对价值 sleeve 勉强合格。
