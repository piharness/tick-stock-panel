# 沉默小盘股的 regime 条件 alpha：市场状态 vs 事件前动量

> 一句话结论：**「沉默无 alpha」在牛市/题材轮动里同样成立，且比想象更硬——真正携带信息的是「以什么姿态跌入沉默」（事件前动量），不是市场状态本身。**
> 牛市里还沉默的票是「被资金彻底抛弃的烂票」，跑输更狠；题材轮动热度本身对 silent 超额几乎零边际贡献（「鸡犬升天」假说被证伪）。

---

## 1. 问题（对上轮结论的升级攻击）

上轮（`silent-excess-return-attribution.md`）证明：silent 的 +606bp 超额是小盘+低流动性的投影，
拆掉后全样本事件后差分 CAR ≈ −134bp，即「沉默无 alpha」。

但这是**全样本 21 年平均**。一个自然的质疑：这个「无 alpha」是否在特定市场状态下反转？
A 股存在「牛市末期/情绪亢奋期低流动性小盘补涨」（消灭低价股、鸡犬升天）的直觉——若真实，
silent 的超额应在「牛市 + 高轮动热度」里反转为正。

## 2. 方法

沿用事件研究 + PSM（防前视，匹配特征取事件前一日）框架，加一层 regime 交互：

- **事件** = 首次「跌入 silent」（前一日非 silent，当日 silent），同 4380 事件 / 3773 匹配对。
- **市场状态标签**（严格无前视，滚动 250 日窗口）：
  - `mkt_ret` = 全市场日收益横截面中位数（当日）
  - `bull_rank` = mkt_ret 过去 250 日滚动分位（>0.7 牛市 / <0.3 熊市 / 其余震荡）
  - `hot` = 当日涨停家数 > 过去 250 日滚动中位（题材轮动热度）
  - `regime` = market × hot 六象限
- **事件前动量** `ev_mom` = 跌入 silent 前 20 日累计对数收益（作为关键混淆变量显式控制）。

## 3. 结果

### 3.1 分 regime 的事件后差分 CAR（t=60，bp，负=跑输对照）

| regime | n_pairs | 事件后 CAR | se | t |
|---|---|---|---|---|
| bear_cold | 690 | −124.9 | 310.5 | −0.4 |
| bear_hot | 282 | +1005.3 | 701.4 | +1.4 |
| bull_cold | 189 | −117.2 | 293.0 | −0.4 |
| bull_hot | 1050 | −376.4 | 328.6 | −1.2 |
| neutral_cold | 780 | **−428.8** | 151.5 | **−2.8** |
| neutral_hot | 726 | +79.0 | 443.3 | +0.2 |
| **ALL（复现）** | 3717 | **−133.8** | 151.8 | — |

复现成功（−133.8 ≈ 上轮 −134）。表面看 `neutral_cold` 显著为负、`bear_hot` 大正——但这是**选择效应**的假象，见下。

### 3.2 真凶是「事件前动量」，不是 regime

按事件前动量（ev_mom）三分位，**跨所有 regime 合并**：

| 动量 bin | n | 事件后 CAR |
|---|---|---|
| mom低（跌入 silent 前已崩） | 1239 | **−861 bp** |
| mom中 | 1239 | −302 bp |
| mom高（跌入 silent 前仍在涨） | 1239 | **+762 bp** |

单调、幅度 1623bp。**且这个梯度在每个 regime 内部独立复现**（bull_hot / neutral_cold / bear_hot … 无一例外）。
说明：跌入 silent 的因果效应，主要取决于「它是带着下跌动量进来，还是带着上涨动量进来」。

### 3.3 控制动量后，regime 的独立主效应

用动量 bin 中心化残差，剥离动量后：

| 变量 | 组 | 残差 CAR（控制动量后） |
|---|---|---|
| 牛熊 | bear（熊） | **+393 bp** |
| | neutral（震荡） | −31 bp |
| | bull（牛） | **−271 bp** |
| 轮动热度 | cold | +7 bp |
| | hot | −6 bp |

**两个反直觉但可解释的结论**：

1. **题材轮动热度（hot vs cold）对 silent 超额几乎零独立贡献（差 13bp）**——「鸡犬升天」假说**被证伪**。题材轮动的强弱，不决定沉默小盘股的相对表现。
2. **牛熊有独立次级效应，但方向相反于直觉**：熊市里跌入 silent 的票**更好**（+393bp），牛市里跌入 silent 的票**更差**（−271bp）。机制：牛市里还沉默的票 = 被资金彻底抛弃的「最烂票」，后续继续跑输；熊市里沉默是市场常态（大家都缩量），沉默不携带「烂票」信息。

## 4. 结论

1. **「沉默无 alpha」在牛市、熊市、题材轮动里都成立**，不是某个 regime 的局部假象。
2. **但「沉默」是一个信息不完全事件**：真正携带未来收益信息的是**「以什么姿态跌入沉默」**——
   - 动量崩坏（前 20 日已跌）跌入 silent → 继续跑输 −861bp（烂票惯性）
   - 动量仍强跌入 silent → 反而 +762bp（可能被流动性暂时错杀）
3. **牛熊修饰这个效应**：牛市放大了「烂票」的惩罚（−271bp），熊市则让「沉默」趋于中性甚至偏正。
4. **题材轮动强度本身不产生 silent 的超额**——你的「鸡犬升天」直觉在数据里不成立。

## 5. 对产品/交易的含义

- 如果要把「沉默公民」用作交易信号，**不能只看沉默这个标签，要看「跌入沉默前的动量」**：
  - 「动量崩坏 + 跌入沉默」= 最危险的组合（烂票延续，−861bp）
  - 「动量仍强 + 跌入沉默」= 潜在的机会（错杀，+762bp）
- 但这是**事后**（事件研究）的样本外结论，尚未做**事前可交易性**检验（信号在 T 日收盘后可知，需验证 T+1 开盘买入的可行收益），不能直接当策略。
- 页面边界声明的正确升级方向：沉默的价值不在「沉默」本身，而在「沉默前的姿态」。
