# OS / FE 预注册：上方筹码真空度 × 浮筹枯竭度 → 未来 60 日被拉升概率

> 写于**任何条件概率被计算之前**。所有阈值、口径、证伪条件在本文固定；
> 之后新增的任何切分只能标为探索性，不得回溯修改主判据。
> 动机：本仓已有一次教训——384 格搜索下 t=3.40 对应 E[max]=3.45、Bonferroni p=0.26
> （`phase2-audit/`）。所以主判据只留一格，其余全部降级为描述性。

## 1. 样本池（PIT，含退市，含 ST）

| 项 | 口径 |
|---|---|
| 主表 | `kline_daily_enriched`（qfq），5,582 只，全部活到 2026-11-24 |
| 缺口股 | `backfill_20261117/stock_gap_daily.parquet`（raw），307 只，含退市/合并/改名 |
| 退市处理 | 不做「活到今天」过滤。退市股只在存续期内贡献观测；窗口跨过退市记 NaN 并报告截断率 |
| ST 处理 | **不剔除**。`is_st` 为 baostock `isST` 的 PIT 标记（日频，交易所口径），仅用于分层与稳健性 |
| 禁用的替代法 | 「5% 涨跌幅指纹」重建 ST（已证伪：precision 0.448 / recall 0.423） |
| 观测网格 | 全局交易日索引 `rn`，每 5 个交易日一格（确定性锚点） |
| 历史门槛 | 该股已有 ≥250 个交易日（次新股排除） |
| 时间范围 | 观测 2016-01-01 ~ 2026-08（标签需 60 个交易日） |
| 已知偏差 | 缺口股为 raw 价，除权日假跌；方向固定为**压低**其收益，只会让退市股看起来更差 |

## 2. 状态变量（定义见 `analysis/_osfe_lib.py` 文档字符串）

换手衰减筹码模型，权重与生产内核 `levels.py::_profit_split` **数值等价**
（构建时硬闸门，实测最大绝对差 4e-16）。窗口 750 个交易日。

- `OS = 1 − 现价上方 10% 内的筹码占比`（真空度，高 = 头顶没有套牢盘）
- `FE = 现价 ±10% 内、60 日以上老筹码 / 同区间全部筹码`（枯竭度，高 = 浮筹已被换手洗掉）
- 控制变量：`profit`（获利盘比例）、`cost_gap`（平均成本偏离）、`near_mass`（近价筹码密度）

## 3. 事件定义（被拉升）

- **主判据 `pump30`**：`max(close[t+1..t+60]) / close[t] − 1 ≥ 0.30`
- 次要 `pump20` / `pump50`（±10pp 阈值敏感性）
- 次要 `fast30`：未来 60 日内**任一 20 日窗口**涨幅 ≥ 30%（"快拉"而非慢牛）
- 窗口完整（`last_rn ≥ rn+60` 且窗口内 ≥40 个有效收盘）才给标签，否则 NaN

## 4. 处理组与对照

- **主处理**：`OS` 与 `FE` **同日横截面双五分位同时进第 5 组**
- 次要处理：仅 OS 进 Q5（FE 中性）、仅 FE 进 Q5（OS 中性）
- 对照 1（naive）：同日全池均值 → 给出"看起来的增量"
- 对照 2（粗匹配）：同日 × 同行业（同花顺一级）× 同市值五分位
- **对照 3（主估计量，全匹配）**：在对照 2 的格内，再做 (r20, r60, to20, amp20, dist_hi250)
  标准化欧氏距离最近 3 只孪生。**只允许被检验的两个维度不同**，其余全部对齐
- 对照 4（组内）：同一只股票的 treated 日 vs 非 treated 日（股票固定效应）

匹配必须同时报告 `对照1 → 对照3` 的衰减。若增量只在对照 1 存在，
结论固定为「OS/FE 是既有特征的重新表述」，不得改口为主张。

## 5. 统计推断

- 单位是**日块**，不是「事件数」：同日全市场一起重采样
- moving-block bootstrap，块长 `L` = treated 状态在**真实数据里的 run-length**
  （各股连续处于 treated 的交易日数中位数，下限 5 日），2,000 次
- 同时报告 iid bootstrap 与 block bootstrap 两个 CI，差值即自相关代价
- 配对差 = `1[pump|treated] − mean(1[pump|controls])`，先按事件求，再按日块平均
- 功效：报告 MDE = (1.96+0.84)×SE(Δ)，避免把「没测出来」写成「没有」

## 6. 容量

- 单票上限 = `1% × ADV20`（元）。5% ADV 不可执行（`phase2-audit` 已证）
- 组合 20 只等权、单票 5% 权重 ⇒ AUM 上限 = 20 × 单票容量
- **决定性检验**：把 treated 事件按 ADV20 五分位切开，看 Δ 是否只存在于最不流动的一档
- 若 Δ 仅存在于 bottom-2 ADV 档 ⇒ 判为不可投资，不论统计显著

## 7. 证伪与负控

1. **安慰剂**：把 treated 换成 OS/FE 双 Q3（中间档）→ Δ 应≈0
2. **标签置换**：同日内打乱 pump 标签，重复 200 次 → Δ 的零分布
3. **机械性检验（surrogate）**：用每只股票自身的波动率与换手率生成随机游走价格路径，
   重算 OS/FE 与 pump，跑同一套匹配。若代理数据上也出现同样的 Δ，
   则 Δ 是估计量的机械产物，不是信息
4. **口径敏感性**：OS 用 20% 窗口、FE 用 20%/80% 区间与 20 日老筹码，
   四个替代定义方向是否一致（不做显著性主张）

## 8. 时间外样本

- 设计期 2016-01 ~ 2021-12，外样本 2022-01 ~ 2026-08
- 主判据要求**两段同号**；只有一段显著 ⇒ 记 CONDITIONAL

## 9. 裁决规则（先写死）

| 结论 | 条件 |
|---|---|
| **PASS** | 全匹配 Δ ≥ +3.0pp；block-bootstrap 95% CI 不含 0；设计期与外样本同号；top-3 ADV 档内 Δ ≥ +1.5pp |
| **CONDITIONAL** | Δ ≥ +3.0pp 且 CI 不含 0，但容量档或时段有一项不满足 |
| **REJECT** | 全匹配 Δ < +1.5pp，或 CI 含 0，或效应完全由 bottom-2 ADV 档贡献 |

主判据只有一格：`pump30 × 双 Q5 × 全匹配`。其余 11 格（3 事件 × 3 处理 + 2 口径）为探索性，
报告中同时给出格数与 Bonferroni 参考值。

## 10. 已知无法消除的偏差

- 行业分类为**当前**同花顺一级（历史行业不可得）⇒ 行业匹配含轻微前视
- 缺口股无分红记录 ⇒ 除权日假跌
- 无「是否曾被调查/处罚/重组」等事件数据 ⇒ 「拉升」只能从价格路径识别，不能识别意图

## 11. 执行后记：三处偏离预注册（如实记录）

1. **块长**：预注册取「状态 run-length」。实测中位 run-length = 5 个交易日（1 格），
   而 60 日标签在每 5 日一格的网格上重叠 12 格。若用 L=5，块自助等于 iid，会低估区间。
   主区间改用 `L = max(run-length, 12)`；两套区间同时报告
   （L=12 → [+0.54,+1.69]；L=5 → [+0.56,+1.62]）。差异可忽略，不改变裁决。
2. **`fast30` 定义修正**：预注册写「未来 60 日内任一 20 日窗口涨 30%」，
   初版实现成 `max_h C[t+h]/C[t+h−20]−1`，把信号日**之前**已发生的涨幅算了进来
   （等于把"已经在涨"当成"将被拉升"）。改为窗口起点不早于 t（a∈[0,40]）。
   修正后 +1.46pp，修前 +4.72pp —— 差的 3.3pp 全是污染。
3. **追加三项证伪**：竞品单变量对照、OS/FE 对全部协变量的正交化、双残差联合检验。
   这三项不是新主张，属预注册 §7 的证伪延伸；它们全部指向"归零"。
