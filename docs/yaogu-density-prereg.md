> 2026-11-25 11:05 冻结，**跑数前写成**。任何事后调整必须在结果文档里单列并标注。
>
> **结果见 `docs/yaogu-density-result.md`：P1/P2/P3 FAIL，仅 P4 PASS ⇒ 不成立，方向关闭。**
> 本文件此后不再修改，作为「当时是怎么想的」的存档。

## 0. 要证伪的那句话

> 「妖股密度处在历史高位时，高热度股的赔率最差；因此它是一个减仓/避让信号。」

上一轮给出的唯一支撑是年度相关 −0.32（N=21，t≈−1.5，不显著）。本轮的职责是把它变成一个**能被证伪的月度检验**，而不是继续引用那个数字。

## 1. 三个必须先避开的坑

1. **用「见顶月份」计数 = 偷看未来。** 一只股票是否见顶，只有它后来跌了才知道。
   所以密度必须由**当日可观测状态**构成：`frac(rmax60 ≥ 150%)`，其中
   `rmax60(t) = close(t)/min(close, t−59..t) − 1` 只用当日及过去 60 行。这不是事件计数，是**状态占比**。
2. **密度与「过去一个月市场收益」机械相关。** 今天的高密度就是今天涨幅的函数。
   任何「密度预测未来」的结论，必须证明它在控制过去市场收益后仍成立，否则只是动量/反转的伪装。
3. **月度重叠。** 月度收益不重叠，但 HOT 是 60 日窗口的平滑量，自相关高；t 值用 Newey-West(lag=3) + block bootstrap(block=6) 双口径。

## 2. 变量（全部 point-in-time）

| 变量 | 定义 |
|---|---|
| `HOT_m` | 第 m 月全部交易日 `frac(rmax60 ≥ 150%)` 的均值；分母 = 当日有成交的 A 股 |
| `HOT_q_m` | `HOT_m` 在**过去 120 个月**（至少 36 个月）中的分位，0–1 |
| `heat_i,m` | 个股 i 在第 m 月末的过去 20 个交易日平均换手率 |
| `EX_m` | 组合在第 m 月收益 − 全市场等权当月收益 |

宇宙：剔除上市前 250 个交易日、北交所（920/8 开头）。ST 无法回溯标记，保留并说明。
退市股并入 `stock_gap_daily.parquet`（但其无换手率，只进基准不进组合，作为已知偏差）。

## 3. 组合与检验

- 每月末按 `heat` 横截面排序，取 **top 20%** 等权；下月**首个交易日开盘**买入、**月末收盘**卖出。
- 主检验：`EX_m` 按 `HOT_q_{m−1}` 五分位分组，**Q5 − Q1**。
  - 统计量：Newey-West t(lag=3)、block bootstrap 95% CI（block=6 月，2000 次）。
- 增量检验：`EX_m = a + b·HOT_q_{m−1} + c1·MKT_{m−1} + c2·MKT_{m−3..m−1} + e`，看 b。
- 安慰剂：把 `HOT_q` 按 block 重排 2000 次，看真实 Q5−Q1 在零分布中的位置。

## 4. 判据（事前固定，四条全过才算成立）

| # | 判据 |
|---|---|
| P1 | Q5 − Q1 的 NW t ≤ **−2.0** |
| P2 | block bootstrap 95% CI **全为负** |
| P3 | 控制 `MKT_{m−1}` 与 `MKT_{m−3..m−1}` 后，b 的 t ≤ **−1.5**（方向不变即可，不要求更强） |
| P4 | 安慰剂：真实值落在零分布左尾 **p < 0.05** |

任一条不过 ⇒ 结论为「密度不含增量信息，只是动量的影子」，方向关闭。
四条全过 ⇒ 仍只算**线索**（月度 N≈220、单一市场），不构成部署依据。

## 5. 稳健性（同时报，不用于挑选）

- heat 换成 `r20`（过去 20 日涨幅）
- `HOT` 换成涨停占比 `frac(lu > 0)`
- 分位换成全样本五分位（含前视，作为上界）
- 组合改成 bottom 20%（反向）
- 剔除 2015 年（单一 regime 主导风险）

## 6. 已知会假通过的方式

- 2015 年一个 regime 就能把 Q5 拉成负：必须看逐年。
- N≈220 时 p=0.05 的门槛很低，先验上应该期待「不过」。
- 若 Q5 与 Q1 的差主要由 Q1 的正超额贡献（低密度月份特别好），那和「高密度该避让」是两件事，必须分开说。
