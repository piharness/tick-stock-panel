# 用户命题：「死拿底仓 + 日内小T，每次赚 1-2%，成本降为负 ⇒ 不败」

> 判决：**不可行，且不是参数问题。** 命题的四个前提各自被独立否证一次。
> 数据：`data/_probe_t0/trades.parquet`（2,655,944 票日 / 1,061 万笔 / 492 日 / 2024-11-06~2026-11-16）
> 脚本：`analysis/_diag_t0_thesis.py` → `_diag_t0_thesis.json`
> 口径沿用 `docs/citizen-t0-transition.md` §1：底仓 T+0 等量往返，正T=跌破锚 d% 买、回锚卖，
> 负T=冲高 d% 卖、回锚买，14:55 强制回锚；成交只用 bar 的 open/close，**不用 high/low**；往返 12bp 已扣。

---

## 0. 一句话

**振幅是够的（中位 3.49%），抓取是不够的（5.5%，需要 32%）；而"抓取率"的上限由"日内方向可预测性"决定，那个可预测性在数据里不存在（方向 IC 0.03，160 个形态格无一为正）。**

---

## 1. 四个前提，四次否证

| 命题里的前提 | 检验 | 结果 |
|---|---|---|
| ①「每天都有 1-2% 的空间」 | 日内振幅分布 | **成立**。中位 3.49%，≥3% 占 60.0%，≥5% 占 28.2% |
| ②「能吃到这 1-2%」 | 抓取率 ρ = 笔毛/振幅 | **否**。ρ 中位 **0.055**；要赚 1% 在 3.5% 振幅上需 ρ=0.32，**差 6 倍** |
| ③「选波动足够的股票更有利」 | 按当日振幅十分位 | **反了**。Q1 +45.6bp → Q10 −32.5bp，斜率 **−7.35bp/振幅百分点**，弹性为负 |
| ④「反复做，积少成多」 | T+1 + 满仓约束 | **结构性死结**。满仓做T只能先卖后买（负T），而负T 在上涨日平均 **−215bp** |

## 2. 「每次赚 1%」缺的那一半

d=1% 正T，n=1,325,918 笔：

| | 值 |
|---|---|
| 触发率（当天跌破锚 1%） | 49.7% |
| **胜率**（回锚） | **51.4%** |
| 赢的笔平均 | **+125 bp**（≈ 赚 1.25%） |
| 输的笔平均（14:55 强平） | **−151 bp** |
| 盈亏比 | 0.83 |
| **盈亏平衡胜率** | **54.6%** |
| 实测笔净 | **−8.9 bp** |

**期望 = 0.514×125 − 0.486×151 = −9.1bp。** 命题只记了左边那一项。

胜率敏感度（赔率 125:151 固定、242 笔/年复利）：

| 胜率 | 笔期望 | 年化 |
|---|---|---|
| 51.4%（实测） | −9.1bp | **−19.8%** |
| 54.6%（平衡） | 0 | 0% |
| 57% | +6.3bp | +16.5% |
| 60% | +14.6bp | +42.3% |

这 3.2 个百分点的缺口 = 12bp 往返成本 + 逆向选择（跌破 1% 的票里，继续跌的比反弹的多）。

## 3. 你的股票池：越"扎实稳定"，越不能做T

d=1% 正T，逐票实测（492 日）：

| 标的 | 振幅中位 | 正T 触发率 | 胜率 | 笔毛 | **笔净** |
|---|---|---|---|---|---|
| 贵州茅台 | 1.54% | 16% | 41.8% | +6.7 | −5.3 |
| 长江电力 | **1.30%** | **11%** | 42.3% | +13.9 | **+1.9** |
| 招商银行 | 1.63% | 18% | 42.0% | +0.0 | −12.0 |
| 五粮液 | 1.61% | 20% | 32.0% | +3.5 | −8.5 |
| 中国平安 | 1.92% | 26% | 31.2% | −23.0 | −35.0 |
| 美的集团 | 1.91% | 21% | 37.3% | +0.6 | −11.4 |
| 中国神华 | 2.29% | 28% | 50.0% | +17.6 | **+5.6** |
| 恒瑞医药 | 2.47% | 40% | 43.9% | −0.4 | −12.4 |
| 海康威视 | 2.08% | 34% | 48.5% | +7.9 | −4.1 |
| 伊利股份 | 1.74% | 19% | 44.2% | +1.6 | −10.4 |

**8/10 为负。** 两只微正的（长电 +1.9bp、神华 +5.6bp）也不构成"每次 1-2%"：
长电振幅 1.30%，赚 1% 要吃满 77% 振幅——所以它只有 11% 的日子能触发。
按实测 +1.9bp/笔复利，把成本降到 0 需要 **5,263 笔 ≈ 21.7 年**（且收益率必须恒定、底仓不跌）。

**「业绩稳定」与「波动足够」在这张表里是互斥的**：蓝筹振幅中位 1.3-2.5%，全市场 3.49%。
你要的"扎实"，系统性排除了"波动够"。

## 4. 上限与实现差 98 倍，差值就是「择时精度」的价格

| 路径 | 日收益 | 242 日单利 |
|---|---|---|
| 完美做T（每日买最低、卖最高） | **+432.7 bp** | +1,047% |
| 正T d=0.5% | −5.0 bp | −12% |
| 正T d=1.0% | **−4.4 bp** | −11% |
| 正T d=2.0% | −2.6 bp | −6% |
| 正T d=3.0% | −1.1 bp | −3% |

**432.7 / 4.4 = 98 倍。** 这 98 倍不是交易技巧的差距，是"日内路径可预测性"的价格。
而 `docs/t0-shape-features.md` 已测：日内方向 IC 0.03（同号日 40%），160 个形态格日净 **0 个为正**；
唯一可预测的是振幅（IC 0.595），振幅只给空间、不给方向。
⇒ **不是"你不够努力"，是信息不在数据里。**

## 5. 「成本降为负」是因果倒置

按 symbol 汇总，5,447 只（≥200 日），492 日累计做T净收益 vs 该股同期涨幅：

| 该股累计涨幅 | 只数 | 做T累计 bp |
|---|---|---|
| −162 ~ +1% | 1,090 | **−2,745** |
| +1 ~ +32% | 1,089 | −2,362 |
| +32 ~ +63% | 1,089 | −2,313 |
| +63 ~ +107% | 1,089 | −2,049 |
| **+107 ~ +523%** | 1,090 | **−1,113** |

- 相关系数 **+0.205**：**股票涨得越多，做T亏得越少** —— 你看到的"做T有效"，是上涨行情的投影。
- 但**五个档位全部为负**。即使股票 2 年涨 5 倍，做T仍累计亏 11%。
- 中位 −2,054bp = **−20.5%**。

"成本为负"的人不是做T做出来的，是**股票涨出来的**；做T只是让他在上涨中少赚一点。
这是记账层面的因果倒置：成本为负是**结果**，不是护城河。

同期 492 日，全市场等权（日内开→收）：

| 账户 | 日均 | 累计 |
|---|---|---|
| 死拿（无T） | +11.9 bp | **+72.3%** |
| 每日一次正T（d=1%，全仓） | +7.5 bp | **+38.1%** |

做T的净贡献 **−4.4bp/日**。bootstrap 10 年（票日经验分布，B=5,000）：

- 终值中位 **0.27x**，P5 0.10x，P95 0.81x
- **亏损概率 97.8%**，翻倍概率 0.1%

（这只是做T增量，不含底仓涨跌。底仓的涨跌与做T无关。）

## 7. 为什么「满仓做T」在结构上只能做负T

正T（低吸）需要**现金**；底仓满仓时没有现金，只能先卖后买（负T）。
而负T 的分布由当日方向决定（d=1%，n=1,312,814）：

| 当日涨幅 | 负T 笔净 | 胜率 |
|---|---|---|
| < −3% | +179.7 | 98.7% |
| −3 ~ −1% | +135.9 | 96.1% |
| −1 ~ 0% | +101.0 | 89.7% |
| 0 ~ 1% | +52.9 | 70.9% |
| 1 ~ 3% | −16.4 | 38.7% |
| **> 3%** | **−215.4** | **21.0%** |

（**事后**分组，不是信号——但它就是"卖飞"的定价。）
47% 的日子（跌）赚钱，53% 的日子（涨）亏钱，加权 −11.2bp。
**「吃主升浪」和「日内高抛」是同一个分布的两端，不能同时要。**
`docs/citizen-t0-transition.md` §3 已证：上行（升格）改善正T +10bp，**完全不改善负T（Δ≈0）**。

## 9. 「不败」的正确形状

用户要的不是"做T"，是**下行不被强制卖出 + 上行不缺席**——这是凸性，不是成本。
做T提供的是**负凸性**：赚 1% 封顶，亏是 −151bp 且尾部到 −2,829bp（p1 = −598bp）。

已在本仓库验证过的三条凸性来源：

1. **仓位结构**：六格（每笔 1/6）vs 满仓逆波动 —— 回撤 −8.1% vs −20.6%
   （`docs/structural-edge/portfolio-replay.md`）
2. **资产结构**：腿1 + 511010 买入持有 → **7.87% / −6.91%**（vs 现金 6.63% / −7.11%），已启用
   （`docs/structural-edge/leg2-bond.md`）
3. **未验证、但结构上最接近用户诉求**：**可转债**。债底 + 股性 + 下修条款 = 真正的下有保底上不封顶；
   且 **T+0、免印花**，是唯一在制度上允许"日内反复"的载体（正股 T+1 一天只能一次）。
   本仓库没有可转债数据，这一条是**假设，不是结论**。

## 11. 已知限制

1. 样本仅 2024-11~2026-11（492 日），且这段是全市场等权日内 +11.9bp/日的上行环境；
   震荡市/下行市的做T 结果未单独分层。`_diag_t0_elasticity.py` 的 22 年外推（beta=1）给出
   core −8.1bp / silent −9.7bp、**22 年 0 年为正**，但那是外推不是实测。
2. 「主观择时」无法回测。本文用"完美上限 432bp"与"规则实现 −4.4bp"夹逼，
   真实主观做T落在两者之间；`t0-shape-features.md` 的 160 格全负是"可预测性不存在"的独立证据。
3. `trades.parquet` 的 r1 存在 NaN（未触发日），本文按 0 处理（不是 −12bp）。这是
   `t0-shape-features.md` §0 纠正过的同一处口径。
4. 成本按 12bp；若单笔名义额 < 7.24 万元，最低佣金 5 元会把有效费率推到
   **±100bp 量级**（`docs/net-expectancy-feasible-region.md` §0.3），结论只会更负。
