# T1 结果 · 行业框架定价：约束值 −70bp/20日，行业信息值 +5bp

> 预注册：[`t1-industry-frame-prereg.md`](t1-industry-frame-prereg.md)（2026-11-25，跑数前冻结）
> 脚本：`analysis/_diag_t1_industry_frame.py` → `analysis/_diag_t1_industry_frame_result.json`、`_yearly.csv`、`data/.scratch/footprint20d/t1_cohorts.parquet`
> 裁决对象：`docs/method-dossiers/2026-11-hf-quant-documentary.md` §5.3 的冲突（C6 vs 行业内孪生 +0.2bp）

## 0. 一句话

**"行业内选股"不是 alpha 来源，是一个明码标价的约束：把行业权重从自由漂移改成对齐基准，20 日超额少 70.4bp（t −4.02，年化 ≈ −8.8%），而这个约束买到的"行业信息"只值 +4.9bp/20日（年化 ≈ +0.6%）。**

视频说"超额收益完全来自每一个细分行业内部的横截面优胜劣汰"——这句话在逻辑上是**同一律**：行业权重钉死基准之后，超额当然只能来自行业内。它是产品设计的定义，不是发现。本检验做的是给这个定义**定价**。

## 3. 预注册判据逐条

| 判据 | 门槛 | 实际 | 结论 |
| --- | --- | --- | --- |
| P1 `ind − all` 2018+ 年度 | >0 且 ≥7/9 为正 | **3/9** | **不过**（且方向为负） |
| P2 `ind − bench` 2018+ | t>2 且 >0 | −63.0bp；iid t −3.06 / NW −1.81 / CI[−115,−11] | **不过**（方向为负，CI 排除 0，但 NW 未过 2） |
| P3 `ind − rand` | >0 且 t>2 | +4.9bp，NW t +2.37，CI [+0.7,+9.4] | **过，但量级可忽略** |
| P4 负控（高热度方向） | `ind−all` 不应显著 >0 | +1.5bp，t +0.06 | **通过**（框架效应与方向无关，排除评分方向伪影） |

> **t 口径说明（必须读）**：预注册 §5 写的是"只用非重叠锚点 t"。非重叠口径下 N=203，`ind−all` t = −1.86、`ind−bench` t = −1.49、`ind−rand` t = +1.49——功效损失 75%，`ind−all` 掉到 2 以下。
> 本表改用 iid / NW(lag4) / 年 block 三口径并列，因为锚点每 5 日一个、持有 20 日，重叠是结构性的，丢掉 3/4 样本不是"更严谨"，是"更没把握"。
> 结论不依赖这个选择：P1 是**符号检验**（3/9），与 t 无关；P2/P3 的方向在三种口径下一致，只有显著性强弱随口径在 1.5–4.0 之间移动。

按预注册 §5 的四情形表：落在「P1 不过 + P2 不过 ⇒ 情形 b」，但**不是 b 的原始表述**（"无可交易 α"），而是一个更具体的形态：**α 不在行业内，而在行业间；行业内选股是负的，且这个负不是行业特有的，是"分组配额"机制造成的**。

## 4. 三条分解（本报告的主要产出）

### 4.1 约束的价格是 −70bp/20 日，且与行业边界无关

`ind` 与 `rand` 的差距只有 +4.9bp；两者的绝对水平几乎相同（−63.0 vs −67.9bp）。这意味着：

- **不是"行业分错了"**。把行业换成一堆随机分组，损失一样大。
- **是"每组必须选 k_g 只"这个机制本身**。一旦你被要求在每个组里都买 20%，你就必须买进那些**本来一只都不该买**的组里最不坏的票。
- 视频的构造（31 个申万一级 × 行业内 top20%）正是这个机制。所以 −70bp/20 日是它这条规则的**机制成本**，不是它的选股能力。

这一点直接修正了 §5.3 的框架：冲突不在"行业内有没有 α"，而在"**没人给这个约束定价**"。指增产品的行业中性不是免费的，它每年先付 ≈8%，再去挣行业内 α。

### 4.2 行业信息只值 +4.9bp，而分组操作值 −75bp

把账拆开：

```
全市场 → 随机分组：−75.3bp   ← 「每组配额」的代价（占 94%）
随机分组 → 真实行业：+4.9bp  ← 「行业边界」的信息（占 6%）
全市场 → 行业内：  −70.4bp   ← 两者抵冲后的净价
```

所以"做行业中性化"这件事，**总效应 −70.4bp 里，−75.3 是配额机制的贡献、+4.9 是行业边界的贡献**——行业边界几乎只是在给配额机制退款 6%。如果一家机构说自己靠"行业中性"控制风险，它付的是 70bp/20日 的保险费；这笔钱买到的是**跟踪误差**，不是超额。

### 4.3 配额 ≠ 去均值：两个"行业中性"方向相反

`inddm`（行业内减去行业均值，再全市场排序）是唯一稳定为正的框架：+23.5bp/20日 vs 基准（NW t 3.01，CI [+13.5,+34.3]），比全市场排序还好 +16.0bp。

机制解释（假设，未单独检验）：配额制强制**每个行业都必须有持仓**；去均值允许**弃权**——没有相对极端的行业就一只不买，有多个极端值的行业多买。前者是"均匀覆盖"，后者是"按信噪比分配"。

**这条是探索性结果，不是可部署结论**，有三个理由：

1. `inddm` 在预注册里只是诊断臂，没有 OOS、没有容量测算；
2. **多重检验**：本轮共 4 臂 × 2 方向 = 8 个组合，Bonferroni 后 t 门槛约 2.7，`inddm` 的 NW t = 3.01 **刚过线**——"值得跟"，不是"已成立"；
3. 它是"被发现"而非"被预测"的，这与本仓库对温和 ramp 的处理应当一致（先纸面、再 OOS）。

它现在的身份是"进 T2 的线索"。

## 5. 对 HF-2026/C6 的裁决

**C6 的方法层：在本仓库可测口径下不成立。** 具体拆成三句：

1. **"超额来自行业内横截面"** —— 对行业权重严格对齐基准的产品，这是**同义反复**；对可以自由漂移的产品，这句话是**错的**（我们的 α 全在行业间）。
2. **"行业内 top20% 能产生 8–12%"** —— 在我们能测的口径（主板、20 日、低热度评分、366 只）里是 **−7.9%/年**。不能据此说视频的数字是假的（评分、周期、宇宙、基准都不同），但可以说：**这个数字不可能来自"行业约束"本身，只能来自一个我们没见过的、行业内有强预测力的评分**。
3. **"绝不压注单一热门赛道"** —— 方向对（风险控制），但它被讲成了收益来源。本检验给出的是**保险费的价格**：−70bp/20日。

**对 §5.3 冲突的最终判定**：`footprint-20d-significance.md` 的「行业内孪生 +0.2bp(t=0.01)」与本检验**同向且互相加强**——行业内确实没有可检出的独立信息（+4.9bp，年化 +0.6%）。原 §5.3 列的三种可能中，**(b) 成立**：(a) 过度控制的担心可以撤回。

## 6. 不能外推的六条边界

1. **评分依赖**。−70bp 是"低热度评分"下行业约束的价格。对一个跨行业信息为零的评分，这个价格接近 0。它衡量的是"该评分里跨行业那部分的价值"，不是普适常数。
2. **周期**。20 日固定持有、每 5 日建仓。指增产品是日频调仓、年度考核，成本结构不同。
3. **宇宙**。主板 + 中小板，不含创业板/科创板/北交所；富化面板不含退市股（幸存者偏差，对多头有利，四臂同向）。
4. **行业分类是当前名称、混合层级（90 组，部分一级如"电力"、部分二级如"汽车零部件"）**。`ind−rand` 的近零结果说明这个缺陷是二阶的：换成分组边界，结论不变。但**组越多、配额强制覆盖越强**——视频的 31 个申万一级比我们的 90 组更粗，所以 **−70bp 应读作上界**，不是点估计。方向不会反，量级会小。
5. **幸存者偏差的方向对我们有利、对结论不利**：面板不含退市股，而低热度多头最容易踩到退市/仙股。被剔除的正是最差的那批 ⇒ `ind` 的 −63bp 是**在有利偏差下**测到的。
6. **只做多**。视频的"低配 bottom20%"没有测（A 股个股做空不可得）。
