# L1 缺口反转 — 每日候选与结算

> 这是 `analysis/` 里 300 多个 cell 唯一活到生产的东西，也只活到"给限价"这一步。
> 它不是选 20 只股票，是**等一个低开**。

## 1. 策略定义（拆开引用就变成另一个策略）

    T 日收盘   全市场按 mom20 = close[T]/close[T-20] − 1 降序取前 20
    T+1 开盘   这 20 只里 open[T+1] ≤ close[T] × 0.99 的才买（集合竞价成交）
    T+1 收盘   卖出

研究口径实测 8.71 只/日、316 日、2,752 只-日。把"低开才买"当可选项、直接买满 20 只，
是**未经检验的策略**——研究里那 20 只的横截面均值不是这个 cell 的收益。

## 2. 口径锚（改代码必须让这三条同时命中）

| 锚 | 值 | 出处 |
|---|---|---|
| cohort 只-日 | 2,752 | `_diag_l1_vwap_entry_result.json` |
| 信号日 | 316 | 同上 |
| open→close 日等权 | 121.49bp | `_diag_l1_annualize_result.json`（写 121.5） |

**成员换了而收益照旧**（或反过来）——两种都不是同一个策略。

`test_cohort_identical_to_research_function` 进一步与
`analysis/_diag_l1_vwap_curvature.py::build_cohort()` 逐位比较集合。

## 3. 三个数值决定，别在别处重新解释

**入场价是唯一绑住这个策略的东西。** 同一批 cell：开盘入场 121.5bp，全日 VWAP 入场
6.4bp（扣 20bp 成本后 −13.6bp）。edge 全在 open→VWAP 这一段路上。所以：

- `fill_mode="open_only"`：开盘高于限价就当日不成交，**不许盘中补票**。
  盘中跌到限价的是"高开走弱"那批，方向相反。
- `horizon_sessions=0`：结算里 `exit_i = entry_i + horizon`，0 表示入场日收盘出场。
  写成 1 就成了持有一夜，收益口径完全不同。
- 挂单价用**原始价** `raw_close × 0.99` 并**向下取整到 0.01**（`_tick_floor`），
  不许四舍五入。开盘价本身是 0.01 的整数倍，向下取整不改变「gap ≤ −1%」的判定；
  四舍五入会在半个价位上把限价抬高一分，把 gap = −0.997% 的票也买进来——那不是这个
  策略的 cell。实测 80 个交易日多买 11 只（744 个 cell 的 1.5%），平均 −145bp，
  同期 cohort +120bp。方向单边、完全静默。
- 用复权价挂单不会报错，只会在除权前后买在错价位。

## 4. 每日流程

```bash
# 15:05 后，收盘数据定版
curl 'http://localhost:3018/api/decision/l1/candidates?as_of=2026-11-11'

# 次日 9:20–9:25：按 candidates[].limit_price 挂限价买单
#             （集合竞价单一价撮合，挂高于限价的价格会以开盘价成交）

# 次日 15:05 后结算（open_only 判定 + 当日收盘出场）
curl -X POST 'http://localhost:3018/api/decision/settle'
```

建卡走既有 `POST /api/decision/cards`，传
`{"as_of": "...", "strategy_id": "l1_gap_reversal", "horizon_sessions": 0,
"fill_mode": "open_only", "picks": [...]}`。`picks[].p_win` 必须显式给
（`auto_pwin` 在账本没有历史时会 409，这是失败关闭，不是 bug）。

## 5. 已知未验证项（按重要性）

1. **θ = 能否在集合竞价拿到开盘价。** 本地无 09:25 委托簿快照，测不出。
   容量侧的口径 2026-11-12 已作废一次，见下面的更正：真正未知的是**成交价**，
   不是成交量。
2. **除权日。** `raw_close × 0.99` 与复权阈值在除权日不等价（冻结窗口内 4 个
   cell，3 例是真除权、1 例是 `open == close×0.99` 的浮点边界）。实盘应以行情源
   "前收"（已是除权参考价）为准；本模块不做静默修正，但两条腿的差异已由
   `test_fill_set_census_has_no_unregistered_divergence` 逐类登记。
3. **k\* 不可辨。** 打平所需参与率只有区间 45.1–81.3（`identified=false`），
   19bp 只有 1.44σ。所以它是"未被证否"，不是"已证实"。

### 5.1 更正（2026-11-12）：π\* 曾是 7.98%，真值是 67.7%

`analysis/_diag_l1_open_depth.py::book_budget` 里写的是

```
π* = 建仓额 × r* / (日均只数 × bar0 成交额中位)
```

`r* = (cost 20.00bp − vwap 6.43bp) / gap 115.05bp = 0.1179` 是**收益口径**的
比例（成本吃掉多少缺口 alpha），把它乘进「份额」里没有量纲依据。去掉它：

| 建仓额 | 单票/只 | 需要吃掉的 bar0 份额（中位流动性） |
|---|---|---|
| 1,000 万 | 115 万 | 1.4% |
| 2,000 万 | 230 万 | 2.7% |
| 5,000 万 | 574 万 | 6.8% |
| 1 亿 | 1,148 万 | 13.5% |
| 5 亿 | 5,739 万 | **67.7%**（原写 7.98%） |

同理 10% 参与率能撑的日建仓额是 `8.709 × 10% × 0.848亿 = 0.74 亿`（按日合计中位
是 1.05 亿），不是 6.26 亿 —— 6.26 = 0.74 / 0.1179，同一个 r\* 抬了 8.5 倍。
`R-D4_unit_ok`（`0.01 < r* < 0.5`）之所以放行，是因为 r\* 确实合法地落在这个
区间里：守的是「r\* 像不像比例」，没守「r\* 该不该出现在这个式子里」。

**含义**：0.74 亿是**每票各自按 10% 满配**的加总，不是「一笔钱怎么分配」。一旦要求同一笔
资金按同一规则分到当日 cohort，约束就落在最薄那条腿：11-12 实测 9 只的等额上界只有
**262 万**、按昨额加权（α=1）**627 万**、80% 达标门（q20）**582.9 万**。所以「容量是
千万级」只在「每票都满配」的想象里成立；**可实施容量是百万级**——5 亿这一档不是
「深度有余量」，是「物理上装不进去」。这两个口径不许并排引用（同 §6）。

### 5.2 生存偏差：已量化，方向与直觉相反（2026-11-15）

分母只有活到今天的标的：`kline_daily_enriched` 5,580 只，`instruments` 5,889 只，
缺的 **312 只全是退市股** —— 254 只名字带「退市 / ST」，另 58 只是**吸收合并 / 换股**
退市（600102 莱钢股份、600068 葛洲坝、600991 广汽长丰…，名字正常）。各源对它们
返回空（`sina` 直接丢弃、`fuyao` 无历史）——补不回来。所以问题不是「补」，是
**这个缺口能不能推翻 96.02bp**。

三层读数（`analysis/_diag_l1_survivorship.py --write`）：

| 层 | 读数 |
|---|---|
| 缺口率 | 全样本存活 **94.70%**；2005 年在市池缺 **14.2%** → 2026 年 **5.2%** |
| 归零门槛 | w=9% 时缺失票必须平均 **−935bp/日（−9.35%）** 才能把 92.5bp 打到 0 |
| 顶部代理 | 「之后 60 日跌 >30%」的顶部样本（n=65,617）当日 open→close **+438bp**，负收益仅 **9.3%** |

**结论：生存偏差不是高估。** 缺口票要么进不了 cohort（下跌段 mom20 极负，
进不了前 20），要么进来时正处在最强势的一天。−9.35%/日 超过主板跌停下限
（−10%），且要求连续跌停，与「只买 mom20 前 20」直接互斥。

逐分位修正（w=9%，缺失票落在哪一格）：

| 缺失票收益 | 修正后 |
|---|---|
| 与幸存票同分布 | +92.5bp |
| p50（+17.5） | +85.8bp |
| p25（−273.8） | +59.5bp |
| p10（−563.5） | +33.5bp |
| p5（−716.8） | +19.7bp |
| p1（−948.9） | −1.2bp |

**仍不可排除的一条**：退市股若在上涨段也系统性**跑输**幸存股（而不是更极端），
这个代理测不出来——它需要退市股的历史行情，本仓没有。这是目前唯一能把
96.02bp 推翻的路径，但它要求「退市股在 mom20 前 20 里表现更差」，与
「退市前炒作更凶」的常见路径相反。

## 6. go/no-go
30 个交易日里能判的只有**运营**，判不了盈利：日收益 sd = 340.7bp（337 日），
效应 122bp ⇒ 30 天 80% 功效的 MDE = **174bp**，真实效应打平也要 61 个交易日。
所以门分两类，任一不过就关线：

**运营门（30 日内可判）**

- 成交价 = 当日 `raw_open` 的精确率 = 100%（成交价与开盘价逐分对上）；
- **最薄那条腿**的参与率 ≤ 10%：分母必须是**当日竞价成交额**，不是 bar0，也不是组合平均。
  11-12 实测 9 只成交票：Σ竞价额 1.54 亿、最薄腿 688286 291 万 ⇒ 单票 10% = 29 万、
  9 只合计 **262 万**。实盘 **988.0 万**（9 只、109.8 万/票）= 上界的 **3.77×**、
  最薄腿 π = **37.7%**。别写「等额 100 万/票 34.4%」——那是假设 900 万，与实盘并排
  会让人以为今天只破了 3.4 倍。
  原「2,000 万 → 5.2%、5,000 万 → 13.1%」用 bar0 做分母（bar0 约为竞价额的 3 倍）、
  且最薄腿取的是 300949（bar0 1,563 万），两处都偏乐观；换竞价分母后 2,000 万
  在 9 只上等额分（222 万/票）是 **76%**——这是一道会放行 15× 违规的门。
- **80% 达标门**（可投规模 = `T_max` 的 20% 分位，**不是 p50**）：α=1 只到 **582.9 万**、
  α=1.5 到 622.5 万；1,000 万在 α=1 下 53.8%、988 万 54.9% ⇒ **今日规模在验收门下
  不可行**。p50（1,055.7 万）与 p20（582.9 万）差 1.8 倍，两个数不许并排引用。
  权重口径 `w ∝ 昨额^α` 与容量前沿见 `analysis/_diag_l1_weight_frontier_result.json`
  （单 κ 口径会把容量高估 2.79×，那是「中位票」容量，不是「每票都过」容量；
  α=0→1 的容量倍数同口径是 **2.59×**，不是 5.25×）；
- **规模轴不改变 α 的排序。** 六条 α 曲线在「可投规模 × 达标率」平面上**互不相交**
  （扫描 0.1%–99.9% 达标域、5 万步长），α 越大一阶占优（相邻档最小优势 −0.016pp @
  225 万，落在 128k 重抽样的 SE 0.039pp 之内）。所以不存在「规模过了某个点就该换 α」
  的切换门槛；真正的取舍在 **IR × 容量**的帕累托前沿上：α=0→1 换 2.59× 容量、付
  0.785 点 IR，α=1→1.5 再换 1.17×、再付 0.434 点。首版的「α=1 是上界」不是观测到的
  拐点，是**单 κ 口径**下排序掉头的产物（那里 α=1 的 T_max 2,949.6 万 > α=1.5 的
  2,263.6 万；实测口径反过来 1,055.7 vs 1,232.9 万）；
- 漏单率（该成交未成交）与次日分区可用率（`entry_date != None`）。

**盈利：报滚动 CI，不设二元门**

60 / 120 / 242 日的**同日配对超额**（filled − 同日同名单 unfilled；全样本
+84.2bp、sd 316.5bp、IR 4.10）。30 天只有 t = 1.96（假设效应不衰减），
不构成判据；写「t < 2 就关线」等于用一个设计上不可能通过的检验代替判断。

在此之前，**任何一次放大都是把未验证假设当成已验证**。
