## 1. 原理论的三个结构性错误

### 1.1 宽度是二阶矩，理论漏了一阶矩

原文全体论证只用一个量：分布有多宽。但供给曲线的形状不由宽度决定，由**当前价与分布重心的相对位置**决定。

反例是自明的：一只股票全部持仓成本挤在 10.00 元（宽度≈0）。现价 10.00 时，任何想买的人都能立刻找到卖家——供给曲线是**水平**的。现价 12.00 时，所有持仓浮盈 20%，供给才可能变陡。同一个宽度，供给弹性相反。

宽度答「成本有多散」，位置答「散在现价上方还是下方」。**理论缺的不是数据，是第二个状态变量。**

实测印证：单变量宽度在样本外是倒 U（Q1 −11.2bp、Q3 +30.3bp、Q5 −37.0bp），最窄的一档并不最好。因为最窄里混着两类完全相反的状态——「窄且在现价」和「窄且在现价下方」。

### 1.2 涨停坍缩的是流量，不是存量

原文说涨停是「唯一能在一天内把熵压成零的机制」「成本坍缩器」。这在物理上不成立。

涨停封板压低的是**当日新增成交的价格方差**。存量持仓的成本一分未动——昨天 15 元买入的人，今天涨停到 17 元，他的成本还是 15 元。所以涨停坍缩的是**流量分布**，不是**存量分布**。

后果比原文的「坍缩态解除」更严重：**坍缩态从来就不存在**，存在的只是「当日无法成交」。一旦打开，存量筹码的分布原封不动地回来了，它不是「扩散」，是**从未收窄过**。

这条修正解释了原文自己观察到的现象，而且给出一个原文给不出的量：**打开日的抛压 = 封板期间累积的、未被消化的存量**，不是当日成交量。封板 N 天，抛压随 N 单调增，与当日换手无关。

### 1.3 「浮盈的人不卖」方向反了

原文：「任何一点新增买盘，都让几乎全部持仓同时翻红，而浮盈的人不卖。」

这是全篇最硬的经验假设，也是**唯一一个与既有实证方向相反的**。处置效应（Shefrin–Statman）说：投资者在盈利时卖出意愿上升，在亏损时下降。A 股的 T+1 与涨跌停制度进一步放大它——浮盈是唯一能当天兑现的收益。

若这条反了，整个「窄分布 → 供给垂直」的推论就反了：窄分布 + 浮盈 = **所有人同时进入盈利区 = 卖压同步到达峰值**。供给曲线在成本带上方是**水平**的，不是垂直的。

数据站在处置效应这边：`dens`（现价附近筹码密度）的 Q1（现价上方无筹码）只有 +34.5bp，而 Q5（现价附近筹码密集）是 −102.3bp。**「上方没筹码」并没有带来大涨，只是没有大跌。**

## 2. 升级：从「熵」到「势」

熵是对称的、标量的、无方向的。真实的东西是不对称的、函数的、有方向的。所以这个名字本身是错的。

**正确的对象是一个势场 S(p)**：

```
S(p) = Σ_{t=T-N}^{T}  turnover_t · K( (p − vwap_t) / (ivd_t · p) )
```

- 权重 = 当日换手率（**可观测**，不需要衰减核）
- 核宽 = 当日成交价离散度 ivd（**可观测**，从 5min 直接算）
- S(p) 读作：「价格 p 附近，过去 N 日有多少筹码换过手」

这是原文那句「三个已知量解不出四个未知数」的解法。不是找到了第四个方程，是**换了未知数**：不问「存量分布是什么」（不可识别），问「现价附近的可交易筹码有多少」（可识别，因为分子分母都在 5min 里）。

势场给出三个可测的派生量：

| 量 | 定义 | 读法 |
|---|---|---|
| `ivd` | 当日成交价加权标准差 / vwap | 二阶：这一天成本带多宽 |
| `dv` | vwap / close − 1 | 一阶：换手发生在收盘价的上方还是下方 |
| `dens` | S(close)，N=15 | 势值：现价附近有多少筹码 |

三个量两两相关都在 0.17–0.29，**不是同一个东西**（§3.2）。

在这个框架下，原文那几个现象全部落地，且不再自相矛盾：

| 现象 | 势场解释 |
|---|---|
| 涨停打开即死 | 井外势场未变。价格离开井，沿存量势场回落 |
| 温和 ramp 好、强 ramp 差 | 温和 ramp 整体抬升势场（新井在更高处）；强 ramp 把价格抛进真空区（无井） |
| 锁仓横盘无超额 | 势场没变，粒子没动。没有外力时「不动」不产生任何可交易信息 |
| 席位接力无用 | 搬运工的名字不改变势场形状 |
| 换手越强 20 日越差 | 高换手把势场抹平（分布变宽），势阱变浅，任何方向都更容易走 |

**换手不是熵增率。** 两个成本相同的持有人之间换手，分布一点没变。换手是否增熵，取决于它发生在什么价位——这就是 `dv`。同样 3% 换手，低位换手削右尾（降熵），高位换手拉右尾（增熵）。原文缺的正是这个符号。

## 3. 实测

### 3.1 口径

- 5min 面板两段：baostock 段 2020-01~2024-10（抽样 900 只，903,578 股票-日）与本地段 2024-11~2026-10（**全市场** 5,573 只，2,481,999 股票-日）。两段无重叠日（`minute_union.SPLIT`）。
- 宽度给出**区间**而非点估计：`ivd_lo`（bar 内视为点，下界）与 `ivd_hi`（bar 内均匀，上界）。真值被夹在中间，结论必须在两端同向才算稳健。实测两端几乎一致（−68.2 vs −71.3bp），**结论不依赖 bar 内形状假设**。
- fwd20 = `close[didx+21] / open[didx+1] − 1`；超额 = 减当日池内等权均值。
- 剔除当日 |ret1| > 9.5%（封板使 ivd 机械趋零，会把制度读成熵）；剔除上市 < 250 日；按日聚合求 t。

### 3.2 宽度有没有独立信息

`corr(ivd_lo, amp) = 0.841`。所以 ivd 有 29% 的独立方差，不高但也不是重命名。

| 检验 | 样本内 | 样本外 |
|---|---|---|
| ivd 五分位 Q1 / Q3 / Q5 | +23.7 / +16.4 / **−68.2** (t −9.15) | −11.2 / +30.3 / **−37.0** (t −2.33) |
| 换手最高组内：ivd 低 vs 高 | +61.9bp (t 3.88) | +14.0bp (t 0.66) |
| 量比最高组内：ivd 低 vs 高 | +82.5bp (t 5.83) | +20.3bp (t 0.91) |
| 高振幅组内：ivd 低 vs 高 | +18.9bp (t 0.48) | −34.7bp (t −0.59) |

**读法**：宽度唯一稳定的是「宽 → 差」（Q5 两期都负且显著）。「窄 → 好」只出现在样本内，且只在特定分组里，OOS 全部归零。**它是一个排除器，不是一个买点。** 这与本项目此前所有结论（surge-all、锁仓、席位）同构。

### 3.3 势值 dens 是唯一活过 OOS 的量

`dens` = 过去 15 日换手加权、落在今日收盘价 ±2·ivd 内的成交密度。

| | Q1（上方无筹码） | Q3 | Q5（筹码密集） | Q1−Q5 | t |
|---|---|---|---|---|---|
| 样本内（含次新） | +45.4 | +19.4 | −91.1 | +136.5 | — |
| 样本外（含次新） | +34.5 | +34.3 | −102.3 | +136.8 | — |
| 剔次新 · 样本内 | | | | **+123.7** | 9.26 |
| 剔次新 · 样本外 | | | | **+132.5** | 4.60 |

控制变量后仍在：控制 ret1 → +250/+72/+233（样本内）、+189/+50/+276（OOS）；控制 ivd → +30/+263、+43/+344；控制 ret20 → +64/+102/+208、+114/+122/+242。

**它不是任何已知量的重命名**：`corr(dens, ret1) = 0.09`、`corr(dens, ivd) = 0.17~0.23`、`corr(dens, pos20) = −0.15 / +0.06`（两期符号还反了，说明二者确实不同）。

**但它在衰减，而且大票无效**：

```
分年 Q1−Q5(bp)：2020 +252 | 2021 +108 | 2022 +162 | 2023 +56 | 2024 +24 | 2025 +16 | 2026 +240
市值分层（OOS）：小 +179 (t 11.6) | 中 +197 (t 7.3) | 大 +41 (t 0.84)
```

三年连续衰减（2023/2024/2025 几乎为零）后 2026 反弹——这是「效应在被套利」或「由特定 regime 驱动」的典型形状，不是稳定 alpha。**不能部署，只能当状态变量。**（大市值组无效这一点与容量结论一致：cap Q5 的 +41bp/t0.84 是拒绝部署的直接理由。）

### 3.4 大宗折价率不是熵的标价

`block-trade-source.md` 把大宗让价认作「唯一把熵标了价的地方」。三项检验都不是这个结论：

| 检验 | 读数 | 判读 |
|---|---|---|
| 折价率与事前 20 日振幅 | Spearman **0.065** | 与「宽度」几乎无关 |
| 折价率与事前 20 日换手 | Spearman **0.033** | 同上 |
| 同股票同日、不同类型买方 | within R² **0.034**（buyer_inst +33.5bp t4.49、seller_inst +116.5bp t9.87） | 身份只解释 3.4% |
| 方差分解（date×symbol 组内/组间） | 组内仅占 **9.4%** | 折价是**股票-日属性**，不是单笔议价 |

组内只占 9.4% 这一条推翻了「折价 = 单笔谈判结果」的直觉：它是股票-日层面的状态。但那个状态**不是宽度**（相关 0.065）。剩下的候选是减持压力、流动性补偿、大宗市场供需失衡——都可以检验，但都不是熵。

**这一刀已经落下了。** 原文说「大宗折价率与后续 20 日超额无关——这是最便宜的一刀，一个数据源就能试」。数据源已经拿到，第一项检验的答案是：它连「熵」这一侧都没对上。

## 4. 理论的天花板：它只描述供给侧

这是整套东西最深的限制，原文没有意识到。

「所有持仓成本挤在同一档 → 上方供给垂直 → 任何新增买盘都推高价格」——**这一步不成立**。

供给垂直只意味着**价格不容易下跌**，不意味着**会上涨**。价格需要买卖两侧。没有卖盘，也没有买盘，价格不动。原文把「无卖压」直接等同于「上涨」，这是把必要条件当成了充分条件。

数据完全符合这个修正：
- Q5（供给充足）→ **−102bp**，稳定显著
- Q1（供给稀缺）→ **+34bp**，微弱、OOS 不稳

**不对称。** 稀缺性只买保险，不买收益。所以这套理论的正确用途是**风险管理**（识别「谁会跌」），不是**收益预测**（识别「谁会涨」）。

任何声称从筹码结构推出「超级龙头」的说法，都必须额外补一个需求侧的方程——而那一侧原文一个字都没有。

## 5. 还活着的三个可证伪预测

### 5.1 涨停打开日的抛压由封板期累积决定，不由当日量决定

由 §1.2 直接推出。若「坍缩态」为真，打开日应**缩量**续涨（无卖盘）；若「流量坍缩」为真，打开日应**放量**下杀，且下杀幅度随封板天数 N 单调增。

判别指标：`open_day_pressure = Σ_{封板期} turnover × I(成交价 ≥ 打开日开盘价)`。
预测：与打开后 5 日收益负相关，t ≥ 2，且控制打开日换手后仍显著。
这是**唯一能分开两个机制的检验**，5min 数据完全够。

### 5.2 大宗折价的时间尺度反向

已在 `block-trade-source.md` §8 预注册，尚未执行。二十日与一百二十日符号相反 ⇒ 两个机制（筹码位置 + 锁定期补偿）都在；同号 ⇒ 只剩一个。

### 5.3 势场的非对称性

若「势」比「熵」对，则**上方势垒与下方势阱的预测力不对称**：`S(close × 1.1)`（上方筹码）应比 `S(close × 0.9)`（下方筹码）更强地预测下跌，而反向不成立。
这条能把「标量熵」与「函数势」分开——熵对一个分布只有一个数，无法产生上下不对称。

## 7. 这套东西现在的地位

原文自评：「它与你的直觉逐条吻合，能吸收你全部的反证，并且在现有观测系统里没有对应的投影。」

前半句是对的，后半句不成立。**投影存在**，而且已经在手上了：5min 的价格-成交量联合分布不是日频信息的重排，它是另一个信息集。把它压成 ivd / dv / dens 三个数之后：

- 一个死了（高换手 × 窄带，OOS 归零）
- 一个活了但衰减（dens，大票无效）
- 一个不成立（大宗折价不是熵的标价）

这不是「免死金牌」，是三块墓碑和一块还在动的表。

**理论的价值不在于能解释多少失败，而在于它敢在哪一格押注然后输掉。** 原文能吸收全部反证——那是它的弱点，不是优点。一个能吸收一切的模型等价于零信息。现在它至少有了一个会说「不」的地方。
