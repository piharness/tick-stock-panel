## 0. 一句话

**别再找「替代注意力的因子」——注意力从来不是独立因子（正交化后归零，是「市值+换手率+流动性」的复合代理）。真正该做的是：枚举 A 股结构里每一类「被迫交易方」，系统性做它的耐心无约束对手方，并给每条腿配「半衰期 + 衰减监控 + 预注册退役阈值」。你的 moat 不是信号，是约束集比对手空。**

## 1. 你原本实际在要求什么

「注意力定价失效后，找一个新因子替代它，并证明我比别人更该赚这笔钱」——一个「换因子」请求，附带「凭什么是我」的自我合法性焦虑。

## 2. 最重要的认知局限与未经验证假设

1. 假设注意力曾经是独立因子 —— 实为复合代理（见 `docs/attention-change-consensus-ortho.md`）。
2. 假设结构变化本身可当信号交易 —— 它是事件不是现金流。
3. 假设「更早/更快/更便宜」是对手排序的正确坐标 —— 正确坐标是**约束集**。
4. 假设优势是「算出来的」—— 其实由你的约束集先天决定。
5. **未验证的核心命题：你看到的每处错位，是否通过了你自己的四层淘汰链**（此前没有一条 edge 做过这个检验，本目录补上）。

## 3. 升级后的真正目标

建一个「被迫交易方账本」（谁、何时、为什么非交易不可），做它的耐心无约束对手方；把优势做成**承保组合**（每条腿 = 一张保单：保费 / 尾部损失 / 容量 / 相关性），而不是一个会过期的信号。

## 4. 深度升级：数据 / 工具 / 方法

- **数据（从代理到因果）**：注意力正交化归零已经指明方向——直接测**流**。已落地：龙虎榜席位（`data/dragon_tiger`）、ETF（`backfill_20261117/etf_daily_full.parquet`）、指数（`index_daily_full.parquet`）、退市缺口股（`stock_gap_daily.parquet`）、时点持股（`data/shareholder`）。缺口：更长的龙虎榜历史、北向/两融持仓（付费）。
- **工具**：`delisting_guard`、`market_context`、实验室/守护层/决策账本、walk-forward 已具备。缺：**「被迫交易日历」**（把账本里每类被迫流做成带日期的可回放表）。
- **方法**：IC/IR + 分层 + walk-forward（`quant-factor-research`），补两条——**成本与容量同时入模**、**对抗性对手测试**（第 6 项）。

## 5. 广度升级：其他学科与方法

| 学科 | 迁移过来的方法 | 用在哪 |
|---|---|---|
| 做市商库存理论 | 被迫流→瞬时错位→耐心反转 | 你就是被迫流的流动性提供者 |
| 保险精算 | 承保账簿（保费/尾部/容量/不卖拿不到到期的） | silent +606bp 本质是流动性保费 |
| 产业组织（Porter） | 护城河=对竞争者的约束，不是技能优越 | 「凭什么是我」的正式回答 |
| 生态学（竞争排斥） | 不抢同一份 alpha，占捕食者进不去的 niche | 慢/小/丑/容量 = 你的生态位 |
| 认识论（Popper） | 下注前写死成功判据与杀死阈值 | 可证伪验证 |

## 6. 更强的任务定义

每条候选腿，下单前强制过 `analysis/_diag_moat_filter.py` 的四层淘汰链 + 对抗性总闸：
> 若一只 5000 万规模的量化基金能用公开数据廉价算出该信号并更低成本执行 → 跳过，它不是你的。

**当前判定结果（`analysis/_diag_moat_filter_findings.md`）：**
- **silent 流动性承保暴露** = 唯一四层全过（慢+小+丑+容量小），结构性只归你，但 regime 敏感、2026 已失效 → 必须外挂条件门。
- **L1 跳空反转** = 慢 + 容量受限，归你但半衰期短（量价公开）。
- **T+2 日内腿** = 速度层淘汰（日内回合 T+1 不可执行），已正确作废。
- **龙虎榜 / 涨停点火** = 容量 + 舒适层淘汰，归机构/被动。

## 7. 可证伪、可量化的验收标准

1. 每条腿**预注册**一个样本外（walk-forward）的、真实成交成本下的期望值 + 退役阈值（如滚动 120 日 t<2 或超额转负连续 N 日即退役），退役在真实成交上判定，不回测自证。
2. 组合按**承保账簿**记账：保费、尾部（MAE/p1）、容量、腿间相关性；容量超限自动缩量而非加仓。
3. 反向证据同等采集：任何错位段若在**未过四层前**就被更快/更大/更便宜的钱吃掉，记「剩余价值为零」，计入退役统计。
4. 判决用真实成交，`n_eff` 达标才下结论（既有纪律：n_eff<30 ⇒ 结论不可判定）。

## 8. 顶级团队会怎么做

① 流归因引擎（每天每票的价格变动分解到零售/机构/量化/被动流，取代注意力代理）；② 被迫交易方账本+日历（本目录第一份）；③ 半衰期与容量模型（连续估计衰减与可部署规模）；④ 真实成交纸上交易 + 预注册杀死阈值 + 独立退役复盘。已具备 ③④ 骨架（实验室/守护层/决策账本），缺 ①②。
