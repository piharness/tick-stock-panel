# 预注册：救助可达性 → 贴线反弹（P2 · 2026-11-27）

> 状态：**草案，写于跑数之前**。判据冻结后才允许看分组结果；看完全样本后不得改判据。
> 上游：`chip-ap.md` §7–§8（H11 修正为 «越贴线越反弹»，near−far +525bp / t 7.47）。
> 实现点：`analysis/_diag_chip_p2_rescue.py` → `data/.scratch/leverage/p2_rescue.json`

## 1. 问题

修正后，质押贴线的符号是**正**的：股价越接近平仓线，未来 60 日反弹越强。有两种解释：

- **救助读法（H1）**：贴线意味着控制权质押进入「要么补仓、要么违约」的窄解空间；
  A 股的解除方式以救助/展期/重组为主，救助可达性越高，救援期权越值钱 → 反弹越强。
- **超跌读法（H0）**：贴线只是「跌得多」，A 股边际持有人抄底 → 反弹；与救助无关，
  小市值、高波动的民企应该反弹更强（或两组无差异）。

两个读法对**组间差异的符号**预测相反，所以这是一次可判别的检验，不是又一次「找显著」。

## 2. 分组

用十大流通股东的**第一大股东**（最新一期，2024-12 ~ 2026-09）做产权代理：

- **国资（soe）**：第一大股东名称命中国资/财政/国务院/央企集团/地方城投等关键词。
- **民企（person）**：第一大股东是自然人（`is_org = 0`）。
- **其它**：结算/证金/汇金/基金/保险/信托/外资/无法识别 → 剔除。

选择「国资法人 vs 自然人」而不是「国资 vs 全部非国资」，是为了避开「民营集团/外资/无实控」
这团混合物；代价是样本变小、把「民营集团控股」排除在外。

## 3. 信号与判据

信号（冻结）：`drift_c = 公告日复权收盘 / 质押起始日复权收盘 − 1`；`ratio_c = 折算 / (1 + drift_c)`。
月内按 `drift_c` 做 rank 三分位：Q0 = 跌得最深，Q2 = 涨得最多。

| # | 判据 | 阈值 |
|---|---|---|
| 主 | 组内 `spread = mean(f60[Q2]) − mean(f60[Q0])`；组间差 `Δ = spread_soe − spread_person` | **Δ < 0**（国资更负 = 深跌反弹更强）且 NW t **≤ −2** |
| 次 | 月截面 `f60 ~ z(drift_c) × soe + z(drift_c) + soe + 控制`，交互项 | **< 0** 且 t **≤ −2** |
| 稳 | 控制 size / vol20 / turn20 / D / ret60 / ret250 后，交互项同号 | 同上 |
| 同质 | 在 size 三分位内重做组间差 | 至少两层的 Δ 同号 |
| 反向 | 若 `Δ > 0`（民企更强） | 救助解释**死**，回到超跌 |

控制：换手、波动、规模、久期、事件前 20/60/250 日动量；月聚簇后 Newey-West（lag 6）。

## 4. 杀死

1. `Δ ≥ 0` 或 |t| < 2 → 救助解释没有证据，符号只是超跌。
2. 加控制后交互项翻正 → 组间差是规模/波动的代理。
3. size 三分位内 Δ 全部反号 → 不是产权，是市值。
4. 国资组内「央企 vs 地方国企」无差异、且两组都强 → 不是「救助渠道」，是「国资」这个标签本身
   （下一轮再拆，不在本预注册的判据内）。

## 5. 局限（诚实标注）

1. 产权用 2024–2026 的第一大流通股东代理，历史事件（2020–2024）存在错分；控制权变更的样本会错。
2. 第一大流通股东 ≠ 实控人；国资集团旗下上市公司、无实控人公司会被错分。
3. 「民企」只取自然人第一大股东，排除了民营集团控股，样本不等于全部民企。
4. 国资与民企在规模、波动、行业上系统性不同；size 分层只能部分消除。
5. 全部为探索性：H11/H12 已看过全样本，本检验不是样本外。

## 6. 结果（2026-11-27，跑数后追加）

实现点：`analysis/_diag_chip_p2_rescue.py` → `p2_rescue.json`。产权 = 第一大流通股东（2024–2026 最新一期）。

| 层 | 国资 | 民企 | Δ = 国资 − 民企 |
|---|---|---|---|
| 质押事件 · f60 spread（Q2−Q0） | **+588.1**（268 事件 / 43 只 / 11 月，t 2.78） | **−633.0**（6,308 / 697 / 80 月，t −5.81） | **+1,269.3 / t 5.27** |
| 存量簿 · wdist Q5−Q1 | +447.2（1,882 行 / 46 只，t 2.10） | +176.1（34,915 / 731，t 1.37） | +271.2 / t 1.05 |
| 全市场 · ret60 交互 | — | — | −23.2 / t −0.57 |

**裁决：主判据未过（Δ > 0）。按预注册字面，H1 不被支持。**

但这是一个**选不到样本**的失败，不是证伪：

1. 国资质押事件只占 2.1%（268 / 20,280），43 只；80 个月里只有 11 个月有 ≥6 个国资质押事件。
   事件层的 spread 是在每月 2–3 个事件的桶上做三分位，池化后 deep +303.5 / shallow +346.7（差 −43bp）
   ——「方向相反」是小组噪声，不可读。
2. 这 43 只是「国资里仍要质押」的选择样本：万科（深铁）、云铝（中铝）、大华（中国移动）、
   昆药/天士力（华润）……多数是混合所有制，不是典型的地方融资平台。
3. 存量簿层（不要求事件、只要求有活合约）样本大 7 倍，方向与 H1 一致（+447 vs +176），但 Δ 的 t 只有 1.05。
4. 全市场 ret60 没有可调制的反转（−23 / t −0.57），说明「超跌反弹」本身在 60 日尺度上不存在，
   贴线反弹不是「跌得多」的同义词。

**结论：不可识别。** 质押渠道本身是民企渠道——能救助的公司很少质押（它们不需要用股权换钱），
所以「救助可达性」在质押样本里被选择掉了。要检验 H1，必须换数据：国资入股、纾困基金、重组预案
——那些才是「救助」本身，而不是「谁在质押」。

**不改判据**：本预注册到此关闭，不因样本薄而放宽阈值。下一版另写。
