## 0. 一句话

**旧理论问「现价附近有多少筹码」，新理论问「这些筹码由谁持有、还能持有久、跌了会不会被迫卖、谁会被一起拖下水」。**

- 密度只回答「有多少」。
- **久期**回答「还能拿多久」。
- **伽马**回答「跌了会不会被迫卖」。
- **网络**回答「谁会被一起拖下水」。

旧页的结论没有错，错的是**对象**：它把「筹码」当成了价格上的一个标量场，于是把「谁持有、持有多久、带着什么约束」全部边际掉了。边际掉之后，剩下的唯一维度就是换手率——所以它必然退化成换手率的影子。这不是模型没调好，是**投影选错了**。

# 第一部分 · 九项升级

## 1. 我原来实际上在要求什么

表面上：把 `/chip` 页面的理论写得更高、更广、更深。

实际上：**给这个页面一个值得单独成页的对象。**

现在的 `/chip` 是一份**验尸报告**：它精确地记录了「势场死了、介质是换手率的影子、信号关闭」。它有价值，但它是**否定性**的——它告诉你什么不是，没有告诉你**下一个对象是什么**。所以页面只能以「三个描述，零个信号」收尾。

你真正要的不是「换一个更漂亮的隐喻」，而是**一个能解释旧理论为什么失败、并且能预测旧理论预测不了的东西**的理论。换句话说：

> **不是把旧故事讲得更大，而是换一个旧故事没有的对象。**

## 2. 最重要的认知局限与未经验证的假设

| # | 被默认成立的假设 | 为什么可疑 | 代价 |
|---|---|---|---|
| 1 | **筹码 = 成本分布** | 这是一个**统计摘要**，不是自然种类。它把持有人、持有期、资金约束全部边际掉了。 | 密度必然与换手率同义；形状必然没有独立信息。 |
| 2 | **价格被成本重心吸引** | 这是**均衡物理**的假设。负控已经杀了它（−0.125 vs 随机游走 −0.107），但理论保留了「场」的对象，只把名字换成「介质」。 | 一个被否证的本体，换名字救不回来。 |
| 3 | **fwd20 超额是唯一值得预测的因变量** | 这是全页最大的未检验假设。筹码结构可能预测**波动、偏度、回撤、恢复时间、流动性、传染**，而不是均值。 | 用错误的因变量测一个真实的对象，结论必然是「没有信号」。 |
| 4 | **持有人是同质的、无约束的** | 没有微基础。相同的密度，在「杠杆短线客」和「险资长钱」手里，含义相反。 | 密度的符号不可识别；平均效应必然接近零。 |
| 5 | **换手率是筹码更新的唯一时钟** | 换手率是**总量**，它隐藏了「谁在换、为什么换」。同样 3% 换手，可能是散户互搏，也可能是机构建仓。 | 1/TO 只是一个均值，丢掉了期限结构的全部形状。 |
| 6 | **5min 价量是唯一的信息集** | 它看不见所有权、杠杆、委任约束、网络重叠。 | 把「持仓的政治经济学」压成了「价格的历史」。 |
| 7 | **理论必须用物理语言** | 物理是隐喻，不是机制。金融有自己的结构语言：久期、凸性、展期、挤兑、传染。 | 隐喻越漂亮，越容易吸收反证，越不像一个可下注的模型。 |

**最贵的一条是 3。** 旧页把「筹码密度 → fwd20」当作唯一战场，于是当 fwd20 归零时，它宣布整个对象关闭。但一个对象在**均值**上没有信息，不等于它在**尾部、路径、传染**上没有信息。银行不会因为「平均利率」预测不了危机，就宣布资产负债表没用。

## 3. 高度升级后的真正目标

**从「预测 20 日超额」升级为「绘制市场的久期—伽马—网络脆弱性地图」。**

具体说：

> **把股票看成一张每天都在重新融资的资产负债表。**
> - 流通盘是**负债**：必须有人持有。
> - 成本分布是**负债的期限结构**：哪些筹码是老钱，哪些是新钱。
> - 换手率是**展期速度**：每天有多少负债到期、被重新定价。
> - 价格是**当天的展期价格**：边际持有人愿意接受的融资条件。
> - 脆弱性是**期限错配**：短钱持有长故事，一旦展期条件收紧，就被迫折价卖出。

这个目标比「找一个新因子」高一层：它不问你「明天涨不涨」，它问**「这个市场的持仓结构有多脆、脆在哪里、谁会被迫先动」**。而后者恰好是本仓库 `verdict.md` 的核心命题——**做被迫交易方的耐心对手方**——的测量层。

### 3.1 本体论的换轴：从空间到时间

旧理论是一个**空间**理论：价格是位置，筹码是地形，势场是高度，密度是海拔。它问「现价附近有多少筹码」，本质上是问「这个位置的地形有多陡」。

新理论是一个**时间**理论：筹码是**等待被卖出的时间**，成本是**过去的时间**，久期是**未来的时间**，展期是**时间的交换**。它问「这些筹码还能等多久」，本质上是问「这个位置的持有人有多急」。

这个换轴不是修辞。它直接决定了三件事：

| | 空间理论（旧） | 时间理论（新） |
|---|---|---|
| 状态变量 | `S(p)`：价格上的密度 | `S(p,a)`：价格 × 年龄 |
| 核心参数 | 核宽、衰减窗 | 久期、hazard、展期速度 |
| 预测对象 | 价格往哪走 | 谁先被迫走、多快走、走了之后谁接 |
| 失败模式 | 密度=换手率 | 久期=换手率的另一个均值（必须用分布避免） |
| 数学 | 势场、梯度 | 生存分析、排队、期限结构 |

**旧页的「形状没有信息」只有在这个换轴之后才讲得通**：它测的是**价格上的形状**（峰高、曲率、偏度），而真正有信息的是**时间上的形状**（年龄分布、久期错配、年龄熵）。价格形状是空间投影，时间形状才是对象本身。

### 4.2 工具

- **生存分析**：离散时间 hazard、竞争风险、frailty（未观测异质性）。
- **人口学**：Lexis 图（年龄 × 日历时间）、队列生命表、Lee-Carter。
- **状态空间 / 隐马尔可夫**：从总量换手反推年龄分布与 hazard。
- **市场微观结构**：Kyle λ、Amihud、Hasbrouck VAR、订单流不平衡。
- **网络科学**：二分图投影、中心度、社群、ERGM、传染模拟。
- **衍生品**：供给曲线凸性 → 伽马；ETF/指数期权的 pinning 作外部校验。
- **控制论**：脉冲响应、传递函数、稳定性、滞回。
- **统计物理**：熵产生、临界慢化、相变检测。
- **信息论**：转移熵、MDL、压缩复杂度。
- **因果推断**：指数纳入/剔除、解禁、两融规则变化做准实验。
- **结构估计**：模拟矩估计、间接推断、贝叶斯分层。

### 4.3 方法

从**归因**转向**结构**：

| 旧方法 | 新方法 | 差别 |
|---|---|---|
| 横截面回归 `fwd20 ~ dens + controls` | 结构 hazard + 反事实供给曲线 | 从「相关」到「机制」 |
| 一次切一个控制变量 | 联合控制 + 匹配孪生 + 预注册分格 | 从「假存活」到「可识别」 |
| 单股票、单期 | 股票 × 持有人 × 时间的面板 + 网络 | 从「点」到「系统」 |
| 均值 | 偏度、回撤、恢复半衰期、尾部相关 | 从「方向」到「脆弱性」 |
| 日历 regime | 久期/伽马相图 | 从「牛熊」到「结构」 |

## 6. 一个更强的任务定义

> **不是给 `/chip` 换一个更漂亮的隐喻，而是把「筹码」重定义为持仓的期限结构，并回答四个问题：**
>
> 1. **谁持有？**（持有人类型、集中度、杠杆、委任）
> 2. **还能持有久？**（年龄分布、久期、年龄熵）
> 3. **跌了会不会被迫卖？**（供给曲线凸性、伽马符号）
> 4. **谁会被一起拖下水？**（所有权网络、共同持有人、传染）
>
> **理论的成败不看它解释了多少旧结论，而看它能否预测旧理论预测不了的东西：脆弱性、路径、传染、相变。**

这个定义有一个明确的**证伪边界**：如果四个问题里只有第 1、2 个有数据，第 3、4 个只能讲故事，那它就退回「描述层」，不配叫理论。所以下面的七个预测，每一个都必须绑定**可测量的代理**和**杀死条件**。

## 7. 可证伪、可量化的验收标准

> 阈值是**预注册起点**，不是真理；写死之后才能改，改要记录。所有 t 值按日聚合，重叠窗用 Newey-West 校正。

| # | 预测 | 数据 | 通过线 | 杀死条件 |
|---|---|---|---|---|
| **H1** | 久期错配 → 脆弱性，不是收益 | 日线 + 财务/行业周期代理 | 与下行偏度 \|ρ\| ≥ 0.15，t ≥ 2，OOS 同号；与 fwd20 均值 \|ρ\| < 0.05 | 与偏度无关，或与均值强相关（说明只是另一个收益因子） |
| **H2** | 伽马符号决定密度符号 | `top_float` + 换手 + 龙虎榜 + 大宗 | 密度 × 伽马的交互 ≥ 100bp，两组符号相反，\|t\| ≥ 2 | 交互为零，或两组同号 |
| **H3** | 进入方向决定吸收/崩塌 | 5min + 日线 | 四个格（上/下 × 快/慢）符号符合 2×2，极差 ≥ 80bp | 四格无结构，或方向与预测相反 |
| **H4** | 年龄熵 → 恢复半衰期 | 日线年龄递推 | 高熵组恢复快 ≥ 30%，控制 β/市值后仍成立 | 无差异，或熵只是规模的代理 |
| **H5** | 网络中心度 → 尾部传染 | `top_float` 二分图 | 下行相关每 +1sd ≥ +0.10，平均相关不变 | 只影响平均相关（说明只是 β） |
| **H6** | 记忆相变，不是线性衰减 | 2019-2026 全市场 | 阈值模型 BIC 优于线性 ≥ 10，OOS 分段同号 | 无阈值，或阈值只是牛熊日历 |
| **H7** | Θ 是滚续成本 → 脆弱性 | 5min + 日线 | 与下行偏度负相关，t ≥ 2；与 fwd20 无关 | 与 fwd20 强相关（说明旧 P2 只是没测对），或与偏度无关 |

**最低验收组合：H1 + H2 + H3。** 这三条分别对应「久期」「伽马」「路径」，是新理论相对旧理论的三根独立柱子。如果三条全灭，新理论只是一个更好听的隐喻；如果只活一条，它是「一个描述 + 两个猜想」；如果活两条以上，它值得一个页面和一条预注册研究线。

## 9. 当前条件下最值得立即执行的第一步

**不是跑 H1-H7，而是把新对象造出来。**

具体：写一个脚本 `analysis/_build_chip_age.py`，用日频换手 + 日频价格，对全市场 2019-2026 递推：

```
S_t(p, a) = (1 − TO_t) · S_{t−1}(p, a−1) + TO_t · K_t(p) · 1{a=0}
```

先不估 hazard，只输出四个描述量：

- `D_t`：筹码久期（年龄加权均值）
- `H_t`：年龄熵（期限结构的多样性）
- `q50/q80/q90`：年龄分位（多少筹码是「新钱」）
- `peak_t`：成本密集峰的高度与位置

**产出**：一张 `chip_age_panel.parquet` + 一张市场地图（久期 × 年龄熵 × 市值）。这一天不产生任何结论，只产生**一个旧理论没有的对象**。有了它，H1-H7 才有东西可测；没有它，所有讨论都还是在「密度」这个旧对象上打转。

# 第二部分 · 理论

## 10. 旧理论为什么必然退化

### 10.1 它把持有人边际掉了

旧对象可以写成：

```
S_t(p) = ∫∫ S_t(p, a, c) da dc
```

其中 `a` 是持有年龄，`c` 是持有人的约束（杠杆、久期、委任、集中度）。旧理论只保留 `p`，把 `a` 和 `c` 积分掉。

**积分掉 `a`**：所有筹码变成「同一时间尺度」的，唯一的时间信息是换手率 → `dens` 必然与 `TO` 同义。
**积分掉 `c`**：所有持有人变成「同质无约束」的，供给曲线的斜率只有一个符号 → 密度的效应必然是一个**平均**，正负相抵。

这就是为什么：

- 【已有实测】`R²(log dens ~ log TO15) = 0.689`，`Spearman = 0.778`；去掉换手权重后，`dens` 效应是 **−15bp**。
- 【已有实测】11 个控制联合回归后，`dens` 残差 **−4bp / t −0.60**；匹配孪生后 **−26bp / NW −0.84**。
- 【已有实测】`dens_up` 与 `dens_dn` 几乎对称：**+106 vs +111**。这不是「上方套牢」，也不是「下方支撑」——这是**方向被边际掉了**的证据。

### 10.2 三个症状是同一个病

| 症状 | 旧页的读法 | 新理论读法 |
|---|---|---|
| 密度 = 换手率的影子 | 「介质」被降级 | `a` 被积分掉了 |
| 形状泛函没有独立信息 | 「形状没用」 | `c` 被积分掉了；价格形状不是期限形状 |
| 条件效应匹配后剩 −26bp | 「信号关闭」 | 平均效应本来就是正负相抵的残差 |

**三个症状不是三次失败，是同一次投影错误的三个投影。**

### 10.3 旧理论是新理论的均值场极限

如果所有持有人同质、无约束、同一久期，那么：

```
S_t(p, a, c) = S_t(p) · δ(a − D) · δ(c − c₀)
```

代回去，`S_t(p)` 是唯一的状态变量，`D` 和 `c` 是常数。这时：

- 密度 = 换手率的核密度重构；
- 供给曲线只有一个斜率；
- 所有条件效应退化为同一个平均效应。

**旧页的零，不是「筹码没用」，是「均值场极限下的筹码没用」。** 这和「理想气体没有相变」是同一类结论：不是分子不存在，是你把相互作用积分掉了。

## 11. 新对象：三层结构

### 11.1 第一层：存量层（Census）

**对象**：`S_t(p, a)` —— 在价格 `p` 上、年龄为 `a` 的筹码密度。

**递推**（一天一次，O(1)）：

```
S_t(p, a) = (1 − TO_t) · S_{t−1}(p, a−1) + TO_t · K_t(p) · 1{a=0}
```

- `TO_t`：当日换手率（可观测）。
- `K_t(p)`：当日成交的成本核（5min 的 `vwap` 与 `ivd`；没有 5min 时用日线 `(H+L+C)/3` 与 `(H−L)/C` 近似）。
- 展开就是生存权重：`w_s = TO_s · Π_{u>s}(1 − TO_u)`。

**与旧理论的区别**：旧理论用固定 15 日窗，等价于假设 `D = 15` 对所有股票、所有年份成立。新理论不假设 `D`，`D` 是**输出**。

**四个描述量**：

```
D_t   = Σ_a a · π_t(a)                    久期（均值）
H_t   = −Σ_a π_t(a) ln π_t(a)             年龄熵（期限多样性）
q_t(k)= min{a : Σ_{s≤a} π_t(s) ≥ k}       年龄分位（k=0.5/0.8/0.9）
P_t   = max_p S_t(p)                      成本峰的高度
```

### 11.2 第二层：约束层（Constraints）

**对象**：`c_i` —— 持有人 `i` 的约束向量。

| 维度 | 代理 | 数据 | 方向 |
|---|---|---|---|
| **久期** | 持有人类型（险资/社保/基金/个人/QFII/游资） | `top_float.holder_type` | 险资/社保长，游资/个人短 |
| **杠杆** | 两融余额/流通市值（市场级）；大宗折价；龙虎榜 | `margin`、`block_trade`、`dragon_tiger` | 杠杆高 → 负伽马 |
| **委任** | 基金/ETF 持股比例；指数成分 | `top_float`、指数/ETF | 被动 → 正伽马（再平衡） |
| **集中度** | 前十大流通股东占比、股东户数、户均持股 | `top_float`、`holder_num` | 集中 → 协调行动 |
| **盈亏** | 现价 / 成本 − 1 | `S(p,a)` 隐含 | 深亏 → 处置效应反转 |

**关键**：不是把 `c` 当一个控制变量，而是把 `c` 当成**符号的来源**。同样的密度：

- 在**负伽马**持有人手里（杠杆、短线、游资）→ 跌了必须卖 → 密度是**陷阱**。
- 在**正伽马**持有人手里（险资、指数、长期）→ 跌了可以买 → 密度是**支撑**。

### 11.3 第三层：网络层（Network）

**对象**：`A_ij` —— 股票 `i` 和 `j` 的所有权重叠。

```
A_ij = Σ_h w_ih · w_jh
```

`w_ih` = 持有人 `h` 在股票 `i` 的流通盘占比。数据：`top_float` 的 `holder_name` × `code` × `ratio`。

**三个网络量**：

- `C_i`：特征向量中心度（这只股票被多少「系统性持有人」共同持有）。
- `k_i`：社群归属（同一批基金/同一风格）。
- `S_i`：fire-sale 模拟下的**被迫卖出敞口**：假设持有人 `h` 在股票 `i` 上亏损 `x`，其组合回撤触发赎回/止损，按比例卖出 `j`。

**为什么需要网络**：旧理论是**单股票**的。但持有人是**共享**的：一个基金在 A 股票上被套，可能在 B 股票上卖出来应对赎回。**筹码结构的尾部风险是组合属性，不是单股票属性。**

## 12. 两个新轴：久期 `D` 与伽马 `Γ`

### 12.1 久期：1/TO 只是均值

`1/TO` 是年龄分布的**均值**。两个股票可以有相同的 `1/TO`，但完全不同的期限结构：

- **单峰、窄**：所有筹码年龄接近 → 行为**同步** → 脆弱。
- **厚尾、宽**：老钱和新钱共存 → 行为**错开** → 有韧性。

所以真正的状态变量是**分布**，不是均值。`H_t`（年龄熵）是分布的**形状**，`q_t(0.9)` 是分布的**尾部**。

【新推导】同样的 `D`，`H` 越高，恢复半衰期越短；`H` 越低，越容易「一起卖」。

### 12.2 伽马：密度的符号由持有人的凸性决定

定义**供给强度**：

```
E_t(p) = ∫ h(a, p/c − 1, c) · S_t(p, a) da
```

- `h(a, x, c)`：年龄 `a`、盈亏 `x`、约束 `c` 下的卖出 hazard。
- `E_t(p)`：价格 `p` 上方/下方，单位价格上的**潜在卖压**。

定义**伽马**：

```
Γ_t(p) = ∂E_t(p) / ∂p
```

- `Γ > 0`：价格越涨，卖压越大（获利了结）→ **正伽马** → 价格被**钉住**。
- `Γ < 0`：价格越跌，卖压越大（止损/赎回/追保）→ **负伽马** → 价格被**加速**。

**这是旧理论缺的那一维。** 旧理论只有「密度高 → 差」，没有符号；新理论说：密度高的地方，`Γ` 的符号决定它是**钉子**还是**陷阱**。

【新推导】旧页的 `dens` Q5 −102bp / Q1 +34bp 的**不对称**，不是「供给垂直」，而是**样本里负伽马持有人占比更高**。当把 `Γ` 条件上去，符号应该翻转。

### 12.3 `(D, Γ)` 相图

| | **Γ > 0（耐心/正伽马）** | **Γ < 0（被迫/负伽马）** |
|---|---|---|
| **D 高（老筹码）** | **漂移**：老钱持有，价格围绕成本慢速均值回归；低脆弱 | **价值陷阱**：老筹码 + 被迫持有人；慢跌，然后一次性崩塌 |
| **D 低（新筹码）** | **钉住**：新钱 + 正伽马；价格在成本附近稳定，波动被吸收 | **雪崩**：新钱 + 负伽马；跌破成本即触发止损/赎回，加速下跌 |

**四个域，四种交易/风控含义**：

- **漂移**：不追，等回归；适合做卖方（卖波动）。
- **钉住**：适合做区间；密度是支撑，不是压力。
- **价值陷阱**：不要因为「跌得多、筹码密」就买；先看持有人是谁。
- **雪崩**：不要因为「跌得多」就抄底；负伽马会自我强化。

**旧页的「密度高 → 差」是这张表的对角线平均**：左上（漂移）和右下（雪崩）符号相反，平均接近零。这就是为什么匹配后只剩 −26bp。

### 12.4 反馈回路：伽马是回路增益

把价格、盈亏、卖出、供给连成一个闭环：

```
price_t  →  P&L_t  →  hazard_t  →  supply_t  →  price_{t+1}
   ↑                                                    │
   └────────────────────────────────────────────────────┘
```

- **Γ > 0**：价格下跌 → 获利盘减少 / 正伽马接盘 → 卖压下降 → **负反馈** → 稳定、钉住。
- **Γ < 0**：价格下跌 → 止损 / 追保 / 赎回 → 卖压上升 → **正反馈** → 不稳定、雪崩。

所以 `Γ` 不是「一个变量」，是**回路的增益**。

旧理论的「势场」是这个回路的**静态近似**：它假设回路增益为负（价格偏离成本会被拉回），但负控说不是（−0.125 vs −0.107，换手五分位全平）。**负控杀死的不是「筹码」，是「增益为负」这个假设。** 新理论不假设增益的符号，它**估计**增益；估计出来是正还是负，取决于持有人是谁。

这也解释了为什么旧理论的「形状」没有信息：形状是**开环**的静态切片；信息在**闭环**的增益里。同一个峰，在负反馈回路里是钉子，在正反馈回路里是悬崖。

**这不是行为金融的「处置效应」重述。** 处置效应是 `h` 的一个分量（盈亏对卖出的影响）；新理论的重心是 `c`（约束）和 `Γ`（加总凸性），以及 `A_ij`（网络）。行为金融解释「为什么个人会卖」；新理论解释「为什么一群人的卖出会变成价格的不稳定」。前者是微观，后者是系统。

## 13. 七个可证伪的新预测

### H1：久期错配 → 脆弱性（已跑：部分通过 / 已分解）

**机制**：短钱持有长故事 → 展期风险 → 冲击来临时被迫折价卖出。错配不改变**平均**收益，改变**尾部**和**恢复时间**。

**测量**：

```
M_t = T_t / D_t
```

`D_t` = 筹码久期（`age_mean + old_share×500`，500 日以上老钱按 500 日下限补）。
`T_t` = **市场隐含的重估半衰期**：价格相对 120 日均线的缺口、日频 AR(1) 的 `−ln2/ln(1+b)`，单位交易日。
基本面 T（分析师/盈利修正）当前没有数据，这是本卷的**代理**，不是原教旨的「基本面久期」。

**判据（预注册，跑数前写死）**：
- 主判据：`M` 与 fragility 复合（−mdd20、−skew20、−worst5、+dvol20 的月度截面 z 均值）的月度 Spearman 均值 `|ρ| ≥ 0.15`，NW(6) `|t| ≥ 2`，2023-2026 分段同号。

**结果（2026-11-26，已跑）**：

- 主判据：`ρ=0.380`，NW `t=37.0`；2019-22 `0.351` / 2023-26 `0.410`；安慰剂 200 次均值 0.000、真实值第 100 百分位。**过**。
- 次判据：`ρ(M, fwd20)=−0.064`，`t=−6.0`；Q5−Q1 仅 **−0.53%**（`t=−1.42`）。按 `|ρ|<0.05` **不过**；经济量级很小。

| 关系 | Spearman |

- 偏度、恢复半衰期**不支持**；H1 的正确表述是 **「久期/重估速度 → 回撤深度」**，不是「错配 → 偏度/恢复」。

**测量**：

- 原假设「机构=正伽马、个人=负伽马」被数据打掉；A 股的符号地图可能是「可赎回/可质押=负伽马，个人/集中=正伽马」。
- 但这是 **18 个月、top10-only、14 个检验、无质押/基金流数据** 的探索性结果；分项 t 值 2.0–2.8，只有 `gamma_flow` 接近 Bonferroni 门槛，**不构成结论**。
- 密度效应仍是 **换手交互**（`dens×to`），不是伽马交互；H2 没有救回旧页的密度信号，只是把「谁在被迫卖」这个问题问得更准。

**方法坑（比结果重要）**：类型标签不是凸性。伽马是「价格下跌时持有人被迫卖多少」，不是「他是机构还是个人」。基金有赎回/排名，法人有质押/杠杆，个人可能是抄底者；下一轮要用 **基金赎回/仓位、质押比例、融资余额、ETF 份额** 来量凸性，而不是用持有人类型贴标签。

### H3：进入方向决定吸收/崩塌（已跑：失败——雪崩格反向，密集区不做事）

**机制**：价格从下方进入密集区（上涨）和从上方进入（下跌），持有人的盈亏状态相反，hazard 相反。

**测量**（预注册在跑数前写死）：
- 「密集区」= 换手加权递归成本分布的核心带。`m_t=(1-to)m+to`、`c_t=((1-to)m·c+to·P)/m`、
  `v_t=((1-to)m(v+(c_prev−c)²)+to(P−c)²)/m`；带 = `c_{t−1} ± K·sd_{t−1}`，**用 t−1 的参数**
  （否则带的漂移会伪造穿越）。
- 上穿 = t−1 在带下、t 收盘进带；下穿反之。速度 = `|cum5| ≥ 5%` 为快。
- 冷却 20 日；剔除 `|ret_t| ≥ 9.5%`；入场 t+1 开盘、出场 t+21 收盘。

**判据**：四格符号 = 上慢 +、上快 −、下慢 +、**下快 −**；极差 ≥ 80bp；控制动量/波动后仍在。
**杀死**：四格无结构，或方向与预测相反。

**结果（2026-11-26，已跑）**：191,721 事件 / 5,208 只 / 2,377 个交易日 / 2017-01 ~ 2026-10 / K=0.5。

|---|---|---|---|---|
| 上穿 · 慢 | +11.7bp | 0.18 | + | 持平 |

- 极差 473.8bp；但极差是恒正量，其 t=13.3 **不可读**（检验的是「均值>0」，必然显著）。

- 方向主效应（上穿−下穿）**−89.8bp（t −3.24）**：上方阻力强于下方支撑。

- 「下穿快 = 雪崩」**符号相反**：A 股快速跌进成本区是**反弹**（+116bp），不是被迫抛售。
- 「密集区」不做事：置换后效应更强、剂量反应平坦。四格结构是**短期反转**穿了筹码的衣服。
- 唯一留下的方向性事实：上方阻力 > 下方支撑（−90bp，t −3.24），但这也只是反转的另一种说法
  （涨多了回吐 > 跌多了反弹的绝对幅度）。

**执行口径不影响结论**（t+1 开盘 vs t 收盘入场）：下穿快 +116.0 / +98.9bp、上穿快 −69.8 / −102.8bp、
下穿慢 +5.5 / −11.1bp、上穿慢 +11.7 / −2.0bp；t+1 平均跳空 −0.16% ~ −0.34%。反弹不是开盘跳空假象，
按收盘入场仍留 85%。

**这条失败与 H2 一致**：H2 说个人是正伽马候选、基金/法人是负伽马候选；H3 说总量层面快速下跌被接住。
两个独立测量指向同一件事——**A 股的边际持有人是抄底的，不是被迫卖的**。雪崩需要杠杆数据
（融资/质押/赎回），价格路径推不出来。

### H4：年龄离散度 → 恢复速度（已跑：失败——原始差是冲击深度混淆）

**先修轴**：原始 H4 用 `age_entropy`。实测它与 `age_mean` 的 Spearman = **0.989**、与 20 日换手 **−0.921**。
几何型年龄分布下熵 ≈ log(均值)+常数，它不是第二个轴，只是久期的另一种写法——直接跑等于把 H1 重跑。
所以主轴改为**尺度无关**的 `disp = q90/q50`（年龄分位比；几何分布下 ≈3.32）。实测 `disp` 与 `age_mean`
的 Spearman 仅 **−0.285**、与换手 +0.419。次轴 `excess_H = age_entropy − log(age_mean)`（与久期 −0.501）。

**机制**：持有人年龄越分散，行为越错开，冲击后的恢复越快；越集中，越容易同步行动。

**测量**：个股**特质**冲击 `exc_t = r_t − mkt_t ≤ −2·sd60(exc)` 且 `≤ −3%`（用特质而非原始收益，
避免市场普跌让同日所有股票共享一个冲击）。半恢复位 `(C_{t−1}+C_t)/2`，从 t+1 起算，60 日截尾。
主结果 `rec20` = 20 日内半恢复。冷却 20 日。

**判据**：`rec20 ~ z(disp) + z(D) + 冲击幅度 + z(vol) + z(beta) + z(ret20) + z(turn) + z(size)`，
NW(6) `|t| ≥ 2` 且符号为「高离散恢复快」；Q5−Q1 的 `rec20` 差 ≥ 5pp；冲击幅度三分位内同号；
市况冲击口径同号。

**结果（2026-11-26，已跑）**：100,012 事件 / 5,183 只 / 1,894 个交易日 / 2019-01 ~ 2026-11。

| Q1 最集中 | 1.97 | −5.57% | 2.10% | **68.9%** | 15.0 |
| Q2 | 2.46 | −5.65% | 2.16% | 68.2% | 15.4 |

  与预测相反，且远不到「快 30%」。
- **但这个差是冲击深度混淆**：`corr(disp, drop) = −0.213`、`corr(disp, vol20) = +0.278`。
  高离散组本来就是高波动组，冲击更深（−7.55% vs −5.57%），恢复自然更慢。
- 控制后符号翻正：`b_disp = +0.0056（t 1.73）`——不显著，且与原始分位**方向相反**。

- 次轴 `excess_H`：`b = +0.0085（t 2.66）`——符号与原始分位相反。
- 市况冲击（`mkt ≤ −1.5%`，53 天）：`rec20` Q5−Q1 **−2.64pp（t −2.10）**，`half_days` −0.03（t −0.03）。

**裁决：失败。**
- 「离散 → 恢复快」在原始分位上**符号相反**，在控制后**不显著且翻正**，在冲击幅度分层内**归零**。
  三种口径三个答案，唯一一致的是「没有稳定效应」。
- 原始差 100% 是混淆：高离散 = 高波动 = 冲击更深。这与 H1 的 D/T 是同一个坑的第三次出现——
  **先看被检验变量与冲击幅度/波动的相关，再谈恢复**。
- 「快 30%」的判据（`half_days` 比值 ≥ 1.3）实测 0.85，方向反了。
- 注意轴的选择本身也是结论：原始 `age_entropy` 与久期 ρ=0.989，任何用它做的「分散度」检验
  都只是 H1 的复读。

### H5：网络中心度 → 尾部传染

**机制**：共同持有人 → 一个股票亏损 → 组合赎回/止损 → 卖其他股票。中心度高的股票是**系统性持有人**的交叉点。

**测量**：`top_float` 二分图投影，特征向量中心度 `C_i`；尾部相关 = 下行日的 pairwise 相关（或 CoVaR）。

**判据**：`C_i` 每 +1sd，下行相关 ≥ +0.10；平均相关不变（否则只是 β）。

**杀死**：只影响平均相关，或中心度只是市值/行业的代理。

### H6：记忆相变，不是线性衰减

**机制**：当市场久期 `D_m` 低于某个阈值，库存机制被流量机制压倒，筹码结构失去预测力。这不是「被套利」，是**相变**。

**测量**：市场级 `D_m`（中位 `1/TO` 或年龄递推的均值）；密度效应的时间序列；阈值回归/变点检测。

**判据**：阈值模型 BIC 优于线性 ≥ 10；OOS 分段同号；阈值不是牛熊日历（控制指数收益后仍在）。

**杀死**：无阈值，或阈值只是牛熊日历。

**注**：2026 年 `D` 低但 `dens` 效应反弹（+240bp），这是 H6 的**反例候选**。新理论的处理不是忽略它，而是说：`D` 不是唯一控制参数，`Γ` 是第二轴——2026 可能是「低 `D` + 正 `Γ`」的钉住域。如果加入 `Γ` 后 2026 仍无法解释，H6 降级。

### H7：Θ 是滚续成本 → 脆弱性，不是收益

**机制**：`Θ` 衡量走廊里的筹码被换了几遍。`Θ` 高 = 走廊里的筹码是**新钱** = 久期短 = 更容易被迫卖。旧 P2 问「Θ 高是否收益好」，问错了方向；正确的问题是「Θ 高是否更脆」。

**测量**：`Θ`（已有 5min 窗口产物）；下行偏度、最大回撤、恢复半衰期。

**判据**：`Θ` 与下行偏度负相关，`t ≥ 2`；与 `fwd20` 无关。

**杀死**：与 `fwd20` 强相关（说明旧 P2 只是没测对），或与偏度无关。

## 16. 方法：从归因到结构

### 16.1 Hazard 的可识别性

年龄分布 `S_t(a)` 的递推给出：

```
S_{t+1}(a+1) = S_t(a) · (1 − h(a, x, c))
S_{t+1}(0)   = TO_t
```

给定 `S_t(a)` 和 `TO_t`，可以**反解** `h(a, x, c)`。这是**结构估计**，不是回归。

**三个难点**：

1. **未观测异质性（frailty）**：相同年龄/盈亏的筹码，卖出概率不同。用混合模型/随机效应。
2. **竞争风险**：卖出、转托管、质押冻结是不同事件。先做「卖出 vs 不动」，再做多状态。
3. **右删失**：老筹码可能永远不卖。用生存分析的标准删失处理。

### 16.2 反事实供给曲线

估出 `h(a,x,c)` 后，可以模拟：

- 换手率翻倍 → 年龄分布怎么变？
- 市场下跌 10% → 多少筹码进入「被迫卖出」区？
- 基金赎回 5% → 哪些股票被卖？

**这是旧理论给不出的东西**：旧理论只有「密度高 → 差」的一个系数，没有**反事实**。

### 16.3 网络传染

```
A_ij = Σ_h w_ih w_jh
```

- 投影后做**社群检测**（Louvain/Leiden）。
- 算**特征向量中心度**、**k-core**。
- 用 **SIR/fire-sale** 模拟：给定一个外生冲击，持有人按 `h` 卖出，价格按 `λ` 冲击，迭代。

**判据**：模拟出的尾部相关与真实尾部相关对得上（`R² ≥ 0.3`），否则网络只是描述。

### 16.4 相变检测

- **阈值回归**：`effect_t = β0 + β1 1{D_t < D*} + ...`，网格搜索 `D*`，bootstrap 置信区间。
- **变点检测**：Bai-Perron / PELT。
- **临界慢化**：相变前自相关/方差上升。
- **负控**：把 `D_t` 换成随机序列，看是否还能找到「阈值」。

## 17. 什么会杀死这套理论

1. **H1/H2/H3 全灭** → 它只是一个更好听的隐喻，不配替代旧页。
2. **伽马代理互不一致** → 符号故事不可识别；`Γ` 只是一个拟合参数。
3. **网络中心度只是市值/行业** → 传染故事是旧酒新瓶。
4. **相变只是牛熊日历** → 久期只是市场收益的代理。
5. **2026 反弹是噪声** → 相图过拟合；H6 降级。
6. **年龄递推对核宽/停牌/折算敏感** → 新对象本身不可靠；先做数据审计，再谈理论。
7. **比值被分母主导** → 任何 `M=T/D` 的结论，先报 `corr(M, 分母)`；>0.7 就拆开，不要叫错配。
8. **类型标签不是伽马** → 机构/个人只是先验；H2 的合成符号被分项反转打掉。先量赎回/质押/融资，再贴正负。
9. **穿越不是吸收/雪崩** → H3：四格结构是短期反转，打乱密集区后更强、带宽剂量反应平坦。别用价格路径推被迫交易。
10. **熵不是分散度** → H4：`age_entropy` 与久期 ρ=0.989；用尺度无关的 `q90/q50`。且恢复必须条件于冲击幅度，否则测的是波动率。

**这六条写在跑数之前，是为了防止「跑完再讲故事」。**

## 附：本卷的地位

**它不是一篇「证明筹码有用」的文章。** 它是一篇「把筹码从一个统计摘要，升级为一个结构对象」的文章。

它的赌注是：

> **旧页的零不是对象的零，是投影的零。**
> 把「谁持有、还能拿多久、跌了会不会被迫卖、谁会被一起拖下水」放回去，同一个对象会长出旧理论没有的符号、尾部和传染。

如果这个赌注输了，我们至少知道：**筹码结构在均值、尾部、路径、传染四个维度上都没有信息**——那是一个比「fwd20 没信号」强得多的否定，值得一个页面。

如果它赢了，`/chip` 就不再是一份验尸报告，而是**被迫交易方账本的测量层**。
