# 数据源：国资入股 / 纾困基金（2026-11-27）

> 目的：给卷五 P2 找「救助」的处理组——不是「谁在质押」，而是「谁拿到了救助」。
> 结论先说：**巨潮公告是主源，东财并购重组不是**（它是资产交易，不覆盖上市公司股东层面的股份转让）。

## 1. 主源：巨潮资讯公告检索（免费、官方、可编程）

接口：`POST http://www.cninfo.com.cn/new/hisAnnouncement/query`

**参数（2026-11-27 修正）**：

| 参数 | 取值 | 说明 |
|---|---|---|
| `searchkey` | 标题关键词，空格 = AND | 只匹配标题，不匹配正文 |
| `seDate` | `YYYY-MM-DD~YYYY-MM-DD` | **唯一有效的日期参数**；`secdate` / `startDate` / `beginDate` 全部被忽略 |
| `pageSize` | 最大 30 | 传 50 / 100 都只返回 30 |
| `pageNum` | 1–100 | **第 101 页起静默退回第 1 页**，所以单次查询最多 3,000 条 |
| `isfulltext`（另一接口） | true/false | 正文检索走 `fulltextSearch/full`，但对常用词命中量过大（“国有股东”全期 100 万），不能做预筛 |

> **旧文档的错误**：上一版写“`secdate=2018-01-01~2026-11-27`，42,536 条（2018 年起）”——
> 日期过滤从未生效，那是**全历史**总量；而 60 页的截断又让早年的检索式少拉了一截。
> 这两个错误都在本轮修掉。

### 1.2 标题预筛失效（重要）

原计划「标题关键词筛 → 2,000–3,000 份」，实测**不可行**：

| 检验 | 读数 |
|---|---|
| 标题命中「国资/国有/纾困/财政/城投/无偿划转」的报告书 | 499 条 / 446 事件 / 318 只 |
| 随机 130 份通用标题**简式**中，披露人为国资 | **8.5%**（±2.4pp） |
| 随机 130 份通用标题**详式**中，披露人为国资 | **10.0%** |
| 标题筛的召回（1.2% ÷ 8.5%） | **约 14%** |

原因：报告书标题中位数只有 9–12 个字，绝大多数就是「简式权益变动报告书」，买方名字在封面，

不作为主路径）。

## 5. 建议的 pipeline

1. **全量池**：拉「权益变动报告书」42,536 条（约 1,400 页，30 条/页，约 15 分钟）。
2. **提名字**：标题括号里的名称（如「简式权益变动报告书（海南省国有资本运营有限公司）」）就是受让方/披露人。
3. **打标签**：国资关键词 + 企查查穿透；「纾困」直接命中；剩下的人工抽检 200 条估错分率。
4. **读 PDF**：只对候选（预计 1,500–3,000 条）下载，抽「受让方 / 转让方 / 价格 / 股数 / 比例 / 完成后实控人」。
5. **建事件表**：`date, symbol, buyer, buyer_type, stake, price, premium, progress`。
6. **接价格**：公告次日开盘入场，f20/40/60；与质押事件同一套月聚簇口径。

## 6. 已知缺口

1. 标题检索漏掉「没写国资」的国资主体（如「山东高速投资控股」）——必须靠全量池 + 名称分类，不能只靠关键词。
2. 纾困的很多动作写在「战略合作/债务重组/帮扶」里，标题不含「纾困」；需要正文检索或 PDF 全文。
3. 权益变动报告书有「简式/详式」两版，同一事件多次披露；按（代码，日期，受让方）去重。
4. 终止/失败的事件也在库里，必须读「进度」字段，否则处理组会被污染。

## 7. 200 条级验证（2026-11-27）

实现：`analysis/_parse_state_injection.py`（PyMuPDF + 正则）。样本：三条检索式 189 条，115 条干净报告书。

### 7.1 覆盖率（115 条干净报告书）

| 字段 | 覆盖 | 说明 |
|---|---:|---|
| 上市公司 / 代码 | 82% / 88% | 代码另有公告源，100% |
| 信息披露义务人 | **91%** | 国资主体名，可靠性高 |
| 变动方式 | **94%** | 无偿划转 / 协议转让 / 表决权委托 / 司法拍卖 |
| 股数 + 比例 | 93% | 但语义正确率只有 44%（见下） |
| 变动方向（增/减） | 55% | 来自「股份变动性质」，其余缺失 |
| 每股价格 / 总价款 | 5% / 4% | 无偿划转无价；协议转让也常只写「净资产作价」 |
| 变动后实控人 | 15% | 多数只写「未发生变化」 |

### 7.2 人工核对准确率（18 条分层样本，`validation_18.csv`）

| 字段 | 准确率 | 主要错误 |
|---|---:|---|
| 变动方式 | **78%**（14/18） | 把「无偿划转」写成「协议转让」；把「一致行动协议到期」当成转让 |
| 信息披露义务人 | **94%**（17/18） | 个别封面缺失；名称被截断 |
| 本次变动股数/比例 | **44%**（8/18） | 把「变动后持有」当成「本次变动」；把控股股东的股权当成上市公司股份 |

### 7.3 错误的三种类型

1. **持有 vs 变动**（占错误的一半）：简式报告的标准表是「本次发生拥有权益的股份变动的数量及变动比例」，
   但很多报告同时写「本次权益变动后持有 X 股 / Y%」。正则容易抓到后者。
2. **直接 vs 间接**：`002285 世联行` 是珠海市国资委取得大横琴 90% 股权、间接控制上市公司；
   上市公司股份没有变动，抓到的 324,077,841 股是「大横琴的持股」，不是「本次受让」。
3. **国有对国有**：`000557 西部创业` 是宁国运把 12.28% 转给宁夏煤业，双方都是国资；
   对「救助可达性」没有处理效应，但会被当成一次「国资入股」。

### 7.4 结论：能用到哪一步

- **可以直接用**：事件日期、代码、信息披露义务人（国资主体）、变动方式。
  这三样足够做 P2 的**等权事件研究**（有事件 vs 无事件）。
- **不能直接用**：变动股数/比例、变动方向、直接/间接、变动前后实控人。
  要做「按持股比例加权」或「民营→国资」的干净处理组，必须再加一层语义抽取。

### 7.5 扩到全量的方案（**第 2 步已被 §9 推翻，见下**）

> 原方案第 2 步是「标题关键词预筛 → 2,000–3,000 份」。实测召回只有 14%（§1.2），
> 已废弃；现在改为「全量解析 + 类型判定」。第 1、3–6 步仍然成立。

1. 全量拉「权益变动报告书」42,536 条 → 去重成约 1.5 万份报告。
2. 标题/披露人关键词预筛（国资/国有/纾困/财政/城投/无偿划转）→ 约 2,000–3,000 份。
3. 下载解析，正则出 `code/date/discloser/method`。
4. **LLM 兜底**（首 8 页 + JSON schema）出 `event_type`（直接/间接/表决权）、
   `state_stake_after`、`prior_controller`、`new_controller`、`direction`。
5. 只保留 `prior_controller=民营 且 new_controller=国资` 的增持事件——那才是「救助」的处理组。
6. 与质押事件同一套口径（公告次日开盘、f20/40/60、月聚簇 NW）。

### 9.2 披露人类型

| 类型 | 条数 | 占比 | 判读 |
|---|---:|---:|---|
| 一般法人 | 1,024 | 34.0% | 民企/外资/其他 |

| **国资（强）** | **84** | **2.8% ± 0.6pp** | 国资委 / 财政厅 / 央企集团 / 城投 / 交投 |

三组补充读数：

- **按已识别样本算**：84 / 2,300 = **3.6%**。若未识别的 23.5% 与已识别同分布，这是更接近真实的比例。
- **详式 vs 简式**：4.1% vs 2.5%。取得控制权（详式）的披露人更可能是国资，符合直觉。
- **按年代**：2006–14 4.0% → 2015–19 2.5% → 2020–26 2.5%。没有出现「纾困潮推高国资入股占比」的证据；
  但 23.5% 的未识别会稀释，暂不下结论。

按 3.6% 外推，28,691 个事件里约 **1,030 个** 的披露人是强国资；加上平台档（5.6%），上界约 2,600 个。
这是 P2 处理组的原始池——还需要一步「民营 → 国资」的方向判定。

### 9.3 已知缺陷（扩量前必须知道）

1. **变动方式**：简式报告书把所有选项都印成勾选清单（□协议转让 □国有股行政划转…），
   按关键词盲扫会全判成「国有股行政划转」（上一版 654 条假阳性）。现在只认句子式和 ☑ 勾选，
   覆盖率降到 35.9%，但可信。
2. **变动方向**：只从「股份变动性质」读，缺一半。可补：详式的前后持股表、标题里的增持/减持。
3. **间接持股**：`002285 世联行` 那种「国资委取得母公司股权、上市公司股份不变」的，
   披露人会被正确抓成国资委，但「变动股数」不是上市公司股份——不能直接当增持。
4. **上市公司自身误抓**：封面先印「上市公司名称」，早期版本会把上市公司当成披露人
   （如 600242）。已用「证券简称前缀」排除，但只在简称可见时有效。

### 9.4 扩量成本

5.1 条/秒 × 28,691 个事件 ≈ **1.6 小时**（5 线程；12 线程反而更慢，服务端限流）。
断点续跑，中断不丢进度。

## 10. 详式报告：前后持股与实际控制人（2026-11-27）

实现：`analysis/_parse_prior_controller.py` → `prior_controller.parquet`
范围：5,265 个详式事件（收购报告书并入），全量解析 18 页正文。

### 10.1 一个必须先说清的事实

**详式报告的「前后持股表」只写信息披露义务人自己的持股变化，不写上市公司原控制人。**
原控制人只出现在叙述句里，而且多数报告根本不写。

| 项 | 读数 |
|---|---:|
| 报告明写上市公司原控制人 | **213 / 5,265（4.0%）** |
| 报告称「控制人未变更」（可反推原控制人=买方） | 1,070（20.3%） |
| 两者都没有 | 3,982（75.6%） |
| 取得控制权（成为控股股东/变更为/封面） | 35.1% |
| 买方识别失败（披露人为空） | **1,928（36.6%）** |

所以「变动前民营」无法从报告里规模化读出：96% 的报告不写原控制人，
而买方本身有 36.6% 抓不到名字。这是文本的结构限制，不是正则的问题。

成本：标题检索 + 解析约 2,000–3,000 条，1 小时内可跑完。

## 11. 换成控制权变更公告：A 级 140 只（2026-11-27）

### 11.1 为什么换

「控制权变更提示性公告」正好相反：第一段必写「实际控制人将由 X 变更为 Y」。

|---|---:|

### 11.3 A 级（民营 → 国资）

**156 条 → 按公司去重 140 只**（剔除无偿划转、原控制人本身像国资的 2 条）。

按年：2017 6 · 2018 6 · 2019 15 · 2020 26 · 2021 16 · 2022 19 · 2023 6 · 2024 10 · 2025 15 · 2026 15。

**方式分布才是重点**：

| 方式 | 数量 | 含义 |
|---|---:|---|
| 表决权委托 / 放弃 | **65** | 不出钱，只拿表决权 |
| 协议转让 / 司法拍卖 / 定增 | 45 | 真金白银 |
| 未标注 | 30 | |

也就是说：**A 股国资拿控制权，近一半靠表决权安排，不靠买股。**
这对卷五的「救助」读法是直接证据——救的不是资产负债表，是控制权；
所以行情反应应该看「谁说了算」，而不是「谁付了钱」。

### 11.4 与 P2 的关系

这 140 只才是 P2 的处理组：有事件日、有原控制人（民营）、有新控制人（国资）、有方式。
下一步可以直接跑事件研究：公告次日开盘入场，f20/f40/f60，月聚簇 NW，
再按「现金 vs 表决权」二分——如果救助读法成立，现金组的反弹应强于表决权组
（付钱的人承担了余额，只拿表决权的人没有）。

### 12.4 读法

这与卷五的「救助期权」读法**方向相反**：市场不给国资接盘付溢价，反而在公告后系统性卖出。
三个可能，按可检验性排序：

1. **利好出尽**：公告前 60 日已涨 8.2%（表决权组 15.5%），公告是兑现点。
2. **资产注入预期落空**：国资拿控制权后通常承诺「12 个月内不注入资产」，右尾因此消失。
3. **困境比披露的更深**：国资入场是风险信号，不是救援信号。

注意这与质押贴线（+525bp）不矛盾：那是**存量持有人浮亏**的反弹，
这是**控制权转移**的折价；前者事前跌，后者事前涨。

### 12.5 边界

- 基准是全市场等权，事件股偏小盘；未做市值匹配，CAR 的绝对水平可能被小盘因子污染。
- 129 个国资事件、45 个现金事件，分年样本薄，2021 的 +7.0 只有 14 个。
- 未剔除 2026 年未走完 120 日的样本（f60 覆盖 96%）。
