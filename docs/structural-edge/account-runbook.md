# 运营账户 Runbook：腿 1 + 债券 B&H 叠加（2026-11-22 启用）

> 裁决链：[`leg2-bond.md`](leg2-bond.md)（预注册门槛双过）→ 本文（启用后的每日操作）。
> 引擎：`analysis/etf_watch_account.py`，与回测同一个 `replay_joint`（含整格补足修正），每次运行全量重放，**没有可漂移的增量状态机**。
> 账户性质：**纸面账户**，2026-11-20 收盘以全现金启动（初始 60 万虚拟资金，与真实资金同规模；每格 = 权益/6 ≈ 10 万）。真实资金接入见 §6。

## 0. 账户规则（冻结，改任何一条都要重开预注册）

> **2026-11-23 执行叠加**：进场从「t+1 收盘市价」改为「t+1 开盘限价 = 信号收盘 ×1.03」。
> 回测仍按 t+1 收盘（保守口径），执行叠加的读数见 `analysis/_probe_entry_timing.py`
> 与 `data/etf_watch/_probe_entry_timing.json`（34 事件 / 14 月；开盘中位 +49bp vs 收盘 +1.5bp；
> 加 +3% 封顶后中位 +54bp、月度 t=2.47，in-sample）。
> **预注册口径**：只改进场价，不改判定（F1/F2/F3/F6）、退出（20 日）、仓位（权益/6）；
> 验收 = 成交率、成交价相对信号收盘、20 日相对收益（对照收盘口径）；样本 34 事件/14 月，
> t=2.47 是 in-sample，上线后按新事件前向登记，不回头改历史。

| 规则 | 内容 |
|---|---|
| 腿 1 进场 | 信号段首日收盘已知 → **下一交易日开盘挂限价 = 信号收盘 ×1.03**，按「当时权益 / 6」买入该行业当日 F6 最大 ETF；未成交则放弃（不追已修复出区间的事件） |
| 腿 1 退出 | 进场后第 **20 个交易日**收盘卖出（固定持有，不因候选失效提前） |
| 债券 | 每日收盘后：**511010 市值 = 权益 − 腿 1 持仓市值**。差额为正买入、为负卖出 |
| 拥挤 | 腿 1 进场缺钱**先卖债券**（整格补足），任何腿 1 信号都不被挤掉 |
| 成本 | 模型 **6bp/边**（预注册保守口径，含滑点近似）；真实佣金为 **万 0.5 = 0.5bp/边（最低 0.3 元）**，两口径的账户差异 ≈ **+0.17pct/年**（真实更优），结论不变 |
| 独立性 | **执行层与 V1 判定层独立**：账户按事件进场（与 JB0 回测口径一致），V1 只记录判据读数（0/3 簇），不挡进场 |
| 不做 | 不重配、不因新信号追加旧仓、不加杠杆、不启用红利腿、不因为「感觉要跌」手动干预 |

## 1. 每日流程（收盘后 3 分钟）

```bash
python analysis/etf_watch.py            # ① 扫描 + 记账本（已有，产出 latest.json / ledger / daily 快照）
python analysis/etf_watch_account.py    # ② 重放账户 + 产出次日指令（account.json）
```

②自动打印并写入三条指令（如有）：

1. **卖出**：持有满 20 个交易日的腿 1 仓位，下一交易日收盘卖出。
2. **买入**：最新段首信号对应的载体 ETF，金额 ≈ 权益/6（钱不够先卖债券）；**开盘挂限价 = 信号收盘 ×1.03**，未成交即撤单放弃。
3. **债券对齐**：腿 1 成交之后，把剩余全部买入（或卖出）511010，使 `债券市值 = 权益 − 腿 1 持仓`。

无指令时脚本与页面都显示「下一交易日无指令」。**指令只在收盘后有效**（信号收盘才知道、执行下一收盘），盘中不看。

## 2. 在哪里看

- 面板 **执行 → 02 账户指令**（`/handbook`）：四项状态（权益/债券/腿1/现金）+ 三条指令。
- API：`GET /api/etf-watch/account`（只读 `data/etf_watch/account.json`，缺失返回 404 并提示命令）。

## 3. 资金与执行的两种模式

| 模式 | 含义 | 启用方式 |
|---|---|---|
| 纸面（当前） | 虚拟 60 万，指令仅供核对与积累真实轨迹 | 默认。什么都不用做 |
| 实盘 | 真实资金按同样三条指令执行 | `python analysis/etf_watch_account.py --init <你的资金>`，并自行在券商端按指令下单；**每次下单前核对页面金额** |

实盘注意：最低交易单位（ETF 100 份）会带来与理论的偏差，记录实际成交价与数量即可，不要为了贴合回测改规则。

**真实费率表（2026-11-22 录入）**：ETF 万 0.5（0.5bp/边，最低 0.3 元，买卖均收）；印花税 0.5‰ 只对 A 股卖出收取——**ETF 全免**；511010 按 ETF 计费（0.5bp），比直接交易记账国债（2bp）更便宜。按本账户规模的实际单笔佣金：腿 1 ≈10 万 → **5 元**；债券 ≈50 万 → **25 元**，均不触发最低价。**主要摩擦不是佣金而是价差**：159530 最小变动价位 0.001 元 ≈ 价格的 9bp，实际成交价差可能高于佣金——这是模型保留 6bp 的原因。

**债券对齐阈值（2026-11-22 预注册）**：债券差额 **≥ 3,000 元**才执行对齐；低于阈值累计不动（最低佣金 0.3 元在碎单上放大费率），纸面与实盘由此最多相差 0.5% 权益，有界。

**资金锁定规则（2026-11-22 补，预注册）**：信号日资金不可用（逆回购/理财未到期）⇒ **该笔信号放弃，不做延迟进场**——
回测证据只覆盖 t+1 收盘进场，晚进场的交易没有任何测量支持。资金可用日的收盘起，先按债券规则把全部可用资金对齐到 511010，
之后恢复「信号来了才动」。错过不补。

## 5. 什么情况下停用

- 账户相对「腿1+现金」基准的滚动 12 个月表现 + 债券腿自身回撤，出现 `leg2-bond.md` 未预注册过的劣化形态 → 先停，再研究，不边跑边改。
- 腿 1 规则若被新证据证伪（例如 V1 三簇结算失败），整个账户停用——债券叠加不单独存活。

## 6. 已知边界（启用时即接受）

1. 纸面账户与回测账户**不是同一个对象**：回测是 2019-12→2026-11 的证据，纸面账户从 2026-11-20 全现金启动。它的价值在于积累**真实的执行轨迹**（滑点、最低交易单位、执行纪律），这不是回测能给的。
2. 6bp/边是腿 1 口径的假设；债券实际点差更小，腿 1 的滑点未知——纸面阶段按 6bp 记，实盘后用真实成交替换。
3. 511010 用净值计价，未计溢折价；2022-11 式利率冲击（债券 −4.5%）会进账户，这是启用时接受的。
4. 金额按最近收盘估算；实际成交时权益变了，金额会不同——**以页面当日快照为准，不要用旧快照下单**。

## 7. 现金腿：短融打底 + 国债锚（2026-11-23）

> 面板 **执行 → 03 现金腿**。产出物 `data/etf_watch/cash_leg.json`，由 §1 的第 ② 步顺带生成（不加新命令）。

### 7.1 为什么不是「全仓 511010」

全仓 5 年期国债 = 4.3 年久期，账户回撤完全由利率决定。分档后回撤预算变成显式参数，而且**回报与风险的分母换成权益而不是成本价**。三条规则：

| 规则 | 公式 | 含义 |
|---|---|---|
| R1 国债锚 | `国债 = BOND_W × 权益` | 久期预算按权益定，不按成本 |
| R2 底盘吸收 | `短融 = 权益 − 腿1 − 国债 − 现金` | 腿 1 进出只动底盘，久期目标不漂 |
| R3 缺钱顺序 | 先卖短融；不足 1 手才卖国债 | 底盘是 T+0，价差比国债小 3 倍 |

默认 `BOND_W = 0.40`：`_probe_cash_ladder.py` 实测 5Y 权重 0%→100% 时现金腿 NAV 回撤 0.15%→1.55%（近似线性 0.15% + 1.4%×w），40% 对应约 −0.7%，在 −4.5% 的账户预算里占 15%。偏离阈值 3,000 元；单笔不达阈值不调仓。

### 7.2 为什么期限之间不分档

同一窗口（2020-09→2026-11）：短融 2.14%/−0.15%、5Y 3.02%/−1.55%、10Y 4.13%/−2.27%。5Y 与 10Y 的 `CAGR/|MDD|` 是 1.94 vs 1.82、每单位久期超额 20.5 vs 23.4bp —— **差异在噪音里**。等权阶梯只是把同一个利率赌注做成两份，不产生分散。真正的另一条风险轴是短融（信用/流动性）而非期限。

**10Y 只在 5-10 斜率异常陡时替换 5Y**，不做同时持有。

### 7.3 换标的（唯一需要改的地方）

`analysis/etf_watch_cash_leg.py` 顶部三个常量：`BOND` / `SHORT` / `BOND_W`。流程、阈值、页面全部不动。

五道闸（任一不过就换标的，不调权重）：溢价 < 0.5%、日均成交 > 1 亿、T+0、管理+托管 < 0.30%/年、近 3 年跟踪误差 < 1%。

**QDII 类标的额外一条**：溢价 > 0.5% 不买，等下一期。513500 的实测（2014-01→2026-11）：当前溢价 +10.42%（97.6 分位），中位 +0.31%；按买入时溢价分层的前向 250 日价格收益，>8% 时 +5.7% vs 0–2% 时 +11.2%。历史上 33 段溢价 >8% 有 26 段回到 2% 以内、中位 62 天，但 **2026-08 之后的 7 段全部未回归**（额度约束而非情绪）——基率在当前 regime 不适用，不要拿「62 天会回来」当计划。

### 7.4 验收（12 个月结算，不中途改）

1. 现金腿 NAV 最大回撤 ≤ −1.0%
2. 现金腿收益 ≥ 纯短融 + 10bp
3. 再平衡 ≤ 12 次/年、摩擦 ≤ 100 元

任一不成立 → 退回 100% 短融，不再讨论中间档位。
