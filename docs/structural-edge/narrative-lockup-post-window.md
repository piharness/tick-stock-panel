# 解禁后 20 日：一份被撤下的研究，完整写法

> 状态：**撤下（2026-11-28），不进入任何结论**。
> 本文做两件事：把这项研究按可复核的格式写完整；说明它为什么不够格当结论。
> 读数来自 commit `895aa2a0` 的计算版本（现行脚本已删除 post 窗口）。

## 0. 一句话

解禁后 20 日相对同日等权市场 **+50.8bp**（≥10% 档，t 2.08）——数字是真的，
但它既不单调、也不独立、更不是净额。所以它是记录，不是结论。

## 1. 假设与可证伪形式

**H**：解禁是事件结算。抛压在到期日之前被定价，到期后结算完毕，之后应有回补。
（这是 `/chip` P3「支付后漂移归零或反转」在大盘上的迁移。）

可证伪形式有两条，必须同时成立：

1. **剂量**：post20 超额随解禁比例单调上升（≥10% > 3–10% > 1–3% > <1%）；
2. **净额**：post20 为正，且大到能覆盖双边成本（≈40bp）。

## 2. 设计

| 项 | 口径 |
|---|---|
| 样本 | 解禁 16,928 件 / 2019-01 ~ 2026-06；按 `TOTAL_RATIO`（解禁股数/流通股数）分四档 |
| pre20 | `close[t−1] / open[t−20] − 1` |
| post20 | `close[t+20] / open[t+1] − 1`（t 为 FREE_DATE） |
| 基准 | 同日全市场**等权均值**收益的复利路径（不用中位：右偏会把水平抬 +400bp/20日） |
| 安慰剂 | 同股票、±120 交易日随机日（避开该股自身事件日），20 次抽样取中位 |
| 聚类 | 事件扎堆，按日聚簇 NW(lag=5) |
| DiD | 事件超额 − 同股票安慰剂中位 |

## 3. 结果

| 解禁/流通 | 事件 | pre20 | t | post20 | t | 安慰剂 post 中位 | DiD post |
|---|---|---|---|---|---|---|---|
| <1% | 6,384 | −37.4 | −1.64 | +62.9 | 2.64 | −2.3 | +65.2 |
| 1–3% | 2,540 | −93.8 | −2.29 | +32.4 | 0.94 | −27.9 | +60.3 |
| 3–10% | 2,574 | −172.2 | −6.15 | **+127.7** | **3.67** | −13.8 | +141.5 |

读法：pre 一列单调（这才是留下来的那条规则）；post 一列不单调，3–10% 档比 ≥10% 档高 77bp。

## 4. 四个让它出局的问题

**4.1 剂量关系不成立。** 假设要求「余额越大、回补越强」，实际是 3–10% 档最强（+127.7，t 3.67），
≥10% 档反而只有 +50.8（t 2.08）。一个不单调的剂量反应，只能叫「某一档恰好为正」，
不能叫机制。按本仓的判据（恒正量的 t 不可读，必须看置换后效应消失 + 剂量单调），这一条直接否掉。

**4.2 不独立。** 同一只票的解禁常常连续多年发生（首发原股东、定增、股权激励分批）。
post 窗口 `[t+1, t+20]` 会与同一只票下一件事件的 pre 窗口 `[t_e−20, t_e−1]` 重叠。
按日聚簇只解决「同一天很多事件」，不解决「同一只票反复出现」——有效样本远小于 5,430。

**4.3 条件化。** post 从 t+1 开盘起算，把解禁日当天的跌幅排除在外。
也就是说，进入 post 样本的前提是「这只票在解禁日没有崩」。
这是幸存条件，不是随机化；真正的可执行收益必须包含解禁日那一段。

**4.4 不是净额。** +50.8bp 只回补了 pre20 的 18%（50.8 / 276.5）。
把两段接起来看，40 日净额仍是 **−225bp**。即使 post 的符号是真的，
「持有到解禁后」也不是一个能覆盖前段下跌的策略。

## 5. 如果要复活它，需要什么

1. **事件去重**：同一股票 12 个月内只保留首件；post 窗口与下一件 pre 不重叠，否则截断。
2. **匹配对照**：同日、同流通市值分位、同 120 日动量的最近邻，而不是全市场均值。
3. **预注册单调性**：先把「≥10% 必须 ≥ 3–10%」写成判据，再跑；不成立就撤回，不解释。
4. **样本外**：2023 年注册制之后单独跑一遍；两个子样本同号才算稳定。
5. **DiD 给 t**：现在只有点估计（+56.6），没有置信区间；要做 block bootstrap。
6. **容量与成本**：解禁日的流动性、冲击成本、涨跌停不可成交比例，都要进净额。

## 6. 结论

撤下。它唯一的位置是作为「解禁前 −276bp」这条排除规则的对照记录：
前段是负的、且单调；后段是正的、但不单调也不净。把后段写成买点，等于用最弱的一格解释机制。
