# 被迫交易方账本 + 日历（Forced-Counterparty Ledger）

> 核心命题：结构变化本身是一次性事件、不可交易；可交易的是**新结构稳定后持续制造的那条周期性被迫交易流**。
> 你的优势不是「算得更快」，是「约束集比对手少」——只有「慢 + 小 + 丑 + 容量小」的错位段，四类人都吃不了，才轮得到你。
> 本账本枚举 A 股当前结构里每一类**谁被迫、何时、往哪个方向、为什么非交易不可**，并标注本地数据资产与验证路径。

配套：`analysis/_diag_moat_filter.py`（可执行 moat 过滤器）+ `analysis/_diag_moat_filter_findings.md`（判定结果）。

---

## 0. 读法（每类被迫流的七个字段）

1. **被迫方**：谁是那个「非交易不可」的人（契约/风控/制度锁死，不是意愿问题）。
2. **何时**：周期性发生的日期。
3. **方向**：被迫买入还是被迫卖出。
4. **为什么非交易不可**：锁死它的约束是什么（这是 moat 的来源）。
5. **本地数据**：仓库里已有的资产，可直接回放验证。
6. **已有结论**：本仓库已经证出来的相关判据（带出处）。
7. **moat 判定**：这条流产生的错位段，过四层淘汰链后归谁。

## 1. 指数定期调样（纳入 / 剔除）

| 字段 | 内容 |
|---|---|
| 被迫方 | 指数基金（被动跟踪，契约锁死） |
| 何时 | 中证 / 上证指数半年度调样，约每年 6 月、12 月（具体生效日以中证指数公司公告为准，**需核实原文**） |
| 方向 | 纳入股被迫买入、剔除股被迫卖出 |
| 为什么非交易不可 | 跟踪误差约束：偏离指数权重会被监管与持有人问责，基金必须在生效日前后完成换仓 |
| 本地数据 | `data/kline_index_daily`、`data/instruments_index/instruments_index.parquet`、`data/backfill_20261117/index_daily_full.parquet`；**真实调样名单**已落地 `data/_csindex/`（中证指数官网公告附件 PDF，4 次调样） |
| 已有结论 | **已裁决（无 edge）**：①naive 代理证伪；②**真实名单驱动**（`_diag_index_rebalance_real.py`，1,471 事件）——调出股中位超额 −10.5bp（无回补）、调入股 +20bp（动量）、「买调出/卖调入」价差 −37bp。**被公告日抢跑 + 动量主导 + 被动资金占比小稀释**。见 `_diag_index_rebalance_real_findings.md` |
| moat 判定 | **无 edge**：被迫流存在但反转被抢跑/稀释，「做被迫方对手方」这个动作太便宜太公开 |

## 2. ETF 申赎与成分调整

| 字段 | 内容 |
|---|---|
| 被迫方 | ETF 做市商 + 申赎套利者（一篮子被动买卖） |
| 何时 | 每个交易日（申赎）＋ 成分股调整时点 |
| 方向 | 净申购被迫买入篮子、净赎回被迫卖出篮子 |
| 为什么非交易不可 | 做市商靠提供流动性赚价差，必须接单；套利者靠 IOPV 偏差套利，必须执行 |
| 本地数据 | `data/kline_etf_daily`、`data/instruments_etf`、`data/backfill_20261117/etf_daily_full.parquet`（1,720 只 ETF） |
| 已有结论 | 无 |
| moat 判定 | **归你（容量层）：篮子末端的小票被迫买卖冲击大、大资金不愿意碰** |

## 3. 退市 / ST 过渡清仓（最强的被迫卖压）

| 字段 | 内容 |
|---|---|
| 被迫方 | 公募 / 私募 / 险资（合同禁止持有 ST / 退市股） |
| 何时 | 面值退市逼近（连续 20 日收盘 <1 元）、退市整理期、ST 摘戴帽切换 |
| 方向 | 被迫卖出 |
| 为什么非交易不可 | 基金合同 + 风控红线：不能持有 ST / 退市股，叠加赎回压力 → 不计成本出清 |
| 本地数据 | `services/delisting_guard.py`（规则距离）、`data/backfill_20261117/stock_gap_daily.parquet`（306 缺口股，含「退」154 只） |
| 已有结论 | 「5% 涨跌幅指纹」不可用（precision .448）；本地前复权日线不保留涨跌停约束；只能算「当天规则距离」。（**2026-11-19 事件研究完整闭环**：无条件买跌证伪（20 日 EV −49%）；条件化「浅跌」候选 +970bp；**闸门 1 名单完整性通过**（本地终止交易数与 Wind 几乎一致）；**闸门 2 样本外证伪**——60 日 + 跨 regime 重算后浅跌端也负 EV，「保壳」被 2020 退市新规杀死。见 `_diag_delisting_forced_sell/_conditional/_completeness/_oos_findings.md`） |
| moat 判定 | **moat 真、edge 负（最终）**：四层全过但即便最优条件化仍无正 EV。信号真实（回撤深度→退市概率单调稳定），但只值「风控排除」，不值「买入」。**「约束集真空 ≠ 正期望」被证成定理。** |

**验证路径（未做）：** 用 `delisting_guard` 的规则距离定位「逼近面值退市」的票，测「规则距离跌破阈值 → 未来 20 日」的收益分布；正收益源 = 机构被迫清仓砸出的坑 + 之后回归。**必须与幸存者偏差隔离**（补全包的退市股要在样本内，否则高估）。

## 4. 龙虎榜席位流（机构 / 游资）

| 字段 | 内容 |
|---|---|
| 被迫方 | 上榜股当日被短线资金爆买（关注度驱动），次日无接盘 |
| 何时 | 每个交易日（异动上榜：涨跌幅 / 换手 / 振幅触发） |
| 方向 | 当日被迫买入 → 次日起均值回归 |
| 为什么非交易不可 | 触发榜本身是「已经大涨/大跌」的结果，追高资金次日撤退 |
| 本地数据 | `data/dragon_tiger/date=*.json`（246 日，2025-11 ~ 2026-11）、`services/dragon_tiger.py` |
| 已有结论 | `docs/dragon-tiger-org-vs-hotmoney.md`：上榜股事后 H20 **−400~−500bp** 一律跑输；「机构 vs 游资」在 1 年窗口不显著（n_eff<30，属「未见证据」非「证伪」） |
| moat 判定 | **不是你的（容量 + 舒适层）：上榜股流动性足够、标的干净，机构/被动能接，负向暴露不能提前交易** |

**该有的认知升级：** 龙虎榜不是买点，是**「谁被迫买入、之后谁撤退」的痕迹**。它真正能服务的是第 5 类的「对手方识别」——不是拿来选股，是拿来给别的被迫流做「归因时确认谁是接盘方」。

## 5. 季末 / 年末机构再平衡

| 字段 | 内容 |
|---|---|
| 被迫方 | 公募（季末调仓、年末做净值 / 排名） |
| 何时 | 3 / 6 / 9 / 12 月最后一个交易日附近 |
| 方向 | 卖出涨幅过高（兑现浮盈）、拉抬重仓（做净值） |
| 为什么非交易不可 | 排名与考核：季度 / 年度业绩排名决定规模与奖金，必须调仓 |
| 本地数据 | `data/shareholder`（时点持股）、`services/shareholder.py` |
| 已有结论 | 无（尚未做季末再平衡事件研究） |
| moat 判定 | **归你（慢 + 容量层）：季末卖压/拉抬是短周期动量反转，量化也做，但中小盘的季末效应容量小、机构自己不能吃** |

## 6. 涨跌停制度（封板 / 炸板）

| 字段 | 内容 |
|---|---|
| 被迫方 | 涨停板上排队买不到的人（被迫追高）、跌停板上卖不掉的人（被迫持有） |
| 何时 | 每个交易日 |
| 方向 | 涨停 → 被迫高位接；跌停 → 被迫持仓到开板 |
| 为什么非交易不可 | 价格优先 + 时间优先的撮合制度，一字板当日无法成交 |
| 本地数据 | `services/price_limits.py`、`data/kline_daily` |
| 已有结论 | 炸板率 40%→29.0%（量化系统性利用涨停机制）；「打板溢价」17 年无趋势，溢价全搬到隔夜（gap 占 117%）；`docs/hotmoney-quant-game.md` |
| moat 判定 | **不是你的（速度层）：涨停机制的高频残差已被量化吃完，日内腿（T+2 当日回合）已按此作废** |

## 汇总：六类被迫流的 moat 归属

| 被迫流 | 谁被迫 | 段落在哪（慢/小/丑/容量） | 归谁 |
|---|---|---|---|
| 指数调样 | 指数基金 | 小 + 容量 | **你** |
| ETF 申赎 | 做市商 | 容量 | **你** |
| 退市/ST 清仓 | 基金合同 | 丑 + 容量 | **你**（最强） |
| 龙虎榜席位 | 短线资金 | 干净 + 容量够 | 机构/被动 |
| 季末再平衡 | 公募 | 慢 + 容量 | **你**（部分） |
| 涨跌停制度 | 散户 | 快 | 量化 |

**结论收敛点：真正结构性归你的，是「指数调样、ETF 申赎、退市/ST 清仓、季末再平衡」这四类——它们共同特征是「被迫方是被合同/风控/制度锁死的机构，且错位段落在中小盘低流动性区」。这才是「凭什么是我」的可操作答案。**
