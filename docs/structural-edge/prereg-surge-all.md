# 预注册：全市场放量事件的锁仓分层（surge-all-2026-11-25）

> 状态：**冻结**，写定于 2026-11-25 13:40，运行之前。之后只追加 §6 观测记录。
> 上一版 `prereg-lock-surge.md` 已关闭：锁仓带内每天只有 3 只放量票，6 个月 MDE≈977bp，
> 判据 80bp 不可达。本版把事件面从「0.96% 带」扩到**全市场**，用**分位分层**替代绝对带。

## 1. 问题与它和上一版的区别

| | v1（已关闭） | v2（本篇） |
|---|---|---|
| 事件 | 锁仓带内 tr≥2 | **全市场** tr≥2 |
| 分层 | 与带内安静组比 | 按当日 `turn60` 横截面**五分位** |
| 事件量 | ~3 只/日 | ~300-500 只/日，最低换手档 20-60 只/日 |
| 功效 | MDE 977bp | 日期聚类 4,000 个，可测 80bp 量级 |

v2 问的是同一件事的推广版：**放量发生在「本来就没人交易」的票上，和发生在高换手票上，
后面的 20 日收益一样吗。** 聚类单位仍是月，不是股票日。

## 2. 冻结规则

**股票池**（每日横截面）：非 ST（按当前名称）、非北交所、上市 ≥250 交易日、
60 日均成交额 ≥1,500 万。

**事件**：`tr = 当日换手率 / 60 日均换手率 ≥ 2.0`。

**分层**：对当日通过股票池的全体股票，按 `turn60` 用 **rank 五分位**（`floor(rank/N*5)`，
min→Q1）。`tr ≥ 2` 的票落在哪个档，就归哪档。
用 rank 而不是 `qcut` 的固定边界：后者在并列值多的时候会把两档挤成一样。

Q1 = 最低换手档，Q5 = 最高换手档。

## 3. 指标（单一实现点：`analysis/_diag_surge_allmarket.py`）

- `exc20 = open[t+21]/open[t+1] − 1 − 全市场同日同窗等权均值`（T+1 开盘买、T+21 开盘卖）
- 日配对差 `d(t) = mean(exc20[Q1∩放量]) − mean(exc20[Q5∩放量])`
- **月聚簇**：`d(t)` 先按自然月平均，再对月序列求均值与 t（日级 t 会因重叠窗口虚高）
- 次：中位差、胜率差（P(exc>0) 之差）、五档均值序列（单调性）、Q1 放量的绝对净超额
- 成本：净 = 绝对超额 − 12bp（双边）

## 4. 判据（冻结）

评估日：**2027-05-31，或前向满 6 个月**，以先到者为准。

| 判据 | 阈值 |
|---|---|
| 主判据 | 月均 `d` **≥ +80bp** 且按月 t **≥ 1.65** |
| 红线 | Q1 放量组月均净超额 **≥ 0** |
| 稳健 | 正月份 ≥ 60%；五档单调（Q1>Q5 的月份 ≥ 60%） |
| 容量 | Q1 放量日均 **≥ 10 只** |
| 样本 | 前向 < 6 个月 → 不裁决 |

通过 → 页面在锁仓卡上显示「今日全市场放量票的换手档分位」作为**状态**，不改观察池；
否决 → 关闭，写回本文；想换端点/阈值 → 另写预注册。

## 5. 已知局限

- ST 按当前名称剔除（幸存者偏差，方向高估）。
- 一字板买不进：Q1 里更少（低换手票一字概率低），Q5 里更多 → 会**低估** Q5 的可执行收益，
  从而**高估** Q1−Q5 的差。这是本版最需要盯的偏差，报告里给一字占比。
- 2010-2019 与 2020-2026 的市场结构不同（注册制、涨跌幅、量化占比）；分层用分位已消除
  大部分水平漂移，但事件密度（放量日占比）仍会变。
- 未计冲击成本；Q1 的容量天然小，日均只数是硬约束。

## 7. 结果（2026-11-25 首次运行）与裁决

实现：`analysis/_diag_surge_allmarket.py`，产物 `data/_diag_surge_allmarket.json`。
样本：通过股票池的非 ST/非北交所/上市≥365 日/60日均额≥1500万，`tr≥2` 的全市场事件，
按当日 `turn60` rank 五分位（Q1 最低）。T+1 开盘买 → T+21 开盘卖，减同日全市场等权。

| 分档 | design 2010-2019（120 月） |  | holdout 2020-2026（82 月） |  |
|---|---:|---:|---:|---:|
| Q1（最低换手） | **−39.1bp** | t −2.02 | **−46.6bp** | t −1.65 |
| Q2 | −110.3bp | t −6.77 | −34.8bp | t −1.92 |
| Q3 | −145.9bp | t −7.67 | −58.4bp | t −3.15 |
| Q4 | −196.1bp | t −10.42 | −126.4bp | t −4.34 |
| Q5（最高换手） | **−297.3bp** | t −11.72 | **−304.4bp** | t −7.24 |
| **Q1 − Q5** | **+258.1bp** | **t +9.10** | **+257.8bp** | **t +4.45** |

- 正月份 79% / 72%；Q1>Q5 的月份 79% / 72%；Q1 放量日均 34.6 / 63.2 只（容量不是问题）。
- **市值控制**：在每个市值五分位内部重做 Q1−Q5，五档全为正 ——
  design +390/+395/+323/+214/+152bp（t 6.86/9.09/7.81/4.74/2.79），
  holdout +354/+382/+370/+225/+244bp（t 4.63/7.77/6.45/2.80/2.48）。
  效应在小市值更强，但不是「低换手 = 大市值」的代理。
- 一字占比 Q1 0.26-0.28% / Q5 0.27-0.45%：Q5 更买不进，会把 Q1−Q5 的差**高估**约 20bp 量级，
  不足以解释 258bp。

### 裁决

**分层成立，买入不成立；按冻结判据：否决（红线），不登记前向。**

- 主判据（差 ≥80bp、t ≥1.65）在两段都大幅通过，且是**单调**的：换手越高，放量后 20 日越差。
- 红线（Q1 净超额 ≥0）**不过**：Q1 扣 12bp 后 −51 / −59bp，t −2.02 / −1.65。
  最低换手档也不是买点，只是「少亏」。
- 不登记前向的理由：红线是**水平**判据，在 17 年、约 104 万个放量事件上已经为负；
  6 个月前向改变不了这个水平，登记只会得到又一个「样本不足」。这与 v1 的关闭理由不同：
  v1 是功效不足，v2 是结论已足够清楚。

### 与既有结论的关系

这条读数独立复核了 `footprint-20d-significance.md` 的「换手/成交额越强 → 20 日超额越差」
（那边是横截面指标，这边是**事件 × 分位**，样本与构造都不同）。两边的方向一致，
所以页面上的用法应该是**排除器**，不是选股器：

> 放量当天，最该降权的是「本来就高换手」的票（Q5，−300bp）；
> 「锁仓后首次放量」（Q1，−47bp）只是不亏得那么多，不是买点。

### 如果要继续

1. 把 Q1−Q5 的差当作**排序信号**（同一批放量票里优先看低换手的），而不是买入信号 ——
   这需要另一个预注册，端点改成「相对 Q5 的超额」，红线改成「Q1 ≥ Q5 的月份占比」。
2. 或者直接做成**风险提示**：页面上凡是 `tr≥2` 的票，按当日换手档标注「放量时的位置」。
   这一条不需要新预注册（它只是描述已测的截面读数），但要写进 `shortline-radar.md` 并加测试。
