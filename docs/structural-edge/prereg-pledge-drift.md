## 1. 问题

H11 发现 `ratio = 平仓线/股价` 与未来收益单调（Spearman −0.976）。H12 拆因果后：
- **券商定价分量**（折算 = 平仓线/质押日价）对未来收益**无效**（t 0.62 / −0.46）。
- **股价动态分量**（涨幅 = 质押日→公告日累计涨跌，中位 −14.6%）**强有效**（t 5.06 / 6.78），
  且与动量/换手/波动/规模/久期正交。

要确证的问题：**质押股在质押存续期内的累计涨跌，是否独立地预测未来 20/40/60 日收益**
（跌得越深、未来越差），且不是动量/换手/波动/规模/久期/券商定价的代理。

## 2. 冻结规则

**数据源**：东方财富 datacenter `RPTA_APP_ACCUMDETAILS`（重要股东质押明细）。
实现点：`analysis/_fetch_pledge_v2.py`（回填）+ `analysis/_diag_pledge_drift.py`（检验）。

**股票池**：非 ST（按当前名称）、非北交所、上市 ≥ 250 交易日、60 日均成交额 ≥ 1,500 万。

**事件**：质押公告，去重到股票-日（同日多股东合并），
入场 = 公告日后第一个交易日**开盘**，出场 = t+21 / t+41 / t+61 **收盘**。

**信号（冻结，唯一实现点）**：
```
pledge_drift = CLOSE_FORWARD_ADJPRICE_TODAY / CLOSE_FORWARD_ADJPRICE − 1
```
- `CLOSE_FORWARD_ADJPRICE` = 质押日前复权价（东财字段）
- `CLOSE_FORWARD_ADJPRICE_TODAY` = 公告日前复权价（东财字段）
- 两个都是前复权口径，消除除权噪声；pledge_drift 在「公告日收盘」可观测，入场在次日开盘 → 无前视。

**过滤**（写死，防噪声）：折算 `openline / CLOSE_FORWARD_ADJPRICE ∈ [0.3, 0.9]`；
`pledge_drift ∈ [−0.5, +0.5]`。

**分层**：月度截面内对 `pledge_drift` 做 **rank 三分位**（`floor(rank/N*3)`，min→Q0）。
Q0 = 跌得最深，Q2 = 涨得最多。

## 3. 指标（单一实现点：`analysis/_diag_pledge_drift.py`）

- `fwd20/40/60 = close[t+h]/open[t+1] − 1`（t+1 开盘买，t+h 收盘卖）。
- 主指标：`d(t) = mean(fwd60[Q2]) − mean(fwd60[Q0])`，**月聚簇**后求均值与 NW t
  （日级 t 会因重叠窗口虚高；月是聚类单位）。
- 次：fwd20 同式；控制回归 `fwd60 ~ z(pledge_drift) + z(ret250)+z(ret60)+z(vol20)+z(turn20)+z(size)+z(D)`，
  月截面系数均值 + NW t（这是「独立于动量/换手/波动/规模/久期」的核心证据）。

## 4. 判据（冻结）

评估日：**2027-03-31，或前向满 3 个月**，以先到者为准。

| 判据 | 阈值 |
|---|---|
| 主判据 | 月均 `d` **> 0** 且 NW t **≥ 2** |
| 独立性 | 控制回归 `pledge_drift` 系数 **> 0** 且 t **≥ 2**（不含 ret250 也须成立） |
| 稳健 | 正月份 ≥ 60% |

通过 → 记录为「质押存续期涨跌」风险信号，作为**排除器**（回避深跌质押股），不做多/做空；
否决 → 关闭，写回本文；想换端点/阈值 → 另写预注册。

## 5. 已知局限（诚实标注）

1. **质押日=高点选择偏差**：大股东倾向在股价高位质押（借更多钱），`pledge_drift` 深负 ≈ 距质押日
   高点回撤。本文**不能**区分「质押因果导致下跌螺旋」vs「高位质押后的趋势延续」。两者对
   「深跌质押股该回避」等价，对机制不同。
2. **弱 OOS 污染**：H11/H12 已看过全样本，本文 §6 的 design/holdout 检验只是符号稳定性先行，
   不是干净的样本外；最终裁决依赖评估日前向数据。
3. **幸存者偏差**：只含在市股票；已退市/ST 的质押股不在库，方向高估（退市的深跌质押股更差）。
4. **是排除器不是做空**：A 股融券有限，`pledge_drift` 深负只能「回避」，不能直接做空。
5. **前复权依赖东财字段质量**：若 `CLOSE_FORWARD_ADJPRICE` 存在除权错配，信号会衰减。
6. **未计成本**：报告净超额时减双边成本，但本预注册主判据用毛口径，容量/成本另议。

## 8. 容量与成本核算 + 排除器方案（定稿，2026-11-26）

### 8.1 成本（相对全市场等权超额，毛=净，排除器无交易成本）

阈值 drift < −30%（占质押股 27.6%，5,666 事件 / 1,345 只）：

| 分解 | 占比 | 平均 exc60 |
|---|---|---|
| 排除对（未来跑输） | **69.3%** | **−1,329bp** |
| 误杀（未来跑赢） | 30.7% | +1,473bp（中位 +917bp，p90 +3,408bp） |
| **净期望** | — | **−468bp** |

关键：深跌质押股是**双峰分布**——69.3% 继续阴跌，30.7% 深跌反弹大涨。所以这不是「单调跑输」，
是「高分化」。净期望 −468bp 说明「随机买入深跌质押股平均坑」，但尾部有 +1,473bp 的反弹。

### 8.2 容量

| 项 | 读数 |
|---|---|
| 瞬时名单（60 日有效期内） | ~234 只（日均 3.9 个新公告 × 60 日） |
| 占全市场 | ~4.5%（全市场 5,225 只；有质押 2,286 只 = 43.7%；深跌 27.6%） |
| 信号时效 | fwd20 −119bp → fwd60 −468bp，20-60 日都有效且累积 |
| 数据源 | 东财质押明细，每日增量拉取（~160 页 / 2 分钟） |

### 8.3 排除器方案（定稿）

**规则**：买入决策时查「最近一次质押公告的 pledge_drift」；drift < −30% → 标记「质押深跌」状态，
60 个交易日内有效。

**形态：状态标记（买点警告），不是硬排除。** 理由：
1. 误杀尾部代价大（30.7% 的深跌反弹 +1,473bp，p90 +3,408bp），一刀切会漏掉深跌反弹牛股。
2. 本项目先例（surge-all）：「红线不过 ⇒ 排除器/状态标记，不是买点」。
3. 净期望 −468bp 是「平均坑」，适合做警告项，不适合做一票否决。

**升级条件（已满足，见 §9）**：交叉检验确认「深跌质押股的深跌反弹（30.7%）**从不**通过买点六问」
——且不是历史巧合，是规则定义级（买点六问第 1 问把载体钉死为行业 ETF，个股连第 1 问都过不了）。
故升级为「硬排除」。

**但「升级为硬排除」对当前买点的增量约束 = 0**：个股本就不在买点池里（买点只买行业 ETF），
「标记」和「排除」对买点六问的影响完全相同（都是零）。所以这个「硬排除」的真实定位是——
**「若未来买点扩展到个股」才生效的硬排除规则** + 一个独立的个股风险研究结论；
对当下 ETF 买点，它既不挡任何一笔，也不省任何一笔。

**误杀的机会成本口径（已由 §9 关闭）**：误杀的「错过 +1,473bp」从不构成机会成本，因为那 30.7% 的
深跌反弹牛股是**个股**，本来就不会进入买点池。之前 §8.3 用「可能有限」是保守口径，
§9 把「可能有限」收敛成「结构性为零」。

## 9. 交叉检验：深跌质押股 ∩ 买点六问通过集（2026-11-26）

`analysis/_diag_pledge_buyset_overlap.py` → `data/.scratch/leverage/pledge_buyset_overlap.json`。

买点六问（`frontend/src/pages/structural-edge/data.ts` `buyQuestions`）第 1 问是
**「载体：行业 ETF，不买个股」**——载体是硬性排除，不是软偏好。所以「买点六问通过集」的载体空间
∈ {行业 ETF}，而深跌质押股 ∈ {A 股个股}，两个证券代码空间不相交。

数据坐实（非读代码推断）：

| 集合 | 数量 | 代码前缀 | 含 ETF |
|---|---|---|---|
| 深跌质押股（drift < −30%） | 5,666 事件 / 1,345 只 | 300/002/603/600/000/301/688/601/605/001/003 | **0 只** |
| 全部质押股 | 2,286 只 | 同上 | **0 只** |

- **交集 = 0**，且是**结构性空集**——不是「历史恰好没重合」，是「规则定义上不可能重合」。
- 因此深跌质押股的「深跌反弹」(30.7%, 平均 exc60 +1473bp) **从不构成误杀机会成本**：它们是
  个股，本来就不会进入买点池。

**结论**：
1. §8.3 写死的升级条件满足 → 升级为「硬排除」。
2. 但「硬排除」对当下 ETF 买点增量约束 = 0（个股本就不买）。它不改变任何一笔 ETF 买卖。
3. 真实定位：`pledge_drift < −30%` 是一条**「若未来买点扩展到个股」才生效的硬排除规则**，
   同时是一个**独立于换手/波动/规模/久期/动量的个股风险研究结论**（深跌质押股继续阴跌）。
4. 对当前账户（行业 ETF + 国债现金腿）而言，本信号**零直接影响**；它的价值沉淀在研究层，
   不是执行层。

## 10. 信号效果模拟（评估日前，逐日前向回放，2026-11-26）

`analysis/_diag_pledge_drift_sim.py` → `data/.scratch/leverage/pledge_drift_sim.json` + `_nav.csv`；
拆解 `pledge_drift_sim_decomp.json`。

**做法**：把信号当成一个「逐日滚动、无前视」的多-空组合回放——每个质押公告日，按冻结规格
（月度截面 rank 三分位）把事件分到 Q0/Q1/Q2，从次日开盘起做多 Q2（浅跌/涨）、做空 Q0（深跌），
各持 60 日，逐日聚合滚净值。20,548 事件 / 80 个月 / 2020-01 ~ 2026-08。

**多-空对冲（理论信息量）**：

| 指标 | 读数 |
|---|---|
| 累计净值 | **+484.6%**（7 年） |
| 年化 | **+30.4%** |
| 波动 / Sharpe | 6.5% / **4.66** |
| MDD | −6.7% |
| 年度收益 | 2020 +32.9 → 2021 +15.1 → 2022 +11.5 → 2023 +21.7 → 2024 +24.5 → 2025 +37.9 → 2026 +64.0（**7 年全正**） |

**但这个 Sharpe 4.66 是乐观上界，必须拆开看**（`_decomp.json`）：

| 分位 | 绝对 fwd60 | 相对全市场等权超额 |
|---|---|---|
| Q0 深跌 | −113bp | **−439bp** |
| Q1 中 | +228bp | −92bp |
| Q2 浅跌/涨 | +573bp | **+246bp** |

- 多-空对冲（相对全市场中性）= Q2 超额 +246bp − Q0 超额 −439bp = **+685bp/60 日**。
- **做空 Q0 端贡献 439bp（占 64%，最大）**，但 A 股个股融券受限，**这条腿不可执行**。
- Q2 绝对 +573bp 里，**57% 是全市场 beta，只有 43%（+246bp）是信号超额**。

**可执行口径（纯做多「回避」）**：

| 口径 | 相对全市场等权超额 |
|---|---|
| 基准：买全部质押股等权（Q0+Q1+Q2） | −95bp/60 日 |
| 策略：剔除 Q0（只买 Q1+Q2） | +77bp/60 日 |
| **改善（回避收益）** | **+172bp/60 日** |

**成本敏感性**：多-空对冲对双边成本不敏感（50bp 只把年化从 30.4% 降到 26.2%）——但这是
「换手假设偏乐观（8.3 次/年）+ 假设可做空」的上界，不是可交易数字。

**模拟的诚实结论**：
1. 信号的**截面信息量真实且稳定**（7 年每年正、截面差 +685bp、MDD −6.7%）。
2. 但 **Sharpe 4.66 不可当作「发现了新 alpha」**——「做多涨/浅跌、做空深跌」天然是动量因子的
   极端暴露（drift 本身就是质押存续期累计涨跌），加上样本内、无成本、假设可做空，三重乐观。
3. 做空腿（贡献 64% 的超额）A 股不可执行；**可执行的只有「纯做多回避」，增量 ≈ +172bp/60 日**。
4. 这个 +172bp 相对 §8 的静态 −468bp 坑更准确地定义了「回避深跌」的**可落地价值**——它不是
   30% 的对冲，是「不买深跌质押股、改买非深跌质押股」的 +172bp 增量。
5. 最终定位不变：**独立个股风险信号 + 未来个股腿的候选排除规则**，对当前 ETF 账户零直接影响。
