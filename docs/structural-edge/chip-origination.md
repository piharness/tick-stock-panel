## 0. 一句话

**价格不记得谁在什么价位买过；价格只对「谁刚刚把自己押上去」有反应。**

筹码不是存量，是发起（origination）：
一份有日期、有金额、有具名对手方、有强制条款的合约，被某个人在某一刻创造出来。
存量是状态，状态已经被定价；发起是新闻，新闻才产生漂移。

# 第一部分 · 九项升级

## 1. 我原来实际上在要求什么

表面上：把 `/chip` 的理论写得更大胆。

实际上：**给三次换对象找一个共同的死因。**

卷一建了势场，卷二把它改名为介质，卷三换了坐标（价格 → 时间）。
三次都失败了，而且失败的方式一模一样：**换完之后，测的还是一个横截面上的状态量。**
所以真正的要求不是「第四个状态变量」，而是：

> **为什么这类数据（持仓、成本、年龄、网络、合约余额）天生只能给出这么点信息？**

这个问题的答案会比任何一个因子都耐用：它决定了以后拿到任何一份「筹码」数据，先知道它能回答什么。

## 2. 最重要的认知局限与未经验证的假设

| # | 被默认成立的假设 | 为什么可疑 | 代价 |
|---|---|---|---|
| 1 | **持仓是可观测的** | 只通过强制/自愿披露观测：十大流通股东（季度）、质押公告（事件）、大宗（成交后）、龙虎榜（异动后）。观测即选择。 | 把选择偏差当噪声；而它其实是信号本身。 |
| 2 | **分布是对象的充分统计量** | 分布是非负测度：它能告诉你「多少」，不能告诉你「往哪卖」。收益效应有符号，分布没有。 | 符号只能靠估计发现，于是 OOS 翻转。 |
| 3 | **水平会预测收益** | 水平是状态，状态已被公开信息定价；只有**创新**（news）才产生预期收益。 | 用 state 当 signal，系数必然被控制变量吸干。 |
| 4 | **持有人类型 = 凸性** | 基金有赎回、法人有质押、个人可能是抄底者。类型是先验，不是凸性测量。H2 已证伪。 | 伽马不可识别，合成符号为零。 |
| 5 | **价格路径能推出被迫交易** | H3/H8：快速跌进成本区是反弹，放量是对称放大器。A 股边际持有人是抄底的。 | 用路径代理约束，测到的是短期反转。 |
| 6 | **伽马/网络/相变是独立维度** | H5 中心度=蓝筹轴；H6 无阈值；H7 比值=分子换手。 | 三个「新维度」都是旧变量的重新包装。 |
| 7 | **事件研究是更强的检验** | 事件有信息，但事件的选择也内生：解押发生在股价修复之后（C2）。 | 把选择当外生，事件效应会被高估。 |

**最贵的一条是 1。** 前六条是「测错了变量」，第一条是「看不见的东西被当成没有」。
所有筹码数据都是**被选择出来的样本**：大股东选择何时质押，基金选择何时进十大，游资选择何时上榜。
把选择当外生，等于把信号当噪声；把披露当全体，等于把冰山当整座山。

## 3. 高度升级后的真正目标

> **把筹码从「持仓的统计」升级为「约束的发起」，并回答三个问题：**
>
> 1. **谁发起？**（发送者的身份、信息优势、资金约束）
> 2. **以什么条款发起？**（平仓线、折扣、期限、规模）
> 3. **发起之后，价格反应多久？**（事件时间上的漂移/反转/一次性）

验收不是「找到一个因子」，而是：**能预测哪一种发起会漂移、漂多久、在谁身上、在什么注意力条件下。**

## 4. 深度升级：应该使用的数据、工具、方法

### 4.1 数据（本仓库已有，按「事件/状态」重排）

| 数据 | 形式 | 在新理论里的角色 |
|---|---|---|
| 质押明细（2019+，8.2 万条，含起止日/平仓线/比例/持有人/原因） | **发起事件** | 唯一有日期、条款、具名发送者的约束发起 |
| `top_float` 十大流通股东（季度） | 状态 + 变化 | 「新进/退出」是事件；「占比」是状态 |
| `block_trade` 大宗交易（2005+） | **发起事件** | 折价 = 即时性的价格；首次出现 = 事件 |
| `dragon_tiger` 龙虎榜 | **发起事件** | 首次上榜 vs 连续在榜；席位是发送者 |
| 解禁/定增破发 | **发起/到期事件** | 日期固定、条款固定，天然准实验 |
| `margin` 两融（市场级） | 状态 + 创新 | 2015 的总量自然实验 |
| 日线/5min | 结果变量 | 事件时间上的漂移、波动、尾部 |

### 4.2 工具

- **选择模型**：Heckman 两步、hazard、竞争风险——把「是否披露/何时披露」建成第一层。
- **事件时间金融**：CAR、buy-and-hold abnormal return、cohort、calendar-time portfolio。
- **披露理论**：costly signaling、自愿 vs 强制披露、披露时机。
- **文本分类**：`PF_REASON` 分成「补充质押/追保」「新增融资」「个人资金需求」——发送者的理由就是发送者的状态。
- **注意力代理**：换手、市值、龙虎榜、涨停——反应不足应在低注意力处更强。
- **分解**：任何变量先拆成 level 与 innovation；只检验 innovation。

### 4.3 方法：从「横截面归因」到「选择 + 事件时间」

| 旧方法 | 新方法 | 差别 |
|---|---|---|
| `fwd20 ~ X + controls` | `fwd ~ 发起 + 前路径匹配 + 事件时间` | 从「谁高谁低」到「谁做了什么」 |
| 把事件当外生 | 第一层估 `π(发起|状态)`，第二层估 `E[ret|发起, π]` | 选择本身是信号 |
| 水平五分位 | level / innovation 分解 | 状态已被定价 |
| 单数据集 | 迁移检验（质押→大宗→十大变化） | 区分「一般理论」与「质押特例」 |
| 日历月 | 事件时间 + cohort | 漂移的形状 |

## 6. 一个更强的任务定义

> **不问「筹码结构预测什么」，问「谁在什么约束下、为什么在此刻、把自己押上去；这个动作对价格的冲击持续多久」。**
>
> 三个可测对象：
> 1. `π(发起 | 状态)`：选择的概率（谁在什么条件下出现）；
> 2. `terms`：条款（线、折扣、期限、规模）；
> 3. `drift(τ)`：发起后第 τ 天的超额（形状，不是符号）。

判据：能否在事件时间上复现漂移、能否用发送者/条款/注意力分层、能否迁移到第二个披露数据集。

## 11. 状态 vs 发起：一个二分解释十六个结果

### 11.1 形式

设状态变量 `X_t` 是非负测度或它的矩（密度、久期、熵、中心度、占比、余额）。
设发起变量 `O_t` 是一个离散动作：某发送者在 t 时刻创造了/撤销了一份有条款的合约。

- `X_t` 没有符号：它只说「多少」，不说「往哪」。
- `X_t` 没有日期：它是快照，分不清「还没发生」和「不会发生」。
- `X_t` 没有对手方：它是聚合，约束不可执行。

`O_t` 三者都有：动作有方向（押/卖/披露），时点有日期（公告/到期），发送者有名字（大股东/券商/基金）。

**资产定价的第一课**：只有创新（`X_t − E_{t−1}X_t`）是 news，水平是 state，state 已被定价。
筹码研究十几年一直在 regress state on future return——这就是零的来源。

### 11.2 十六个结果

| # | 检验 | 形式 | 结果 | 读法 |
|---|---|---|---|---|
| H1 | 久期 D/T | 状态 | 半活：两条风险主效应，收益零 | 非负量，符号靠估 |
| H2 | 持有人伽马 | 状态（类型） | 合成零、分项反转 | 类型不是凸性 |
| H3 | 成本带穿越 | 状态（路径） | 雪崩格反向 +116bp | 路径推不出约束 |
| H4 | 年龄熵 | 状态 | 冲击深度混淆 | 熵=久期 |
| H5 | 网络中心度 | 状态 | 蓝筹轴，尾部反向 | 共同持有≠共同义务 |
| H6 | 记忆相变 | 状态 | 无阈值（BIC −4.5） | 阈值不在 D 里 |
| H7 | Θ 滚续比 | 状态 | 比值噪声，分子 t 12.2 | 没有到期日 |
| H8 | 放量 | 状态（量） | 对称放大器 | 量没有方向 |
| H9 | 融资/质押水平 | 状态 | 代理/不雪崩 | 水平不是触发 |
| H11 | 质押公告贴线 | **发起** | f20 −131bp / t −4.02；f60 −474bp | 唯一活着 |
| H12 | 拆因果 | **发起** | 涨幅分量 t 5.06/6.78；折算无效 | 是「披露+漂移」，不是「券商定价」 |
| C1 | 存量簿 near / wdist | 状态 | v1 受控 −0.1bp / t −0.01；v2 全修 +6.0 / t 0.34、wdist −13.7 / t −0.23 | 零；v1 的原始符号是口径 artifact |
| C2 | 解押安慰剂 | 发起（内生） | +763bp / t 2.31，5 只/月 | 不可识别 |

| C4 | 贴线 × 到期 | 状态×日期 | −34.6bp / t −1.06 | 无 |
| F1 | 新合约贴线 vs 有簿但远 | **发起** | +6.9bp / t 0.04；9 只/月 | 样本太薄 |

**十二个状态检验，零个稳定的收益符号；四个发起检验里，两个是同一个信号的两面（H11/H12），
两个是诊断（C2 不可识别、F1 样本太薄）。**
这不是十六次独立试验，是一个二分。

### 11.3 为什么不是「事件研究都成立」

H8 也是一个事件（放量），H3 也是（穿越），但都不成立。区别不在「事件 vs 状态」，在**发起 vs 反应**：
- 穿越、放量是**价格对价格**的反应，没有新信息、没有发送者、没有条款；
- 质押是**人创造合约**的动作，有发送者、有条款、有日期、有成本（利息）。

所以更准确的说法是：**只有「有成本、有发送者、有日期」的动作才携带符号。**
价格路径的事件只是状态的另一种写法。

## 12. 为什么 A 股是这件事的天然实验室

卷三已经测出：A 股的边际持有人是抄底的（H3 下穿快 +116bp；H8 放量下跌仍反弹）。
这意味着**自愿持有人是稳定器**：价格跌，他们买。
于是市场唯一的失稳来源，只能是**被迫卖方**；而被迫卖方必须由合约创造。

A 股恰好有一个巨大、公开、有日期、有条款的合约发起渠道：股权质押。
2013–2018 的质押扩张，2018 的纾困，2024 的减持新规，都是**条款的外生变动**。
这解释了为什么十六个检验里只有质押活下来：不是因为它最聪明，是因为它是唯一一个
**把「谁、何时、以什么价格、把自己押上去」写进公开数据的**渠道。

推论【猜想】：A 股的均值回归不是行为规律，是**约束发起量不足**时的结构性质。
当发起量上升（2015 两融、2018 质押），市场的回路增益上升，尾部变厚。
这条只能用总量检验（E5），不能用横截面。

## 13. 选择的三个维度

| 维度 | 状态量 | 发起量 | 为什么决定符号 |
|---|---|---|---|
| **符号** | 密度/久期/熵/中心度/占比 | 押/卖/披露 | 幅度只能估符号；动作的符号由约束给定 |
| **日期** | 月末/季度快照 | 公告日/到期日/解押日 | 没有日期，分不清「没发生」与「不会发生」 |
| **对手方** | 聚合/类型/网络 | 具名大股东/券商/基金 | 没有对手方，约束不可执行 |

**一句话**：分布没有符号，合约有；分布没有日期，合约有；分布没有对手方，合约有。

## 14. 存量簿：零，而且 v1 的符号是口径 artifact

### 14.1 对象与口径

从 `pledge_raw_v2.parquet`（8.2 万条明细，含 `PF_START_DATE` / `UNFREEZE_DATE` / `OPENLINE` / `PF_TSR` /
`IS_CONTROL_SHAREHOLDER` / `PF_REASON`）重建**活合约簿**：

```
t 日活合约 = start ≤ t 且（unfreeze > t 或 未解押且无到期日）
book_t      = Σ PF_TSR                       活合约占总股本 %
near_share  = Σ PF_TSR·1{openline/close ∈ [0.8,1.2]} / book
wdist       = Σ PF_TSR·(openline/close) / book
exp_share   = Σ PF_TSR·1{unfreeze ∈ (t,t+90]} / book
```

### 14.3 规格坑

`near_share` 是 `ratio` 的**倒 U 变换**：股价下跌 → ratio 上升 → 进入 `[0.8,1.2]` → 继续跌 → 离开（变 breached）。
所以 near_share 的五分位混了「正在靠近」和「已经跌穿后离开」两种状态，单调性被破坏。
H11 的剂量是 `ratio` 本身单调（0.3→1.2 越来越差），连续版必须用 `wdist`，且必须同时报 `breach_share`。
**任何「贴线占比」的信号，先画它与 ratio 的关系；倒 U 会把符号吃掉。**

### 14.4 v1 裁决

v1 看起来是「存量与事件原始符号相反」：存量越贴线，未来收益越高（+266bp）；事件贴线，未来收益越低（f60 −474bp）。
但这个对比有一个隐患：**v1 的平仓线是原始价，价格是前复权价**。老合约的距离被系统性放大，横截面上的「远近」
混进了复权历史。所以 v1 的「正 vs 负」不能当作理论的证据，只能当作一个待查的口径。

真正要回答的是：**修完口径之后，存量还是零吗？** 这由 §14.5 单独裁决；E1–E5 不参与。

### 14.5 测量缺口单独一版：v1 → v2【实测】

存量簿的零有两种解释：理论（状态已定价）或测量（口径错）。这一节把八个缺口逐个过一遍：
能修的修，不能修的标出来，看零还在不在。目的不是给存量找活路，是把「测量」这个替代解释量化。

**八个缺口，按影响排序：**

| # | 缺口 | 影响 | v2 处理 |
|---|---|---|---|
| G1 | 平仓线未复权：raw line / adj close | 2019 起始合约因子中位 0.90、2015 约 0.71 → 距离被放大 10–40%，足以把「贴线」推成「已穿」 | `K_adj = line × C[start]/raw[start]` |
| G2 | 入场用合约起始日，不是公告日 | `[start, notice)` 用了市场还不知道的合约 → 前视 | `entry = max(start, notice)`；起始日早于日线起点按 2019 年初入簿 |
| G3 | 到期日语义混用 | 未解押的计划到期日被当成实际解押日 → 活簿被提前截断 | 未解押一直活；已解押按实际日 |
| G4 | 「已解押但无日期」占 32% | 整行丢弃 → book 系统性低估 | v2c 按 notice+365d 补寿命（敏感性） |
| G5 | 分母是总股本，不是流通盘 | 限售比例高的股票，簿占比被低估；横截面不可比 | 未修（需历史流通股本） |
| G6 | 生存偏差 + 当前 ST 过滤 | 退市/后来 ST 的质押股被剔除 → 高杠杆组被美化 | 未修（需历史名称/退市表） |
| G7 | 月频采样 | 事件效应可能集中在公告后数日；月末快照会漏掉 | 事件时间单独测（H11/H12） |
| G8 | 簿加权稀释单份新合约 | wdist 被老合约拉平；near_share 是占比不是敞口 | 同时报 max ratio / 单合约距离（未做） |

**五变体（受控系数，f60，控制同 §14.1；n≈8.5–13.8 万股票-月）：**

> （合约去重/入场规则）。变体之间可比；不要跨表比绝对值。

**裁决：**

1. **v1 的负号主要来自 G1，不是来自约束。** 不复权（v2a）仍是旧符号；复权（v2b/v2）就归零，
   且 v2 与 v2b 完全相同 → G2 无影响；G3 在三个变体里都开着，不能单独识别，但不可能是主因。
2. **修完 G1–G3，存量是零，不是负。** 这不是「存量被救活」，是「存量连弱负号都没有了」。
   所以 v1 的「正 vs 负」对比作废；真正稳定的对比是「**存量零 vs 事件负**」。
3. **G4 让存量偏正**（v2c near +24.7 / wdist +117.5，t≈1.5–2.0）。补缺失解押日会把老合约留得更久，
   这些合约的平均距离更远，横截面更像「老公司/低估值」——仍然是 tilt，不是约束。
4. **G5–G8 未修**：它们只能让存量更不准，不能把一个零变成稳定的负号；但也不能排除。
   在补齐历史流通盘/退市表之前，存量零的结论应写成「**在可修的口径内为零**」。
5. **事件侧不受 G1 影响**：H11 的 `ratio = openline / CLOSE_PRICE` 是公告日的 raw/raw；
   H12 用两个前复权价相除。事件研究的尺度是自洽的，所以「事件负」不是同一个 artifact。

**一句话：测量缺口修完后，存量零更硬了；v1 的「原始符号相反」被降级为口径 artifact，不再作为理论支点。**

**顺带**：v2 的波动系数仍是 −0.011pp（t −2.0）——贴线股未来 20 日波动略**低**，不是更高。
短伽马读法（贴线 → 波动上升）在修正口径后仍没有证据；这条不依赖 G1。

## 15. 理论收窄

首测之后，「约束簿」必须降级为**「约束的发起」**：

| 版本 | 命题 | 状态 |
|---|---|---|
| 强版本 | 活合约簿的水平预测收益 | **死**（C1/C1b/C1c 零或反向；v2 修 G1 后归零，v1 的弱负号是口径 artifact） |
| 中版本 | 簿的创新（Δwdist/Δnear）预测收益 | **不稳**（Δwdist +10bp / t 0.43；Δnear −29.5bp / t −4.65，符号相反） |
| 弱版本 | 合约的**发起事件**预测漂移，且随发送者/条款/注意力分层 | **活**（H11/H12；E4 形式过、符号半过） |

这不是退让，是把「筹码」从一个**名词**（存量）收窄成一个**动词**（发起）。
一个动词才可能有符号；一个名词只能有大小。

# 第四部分 · 下一轮

## 16. 迁移（E4）单列：形式可迁移，符号不迁移

### 16.1 假设到底是什么

E4 不是「在别的数据里再找一个显著」。它要检验两件分开的事：

- **形式（form）**：在任何披露数据里，**发起**（有日期、有对手方、有条款的动作）应该压过**存量**（累计量/平均水平）。
  这是**数据集内部**的比较，自动控制了数据集特有的混淆。
- **符号（sign）**：符号不迁移，符号由**义务的方向**决定。
  必须卖 → 负；必须买 → 正；自愿（没有义务）→ 0 或不稳。

所以 E4 的判据不是「都显著」，而是一个**带负控的符号排序**：

| 发起类型 | 例子 | 符号预测 | 为什么 |
|---|---|---|---|
| 强制卖方 | 质押贴线、深折价大宗、临近解禁 | **−** | 卖方必须卖，价格是即时性的代价 |
| 强制买方 | 回购、增持 | **+** | 买方承诺了买 |
| 自愿方 | 十大流通股东「新进」 | **0 / 不稳** | 自愿建仓，没有义务；符号不由合约给定 |

**三个必过的关：**
1. 同一数据集内，发起 > 存量（形式）；
2. 强制卖方为负、强制买方为正（符号反转，不只是「事件有效」）；
3. 自愿发起 ≈ 0（负控）。

**杀死**：三类发起同号 → 只是「事件溢价」或「坏消息漂移」；只有质押成立 → 质押是特例；
自愿发起和质押一样强 → 不是义务，是「新信息」；存量在别的数据集也显著 → 状态/发起的二分是质押特有的。

### 16.2 第一个迁移：大宗交易【实测】

深折价 = `min(premium_doc) ≤ −5%`；溢价 = `max(premium_doc) ≥ +2%`；入场次日开盘，出场 t+61 收盘。

| 检验 | 读数 | 裁决 |
|---|---|---|
| 存量：60 日大宗占比五分位 → f60 | Q1 +350.1 → Q5 +302.0bp；Q5−Q1 −48.1bp / t −0.88；受控 −11.8bp / t −1.48 | **零（形式过关）** |
| 发起：溢价首次 → f60 | +384.8 vs other +230.8bp；差 **+154.1bp / t 2.13**（控制回归仅 4 个月事件数≥20，欠功效） | **正号（原始过）** |
| 发起：深折价首次 → f60 | +271.4 vs other +230.8bp；差 **+40.7bp / t 0.77** | **不是负号（符号失败）** |

**读法**：形式过了（存量零、事件有差异），第一刀符号只过了一半（溢价为正，深折价为不为负）。
注意：溢价的 t 2.13 是月聚簇原始差；控制回归只有 4 个月事件数 ≥20，欠功效。深折价不是干净的「被迫卖方」代理：
大宗里混着控股股东转让、税筹、战略接盘，折价可能只是流动性/税的成本，不是强平的信号。
**拆买卖方类型后，符号直接翻转，见 §16.3。**

**其余三个迁移对象（设计，未裁决）：**

| 数据 | 存量（应≈0） | 发起（应有符号） | 符号 | 就绪度 |
|---|---|---|---|---|
| 龙虎榜 | 在榜次数 / 席位存量 | 首次上榜 + 卖方集中 | − / 0 | 2025-11 起，样本太短，不裁决 |
| 十大流通股东 | 基金持股占比 | 新进前十大（首次） | **0 / 不稳（负控）** | 2024-12~2026-09，8 季，功效低 |
| 回购 / 增持 | 回购余额 | 首次公告 / 实施首日 | **+** | 待确认数据 |

**E4 现状：形式 1/1 过，符号不可识别（§16.3），迁移 1/4 跑。它是一个「半活」的假设，不是结论。**

### 16.4 2012–18 机制拆解：质押 / 定增 / 都不是

数据：41,834 条质押 + 3,084 条定增（2012–2018）；469 件 inst_deep。
P = 事件日有活质押（start≤t 且 unfreeze>t 或未解押）；S = 事件日落在定增锁定期内。

| 桶 | inst 事件 | broker 事件 | inst f60 | 读法 |
|---|---|---|---|---|
| 质押（P） | **0 / 469** | 2,790 | — | 机构卖方零重叠；质押强平走营业部 |
| 定增（S） | **364 / 469** | 0 | −302.8bp | 全是机构卖方；2012–15 +996 / 2016–18 −585 |
| 两者都不是 | 105 / 469 | 2,020 | −279.6bp | 负号仍在 ⇒ 不是质押/定增专属 |

| 检验 | 读数 | 裁决 |
|---|---|---|
| P 主效应（非机构） | −10.7bp / t −0.57 | 不显著 |
| P × inst 交互 | 不可识别：inst 807 件里 P=0 | 零重叠 |
| 无质押组的 inst 效应 | **−350.6bp / t −3.42** | 负号更强 |
| S × inst 交互 | 共线：S=1 的 364 件全是 inst | 不可识别 |
| S 与非 S 的月度重叠 | 2014–17 全 S；2019+ 全非 S；同月重叠 1 个月 | 与时代共线 |
| S 桶 2012–15 / 2016–18 | **+996.3bp（65）/ −585.2bp（299）** | 符号翻转 |

**读法：**

1. **质押不是驱动。** 807 件全样本机构专用卖方深折价里，**0 件**有活质押；2012–18 的 469 件同样 0；
   营业部深折价里有 2,790 件有（2012–18）。质押强平走营业部席位，不走机构专用。无质押组的 inst 效应反而更强（−350.6bp / t −3.42），
   质押主效应不显著（−10.7 / t −0.57）。**这条只针对大宗卖方类型，不否定 H11 的质押公告漂移——那是另一条线。**
2. **定增不能单独识别。** 定增锁定期内的 364 件**全部**是机构专用卖方，S 与 inst 完全共线，交互不可识别。
   更麻烦的是时间：**2014–17 的 inst 事件 100% 是定增，2019+ 0% 是定增，同月重叠只有 1 个月**——
   定增与时代完全共线，不能把「定增」和「2016–18」分开。桶均值 −302.8bp，但 2012–15 是 **+996.3bp**（65 件）、
   2016–18 是 **−585.2bp**（299 件）——符号随时代翻转。定增是 2016–18 机构退出潮的标签，不是稳定驱动。
3. **剩下的负号。** 「两者都不是」的 105 件机构卖方，f60 仍是 **−279.6bp**；2016–18 子样本 −375.4bp（97 件）。
   所以 2012–18 的 regime 比质押/定增更宽：更像机构退出/流动性折价，而不是某一种合约。

> 口径边界：当前标的池（退市股未纳入，生存偏差）；质押为公告口径（2012 前起始且未再公告的合约缺失）；
> 定增锁定期从上市日按 `LOCKIN_PERIOD` 计算。P/S 是暴露标签，不是随机分组；结论是「负号集中在哪」，
> 不是「质押/定增的因果效应」。

## 17. 什么会杀死这套理论

1. **存量的零是测量偏差**：G1–G4 已修（v2 仍零）；2005–2018 公告已补、重复披露已去（sn3 仍零）；
   若 G5–G8 补齐后出现稳定负号 → 「事件 vs 状态」降级为「测量问题」。
   **当前状态：G1–G4 + 公告覆盖率 + 重复披露已排除，G5–G8 未排除。**
2. **事件效应被前路径吸收**：控制 ret120/ret250 与公告前 20 日反转后消失 → 不是披露，是动量。
3. **干净的解押检验（预定到期，非提前解押）显示效应不消失** → 不是约束，是公司质量。
4. **迁移失败**：大宗深折价不为负，且拆买卖方后符号翻转（营业部卖方 +41 / 机构专用卖方 −97）；
   扩样到 807 件仍 t −1.22、2019 后归零；若龙虎榜/十大/回购也无同向效应 → 质押是特例，不是一般理论。
5. **总量不成立**：约束发起对市场尾部无增量 → 微观选择函数不能加总。
6. **发送者无关**：控制人/理由/条款都不改变漂移 → 「发起」只是一个时间戳，不是信息。

## 附：本卷的地位

它不证明筹码有用，也不证明筹码没用。它给「筹码数据为什么只能给出这么点信息」一个可检验的答案：

> **因为筹码只在被发起的那一刻是新闻；之后它只是状态，而状态已经被定价。**

如果这个答案对了，`/chip` 就不再是一份验尸报告，而是**约束发起事件的测量层**——
和 `verdict.md` 的「做被迫交易方的耐心对手方」接得上：耐心对手方要知道**谁刚被迫、被迫多少、还剩多少**。

如果这个答案错了，我们至少知道：**在一个把持仓、年龄、网络、合约余额都试过一遍的市场上，
唯一稳定的信号来自「谁刚刚把自己押上去」，而不是「谁手里有多少」。**
这个否定比「fwd20 没信号」强得多，也值得一个页面。
