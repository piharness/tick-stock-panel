# 这五个月的账：成本、产出，与「二手信息」到底值多少

> 触发问题：付出的时间成本与回报成正比吗？如果不划算，有没有实践成果可以检验——
> 比如二手信息、假设、故事，甚至谣言，理论上谣言也是有信息量的。
>
> 本文不辩护，只结算。所有数字可复核（`git log`、`ls analysis/*.py`、`grep` 命令写在文末）。

---

| 项目 | 实测值 | 复核方式 |
|---|---|---|
| 时间跨度 | **2026-06-18 → 2026-11-21，5 个月 3 天** | `git log --reverse --format=%ad` |
| 提交 | **1,378 次** | `git log --oneline \| wc -l` |

**所以「不值」这个判断，按交易回报算是成立的，不需要找补。**

## 二、不值在哪：三个结构性原因，不是运气差

### 2.1 找正信号贵，排除负信号便宜，而我们 80% 的钱花在前者

能拿出来直接用的产出，几乎全是「不要做什么」：

| 类型 | 条数 | 例子 |
|---|---|---|
| 「不要买」类规则 | 10+ | 深跌 >50% 不买；低波阴跌不参与；牛市不买落后行业；日均成交 <5,000 万不碰；月末补票不做 |
| 「买什么」类规则 | **1（待验证）** | 跌破 35% + 波动分位 >66% + 次日进场 |

机制很直白：**排除只需要信号正确，买入还要求信号稀缺。**
一个变量能「证明某类交易会亏」的概率，远高于它能「证明某类交易会赚」——因为市场里
亏损的来源是结构性的（成本、拥挤、流动性），而收益的来源是可竞争的。
把 80% 预算投在不可竞争的那一侧，是这个项目最大的方向性浪费。

### 2.2 返工吃掉了三分之一：109 处「前视 / 修正后」

`docs/` 里 32 篇文档出现 109 处「前视 / 未来函数 / 口径错 / 推翻 / 修正后」。
`.workbuddy/memory/MEMORY.md` 里沉淀了 **10 条复发母题**，每条背后至少一次真实返工：

| 母题 | 代价 |
|---|---|
| 指数起始日不等 ⇒ 事件研究须卡 `k>=250` | 踩两次，产出过假 +18.93% / t=8.23 |
| 严格平衡面板＝每年都有年报 | 家数 803→961，Σ净资产凭空 +77% |
| `announce_date` 年份全错 | 只能重推（滞后中位 33 天），直接用=前视 |
| 分类泄漏（「纳斯达克」漏了「纳指」） | −35~−50% 档显著性从 p_neg 4.2% 变 9.4%，结论改写 |
| 5min 末根≠收盘（缺集合竞价） | 判涨停/MAE 必须换 `raw_close` |
| 事件扎堆 ⇒ N 是周期数不是动作数 | 51 事件只有 26 独立月，t 全虚高 |

**这三分之一不是「研究难」，是「同一个真相有两个定义点」。** 好消息是它可压缩，见第五节。

### 2.3 结论有半衰期，折旧快于积累

| 结论 | 有效期风险 |
|---|---|
| 龙虎榜席位跟单无效 | 只有 1 年历史（接口限制），功效不足，属「未见证据」 |
| 位置梯度（−50~−35% 正 EV） | 只有 2 轮周期，90% 区间已跨零 |
| ROE 拐点 | 24 万公司-季，只能证「不能预测方向」 |
| 游资溢价搬到隔夜 | 17 年面板，最稳，但结论是「白天进场的人付钱」 |

越值钱的结论越依赖长面板，越长面板越难拿到。**积累速度慢于折旧速度，是这套方法的物理上限。**

## 三、「二手信息有信息量」——你的直觉对，而且我们已经测过了

这不是没试过的方向。三条最典型的二手信息，全部进过检验，且**全部指向同一个吸收变量：换手率**。

### 3.1 游资叙事（龙虎榜席位）：68 个席位，无一通过

`docs/dragon-tiger-assessment.md`，239 个交易日、11,505 条席位行、68 个游资席位：

| 检验 | 结果 |
|---|---|
| 上榜全体 H5 超额 | **−141.9bp（t=−5.69）**，持有越久越差 |
| 净买入 >0 / 游资净买 >0 / 机构净买 >0 | 没有一个方向条件把 −45bp 拉回正数 |
| 29 个够样本席位的 Bonferroni 阈值 \|t\|≈3.1 | 最大绝对值 **2.04**（孙哥 −280bp），**一条都没过** |
| 「同席位连续加仓」 | **−237.6bp（t=−2.52）**——游资越加越跌，是反指 |

### 3.2 身份叙事（机构 vs 游资）：控制涨跌幅后 \|t\|<2

`docs/dragon-tiger-org-vs-hotmoney.md`：四种买家类型 H20 全部 **−400 ~ −500bp**；
控制当日涨跌幅后方向不稳定。**「谁在买」不携带量价之外的信息。**

### 3.3 舆情叙事（关注度迁移）：正交化后归零

`docs/attention-change-consensus-ortho.md`，样本内单变量 t 高达 −15.3：

| 规格 | `core→active` 系数 | 判读 |
|---|---|---|
| 单变量 | −66.7bp (t=−13.8) | 强得不像话 |
| 全控制（动量+市值+换手） | **−0.6bp (t=−0.06)** | **归零** |

`active→core` 也从 −73.7bp 衰减 64% 到 −26.8bp。**「关注度变化」是动量的延迟镜像，
「拥挤度」只是「换手率水平 + 市值」的另一个名字。**

### 3.4 散户叙事（股东户数）：滞后 1–3 个月，属回溯型

`analysis/_diag_shareholder_alpha.py` 的口径纪律已经写明：必须用**公告日**
（`notice_date`，或 `period_end+45d` 兜底），用报告期就是未来函数。
一个季度披露、滞后 1–3 个月的户数变化，在信息到达你手上时，价格已经走完。

### 3.5 第五份（本次新增，成本 3 分钟）：传播层级是唯一起作用的维度

前三份都问「谁在说 / 谁在买」，这一份换个问法：**同一个故事，被说第几次，效果一样吗？**

数据：龙虎榜原始 248 个交易日（H20 需未来 20 日，实可用 **228 天**）、**15,715** 个可算收益的事件。三个「叙事质量」维度全部可机械抽取：
`range_days`（1=当日首现，3=连续 3 日上榜＝已被反复报道）、`limit_reason` 按「+」切开的段数（故事复杂度）、
`concept_list` 长度（蹭几个概念）。超额 = 个股 − 同日全市场等权，扣 15bp，t 按交易日聚合。

**先看总闸门：每一格都是负的。** 从 −41bp 到 −539bp，没有一个叙事桶转正。

| 维度 | 大盘内组间差 | 小盘内组间差 | 判读 |
|---|---|---|---|
| 传播层级（3 日 − 1 日） | **+248.4bp** | **+236.4bp** | 跨规模同号且同量级 ⇒ **真效应** |
| 故事复杂度（3+ 理由 − 1 理由） | +97.0bp | −25.1bp | 方向翻转 ⇒ 规模效应，无效 |
| 蹭概念数（3+ 概念 − 1 概念） | −78.6bp | +207.6bp | 方向相反 ⇒ 规模效应，无效 |

三个具体结论：

1. **「越晚听到越差」是错的，而且反得很干净。** 首次上榜（消息驱动的一次性冲高）H20 超额
   **−390.2bp（t=−8.72）**；连续 3 日上榜 H20 **−148.1bp（t=−2.45）**。差 **+242bp**，
   在大盘（+248）与小盘（+236）内几乎一模一样。**被反复报道不是衰减，是「有资金在连续做」的证据。**
2. **「故事越多越假」是规模效应的假象。** 大盘内 3+ 个理由比 1 个理由好 97bp，小盘内差 25bp。
   方向不一致 ⇒ 这条民间智慧不可用。
3. **「蹭概念越多越假」方向都反了。** 小盘内 3+ 概念比 1 个概念好 **208bp**。多标签更可能是
   「多路资金同时关注」而非「纯蹭」。

**为什么这条比前三份值钱**：它是唯一跨规模稳定的维度，而且**说话方式完全不同**——
它不问「谁在说」，只问「说到第几遍」。而它的可用形式是排除：
**首次异动、消息刚出、只上一天榜的票，是这套数据里最确定的负超额（−390bp，t=−8.72）。**

代价：3 分钟、248 天免费数据、一个脚本。**这是整个项目里性价比最高的一次检验。**
它也顺带印证了第二节：排除比买入便宜且可靠——这次连"能不能买"都没问，就直接拿到了能用的结论。

### 3.6 五份实验的共同结论

**谣言确实有信息量——但它的信息量在传到你这之前，已经被换手率与成交额吸收干净了。**
这不是「谣言是假的」，而是「你是最后一个知道的人」。而最后知道的人，在这个信息上
支付的是成本，收到的是负超额。

唯一没被吸收的是**传播层级**（3.5）：同样是负超额，但「第几次被说」能把 −390bp 拉回到 −148bp。
**叙事的内容不携带信息，叙事被重复的次数携带信息。**

## 四、一条可操作的判据：二手信息值多少

由上面三份证据可以推出一条二分法，它解释了为什么 319 个脚本产出 0 条可交易正信号：

> **可检验性悖论：一条二手信息如果可以用历史数据回测，它大概率已经被定价；
> 如果它还没被定价，它一定回测不了。**

推论——评估任何二手信息（研报、传闻、大 V、群消息）只需问四个问题：

| # | 问题 | 若为「否」的结果 |
|---|---|---|
| 0 | 这是你**第几次**听到它？ | 首次 ⇒ −390bp（t=−8.72）；已被反复说 ⇒ −148bp。**先问次数，再问内容** |
| 1 | 它指向**未来现金流/供需**，还是**已经发生的价格**？ | 回溯型 ⇒ 已被定价（龙虎榜三份实验） |
| 2 | 有人**用大钱**为它背书吗（不是转发，是建仓）？ | 无下注 ⇒ 只是情绪，信息量≈0 |
| 3 | 它**尚未被主流覆盖**吗？ | 已覆盖 ⇒ 你买到的是别人的退出流动性 |
| 4 | 你能说出它**错的时候长什么样**吗？ | 说不出 ⇒ 无法退出，不可交易 |

第 0 条是本次实验新增的，也是唯一在数据里"方向对且跨规模稳定"的一条。
它把「谣言有信息量」这句话落成了一个可操作的数：**信息量不在内容里，在重复次数里。**

第 4 条最贵：**能说出失效形态的信息才有头寸，说不出的只有观点。**
本页 V1 之所以还活着，唯一原因是它第 4 条答得出来（3 次里 2 次相对 <−10% 即无条件退役）。

## 五、成本能压到多少：返工是可压缩的那部分

返工主因不是「没想到好点子」，是 10 条母题。这 10 条现在已经变成代码约束与测试：

- 口径唯一产地（`etf_watch.py` 直接 `import` 研究脚本，只换取数路径）⇒ 消灭「两个定义点」
- `--verify` 机械对齐（全量 nav 差 0.00e+00）⇒ 消灭「文档与代码漂移」
- 前视检查成为默认动作（信号日收盘取数，收益从 t+1 起算）⇒ 修完数字变差也要改
- 负控必做（随机池、安慰剂日期、cluster 计数）⇒ 消灭「绿但无感知」

**同样难度的下一个项目，成本应该低 3–5 倍。** 这不是自我安慰，是可核对的：
本项目后期（11 月）单条结论的提交数明显低于早期（10 月），因为约束已经写进工具链。

## 六、结论

1. **按交易回报算，不划算。** 5 个月、1,378 次提交、319 个脚本，可执行规则 0 条。
2. **按「不再亏钱」算，划算。** 10+ 条排除规则每条都对应一种真实亏损方式；这些不需要等样本外验证就能用，因为它们是「不做」。
3. **二手信息这条路已经走过了，不是没走。** 前四份实验一致：增量信息量在控制换手率后归零。
   第五份（传播层级）是唯一的例外，而且它的信息与内容无关——**第一次听到的消息是 −390bp，第五次听到的是 −148bp（龙虎榜 248 日）**。
   剩下的残差只在不被公开数据覆盖的地方——产业验证、政策解读、渠道，那些的成本不是脚本，是时间和人。
4. **性价比最高的一次检验花了 3 分钟。** 传播层级那个实验：248 天免费数据、一个脚本、零付费源，
   产出一条可直接用的排除规则（首次异动不追）。相比之下，为「找正信号」花的那些周，产出是 0 条规则。
   **这不是"研究没用"，是"找正信号的研究没用"。**
4. **现在最贵的动作是「再挖一个变量」。** 边际产出为负：每多挖一个，就多一次过拟合机会，
   而 V1 要等的 3 个事件簇一天也不会因为多挖而提前到来。

**下一步只有一个动作：停。** 让扫描器每天跑，攒簇，别改阈值。
