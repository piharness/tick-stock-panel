## 1. 问题：为什么前四卷全零

卷一/二测价格上的密度 `S(p)`，卷三测年龄结构 `S(p,a)`，卷三·追击测活合约的触发价分布 `Φ(p)`，
卷四测「发起」`O_t`。十六个读数里，十二个状态变量零或不稳，唯一活下来的是质押公告贴线。

前四卷的共同点是：**都在持仓表（资产端）上找 alpha**。持仓按市价计价，市价由成交生成，
形状是过去成交在价格轴上的投影——它可以有信息，但不留下按面值计价的欠款。
零不是十六次失败，是默认值：要有信号，必须有一个未定价的量；资产端没有这个量。

卷四其实已经摸到了负债端（H11 的平仓线），但把它读成了一次「发起」——一个信号，问的是发送者；
卷五读成一笔「余额」，问的是金额。

## 2. 命题：换一张表

同一只股票有两张表：

| | 持仓表（资产端） | 应付表（负债端） |
|---|---|---|
| 对象 | 谁持有多少 | 谁欠谁多少 |
| 计量 | 市价，逐日重估 | 面值，合约写死 |
| 信息 | 已进入价格 | 未进入价格（gap） |
| 符号 | 无（测度非负） | 有（欠方必须处置） |

**命题 1**：价格不是持仓分布的泛函，是未付余额的泛函。
**命题 2**：一个约束是否产生可定价的漂移，取决于它多久被重估一次。

```
drift ≈ (面值 − 市价) / 流通市值 × 摊销(账龄) × 处置方向
```

- 逐日盯市（两融、期货、ETF 申赎）：gap 每天结清 → 无漂移。H9 的融资余额 = 换手/久期代理（ρ_D −0.442）。
- 事件盯市（质押、定增、员工持股、大宗）：gap 累积到处置日 → 有漂移。H11 贴线 f60 −474bp（t −5.41）。
- 从不盯市（成本带、筹码峰、套牢盘）：不是账单 → 只有反转。H3 下穿 +116bp，20/20 置换更强。

这条定律把 H9 与 H11 的相反结果收成一个：**定价的不是杠杆，是没被追保的那部分杠杆。**

## 3. 首测：三条轴，只有一条会动（**本节数字作废，见 §7**）

样本：质押公告事件 20,540 / 80 个月 / 2020-01 ~ 2026-08（预注册 pledge-drift 的同一批）。
口径：`f60 = close[t+61]/open[t+1] − 1`，`exc60 = f60 − 当月均值`，月聚簇后 NW t。
`mean` = 桶内月均 exc60；`spread` = 桶内 drift 三分位 Q2−Q0。

| 轴 | 变量 | 极差 | 读法 |
|---|---|---|---|
| 位置 | 合约年龄（公告日 − 质押起始日） | **100.4bp** | 五桶 \|t\| < 1.5，非单调 → 位置不进入价格 |
| 能力 | 累计质押比例五分位 | **44.8bp** | 五桶 \|t\| ≤ 0.5，无方向 → 粗代理测不到 |
| 余额 | 质押以来涨跌 | **668.4bp** | −301.2（t −7.38）→ +367.2（t 6.55），单调 |

**但账龄会衰减**：桶内 Q2−Q0 从 889bp（<0.5 年）降到 305bp（>2 年），约一年减半。
账单不是到期兑付，是摊销——这解释了 H12 的阴跌形态，也解释了 H8 为什么找不到跳跃。

边界（诚实标注）：

1. `UNFREEZE_DATE` 是结果不是条款（股价恢复会被提前解押），主表不用它；用它做的副检验同样是平的（571 / 638 / 633 / 578bp）。
2. 能力只有一个粗代理（已质押 / 总股本）。换成「剩余可质押 / 流通市值」可能复活——这是杀死条件的第 5 条。
3. 全部为探索性。H11/H12 已看过全样本，不是样本外证据。

| # | 预测 | 判据 / 杀死 |

## 6. 局限

1. 只有一条硬证据（H11/H12）与一条排除证据（C1 的存量零）；其余是从同一恒等式重述出来的推论，重述不是证据。
2. 「面值」在 A 股没有干净的会计口径：质押余额、锁定市值、回购承诺都不是同一张报表上的科目，本卷把它们当作同构的负债，这是抽象，不是事实。
3. 摊销系数只有一条轴（质押账龄）的经验支持；跨合约类型是否同构，未测。
4. 制度类的读法（2019 后符号消失 = 处置方式变化）与读数同向，但未识别因果。

### 7.3 修正后的读法

1. **H12 的结构活着**：折算（行权价）仍然无效（t −0.23），路径（余额）仍然强（t −6.39）。
2. **符号反了**：越贴线、跌得越深，未来 60 日反弹越强；不是阴跌，是反弹。
3. **卷五的符号假设作废，结构待重写**：有日期的参照点仍然重要（路径强于行权价），但 A 股的约束
   不是被强平解决的，是被救助/展期/重组解决的——市场提前给救援定价，而不是给清算定价。
4. **作废范围**：H11、H12、预注册 pledge-drift（评估日 2027-03-31 撤回）、本文 §3、
   卷四 E 节与 D3 图的「事件负」。不受影响：D/D2/D4/D5 存量簿（月末面板价）、H9（质押比例）、
   H1–H8（日线面板）、大宗 F 线。
5. **P1 现在才成立**：锚定安慰剂要求信号在事件日可观测；旧 `drift` 的终点是提取日，
   在事件日不存在。换成 `drift_c` 后，P1 的问题变成「同一段跌幅，锚在合约上为什么比锚在固定窗口上更强」。

### 7.4 同特征对照：+525 是多空差，长腿是 +291（H13，2026-11-27 追加）

§7.2 的「控制后 +182.3bp/sd」只控了换手/波动/规模/久期/动量，**没有控 drift**；而
`ratio_c ≈ 折算/(1+drift_c)`，两者是同一枚硬币。把 `ratio_c` 与 `drift_c` 同时放进线性回归，
`ratio` 只剩 +47.2bp/sd（t 0.83），`drift` 仍 −247.0（t −3.70）。

这不是「贴线无效」，是**线性设定测不到阈值**。换成同日同事件池（2,286 只有质押记录的股票）的横截面残差：

|---|---|---|

| 同日 + ret250 三次曲线 | +229.3bp | 3.63 |
| 再加 ret60 / vol20 / turn20 / log(amount20) | **+290.6bp** | **5.28** |
| far 同基准 | −94.3bp | −4.37 |

**读法**：只做多的人，能被记成 alpha 的是长腿 +290.6bp（相对同特征基准，不是相对现金）；+525 是 near−far 的多空差；

## 9. 后续（2026-11-28）：条件，不是水平

卷五的方程把「贴线」写成一个数。但这个词在簿上有四种实现（`wdist` / `near_share` /
`big_ratio` / `max_ratio`），同一批股票、同一个对照组，60 日超额从 **+141bp 到 −54bp**，
只有一行过 t=2。没有跨口径的常数。

但四种代理按「贴在触发面上的余额质量」单调排列：金额加权 > 数量占比 > 最大合约 > 最贴合约。
所以水平没有唯一值，水平的差异有结构。

但四种实现的排序 **8/8** 一致：低压力 > 高压力、少合约 > 多合约。
所以卷五的方程应改写成条件方程：

```
drift ≈ (面值−市价)/流通市值 × 解除概率 × 解除方向 × 1{执行容量充足} × 1{索取权不可分割}
```

完整论证、四口径表、路径孪生（同一段 60 日路径，账单仍留 +141bp / t 2.71，路径只抵消 5.9%）
与五条杀死条件见 [`chip-conditions.md`](chip-conditions.md)。
