> 本文把 `/chip` 卷五的唯一候选固化成一份可复现的纸面规格；**不接账户、不登记信号**。

> **诚实声明**：H11/H13 已在全样本（2020-01 ~ 2026-08）上看过；`ratio>0.8`、60 日持有这两个选择

## 1. 问题

H13 把 `+525bp` 拆成三个数：near−far 多空差 `+525.3`、near 绝对 `+1011.4`（含 beta）、
长腿相对同事件池同特征基准 `+290.6`（t 5.28，6/7 年正）。纸面要回答的不是「有没有相关性」，
而是：**只做多、按公告次日开盘买、持有 60 日、扣 0.5% 成本、有仓位上限，这个候选还能不能剩下正超额？**

## 3. 冻结规则（v1）

**单一实现点**：`analysis/_paper_pledge_line.py`。信号计算复用
`analysis/_diag_chip_audit_fix.py::load()`，不另写第二份 `ratio_c`。

**股票池**
- 非北交所；非当前名称含 `ST`（当前名称，非历史 ST；方向高估，见 §6）。
- 上市 ≥ 250 个交易日（用 `entry_date − listing_date ≥ 365 自然日` 近似）。
- 入场日 20 日均成交额 ≥ 1,500 万元。
- 事件：重要股东质押公告，去重到股票-日（同日多股东合并）。

**信号（公告日收盘可观测）**
```
drift_c = adj_close(notice) / adj_close(pstart) − 1
ratio_c = zhesuan / (1 + drift_c)
near    = ratio_c > 0.8
```
`zhesuan` 为东财折算字段；`drift_c` 与 `ratio_c` 的唯一实现点是 `_diag_chip_audit_fix.load()`。
事件级过滤：`drift_c ∈ [−0.9, 3.0]`（沿用审计脚本）；`ratio_c` 不设上限，避免把深跌样本切掉。

**入场 / 出场**
- 入场：公告日后第一个交易日**开盘**。
- 出场：入场后第 60 个交易日**收盘**（与 `f60 = close[t+60]/open[t+1] − 1` 同一口径）。

**组合**
- 初始资金 100 万元；每个信号固定 1 个 slot，`slot = capital / 60 × 0.95`。
- 最多 60 个并发持仓；满仓则**跳过**新信号（不替换、不按 ratio 排序，避免二次选择）。
- 现金不计息；不做再平衡；分红由复权价包含。
- 成本：双边 0.5%（入场 0.25%、出场 0.25%），从每笔 P&L 扣。

**基准**
- 主：**同事件池、同日等权**。每个 near 事件，取同一入场日所有其他质押事件的 `f60` 均值（剔除自身）；
  同日只有 1 个事件时，用当月所有事件均值。
- 次：绝对收益（对现金）；`H13e` 同特征残差只作归因，**不作为纸面基准**（同期拟合、含未来信息）。

## 4. 指标

- 每笔：毛收益、净收益（−0.5%）、超额（净 − 事件池基准）、胜率、中位数。
- 月聚簇：`ym` 内先平均，再对月序列求均值与 NW t（lag 6）。**N 是月数，不是交易数。**
- 组合：总收益、年化、最大回撤、平均/最大持仓数、跳过数、平均暴露。
- 容量：入场日 20 日均成交额的中位/p10；按 1% ADV 估算可承载资金。

## 5. 判据（冻结）

评估日：**2027-06-30，或前向满 6 个独立月，以先到者为准。**
纸面回放（holdout）只作先验，不单独构成通过；通过必须同时满足 holdout 与真前瞻同号。

| 判据 | 阈值 | 含义 |
|---|---|---|
| 主判据 | holdout 月均**净超额** > 0 且 NW t ≥ 1.65 | 扣成本后仍跑赢同事件池 |
| 稳健 | 正月份 ≥ 60%，且 2025/2026 不反号 | 防止均值被单年抬走 |
| 组合 | 年化 > 事件池基准，最大回撤 ≤ 25% | 能承受的路径 |
| 容量 | 中位 20 日均额 ≥ 3,000 万；1% ADV 容量 ≥ 300 万 | 小资金可执行 |
| 成本 | 0.5% 双边后主判据仍成立 | 不允许靠零成本 |
| 样本门槛 | 前向 < 6 个月 | 不裁决，只报进度 |

- **通过** → 进入「纸面观察」，仍不接账户；再满 12 个月且同号，才讨论是否登记为策略。
- **否决** → 关闭该候选，写回本文；**不允许**现场改阈值/换持有期再测（那是又一次多重比较）。

## 6. 已知局限

1. **准 OOS 污染**：规则在 2020-2026 全样本上选过；holdout 只提供先验强度，不是干净 OOS。
2. **ST 按当前名称剔除**：历史戴帽/退市股可能被错误保留，方向高估。
3. **退市缺口**：只含在市股票；退市/长期停牌的深跌质押股不在库，方向高估。
4. **开盘可成交假设**：一字板买不进；公告次日开盘可能跳空。纸面未计冲击成本，只扣 0.5%。
5. **行业未中性**：near 组可能集中在地产/小市值；H13e 未控行业。
6. **事件源截止 2026-08-22**：真前瞻开始前需补 2026-09 之后的质押公告；未补之前，前向账本为空。
7. **不是投资建议**：本文只定义纸面规则与判据，不构成任何买入建议。

## 9. 纸面结果（2026-11-27 首次运行）

完整表见 `reports/pledge-line-paper-2026-11-27.md`。核心：

成本敏感性（holdout）：0.5% → +293.7bp / t 1.80；0.8% → +263.7 / t 1.62；1.0% → +243.7 / t 1.49。

holdout 均值 +293.7bp、t 1.80 ⇒ se≈163bp，双侧 95% CI 约 **[−26, +613]bp**，刚跨零；
t 1.80 是单侧 1.65 门槛的边缘通过。near 原始 1,478 条，过滤/缺价后 1,433 条。

**裁决**：主判据、稳健、组合、容量均过；成本只在 ≤0.5–0.7% 时过；真前瞻未裁决。
