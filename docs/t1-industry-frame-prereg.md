# T1 预注册 · 行业框架是否产生收益（裁决 HF-2026/C6）

> **写于跑数之前**，2026-11-25 10:2x。此后任何对口径的修改都必须记入 §7 变更，不允许静默调整。
> **裁决对象**：`docs/method-dossiers/2026-11-hf-quant-documentary.md` §5.3 的冲突——
> 视频称「行业/风格严中性，行业内超配 top20%，年化超额 8–12%」；
> 本仓库 `footprint-20d-significance.md` 的「行业内孪生」只有 **+0.2bp（t=0.01）**。

## 0. 一句话设计

同一评分、同一宇宙、同一持有期，**只改排序的「框架」**（全市场 / 行业内 / 行业内去均值 / 随机分组），
看 20 日超额差落在哪里。四个臂的唯一差别是"分组"这一操作，因此差值可归因。

**已知偏差（不修，只声明）**：① 富化面板不含退市股 ⇒ 幸存者偏差，对多头有利；② 行业为**当前**同花顺分类，非 point-in-time；③ 行业层级混合（90 组，部分为一级如"电力"，部分为二级如"汽车零部件"），因此本检验的中性化**强于**申万一级。三者对四个臂同向影响，不影响臂间差值的方向解释，但影响绝对水平。

## 2. 评分（冻结，不调参）

`score = −heat`，其中 `heat` 为 `_diag_footprint_composite.py` 的 2026-11-23 定义：

```
heat = mean( z(turn20), z(vol20), z(ret20), z(limit_up_cnt20), z(range20), z(turn_chg), z(amt_chg) )
z(x) = 当日横截面 pct-rank × 2 − 1
```

方向：**取 `score` 前 20%（= 热度最低 20%）为多头**。这与 `footprint-score-exit-oos.md` 的 `low` 臂一致（OOS +18.6% 超额），方向已由既有 OOS 决定，本检验不再选方向。

**负控臂**：`score = +heat`（热度最高 20%）。预期三臂全负；若某框架下变正，说明框架效应可翻转方向，需单独解释。

## 3. 四个臂

| 臂 | 选择规则 | 行业权重 | 权重 |
| --- | --- | --- | --- |
| `all` | 全市场 `score` 前 `k=round(0.2N)` | 自由漂移 | 等权 `1/k` |
| `ind` | 每个行业内取前 `k_g=max(1,round(0.2·n_g))` | **= 基准**（`n_g/N`） | `w=(n_g/N)/k_g` |
| `inddm` | 行业内**去均值**后全市场取前 `k` | 漂移（偏向行业内离散度大的行业） | 等权 `1/k` |
| `rand` | 按 `md5(symbol)` 切成 90 个"伪行业"，**规模分布与真实行业逐一对应**，组内取前 20% | = 基准（同 `ind` 机制） | 同 `ind` |

`ind` 是视频 C6 的严格实现：行业配置与基准逐行业对齐，超额只能来自行业内排序。
`all` 是我们既有做法（全市场排序）。
`inddm` 是"行业中性化"的另一种常见实现（ demean 而非按比例配额）。
`rand` 是**负控**：同样做"分组 + 组内选前 20% + 行业权重对齐"，但分组不含行业信息。`ind − rand` 才是"行业信息"的净贡献；`rand − all` 是"分组这一操作本身"的代价。

## 4. 成本

主口径扣 **12bp/往返**（佣金 2.5bp×2 + 印花税 5bp + 过户费 0.2 + 滑点 ~2bp），对每个 cohort 的毛超额直接减 0.0012（四臂相同，故不改变臂间差值）。另报 20bp 供对照。

## 5. 统计与判据

- **点估计**：全部 811 个锚点的臂间差均值（重叠，仅作水平参考）。
- **t 值**：只用非重叠锚点（`di % 20 == 0`，约 203 个），`t = mean/se·√n`；同时给按年 block bootstrap（1000 次，年为单位重抽）的 5/95 分位。
- **逐年**：按锚点年份分组求均值（年内重叠不修正，仅作形状）。

**主判据（原样保留自 HF-2026 §8）**

> P1：`ind − all` 在 2018-01~2026-10 的**年度**超额差 > 0，且 **9 年中 ≥7 年为正** ⇒ 支持 C6「行业约束本身产生收益」。

**辅助判据（本次新增，用于分解，不替代 P1）**

- P2：`ind − bench` 在 2018+ 显著 > 0（t>2）⇒ 行业内选股本身有 α。
- P3：`ind − rand` > 0 且 t>2 ⇒ 收益来自**行业信息**，而不是"分组配额"这一操作。
- P4（负控）：`+heat` 方向下 `ind − all` 若显著 > 0，则框架效应与评分方向无关，P1 的解释力下降。

**四种结果的解读（先写死，避免事后编故事）**

| 结果 | 结论 |
| --- | --- |
| P1 过 + P3 过 | 行业约束有真实信息价值，C6 方法层成立；我们的 +0.2bp 属过度控制或口径错配（§5.3 情形 a） |
| P1 过 + P3 不过 | "行业内选股"有效但**不来自行业信息**，来自分组配额（分散化/去集中），C6 的因果解释错 |
| P1 不过 + P2 过 | 行业内选股有 α，但全市场排序同样有，行业约束不增值（C6 多余，非错误） |
| P1 不过 + P2 不过 | 20 日横截面排序在主板无可交易 α，C6 的 8–12% 归 C 级渠道估算（§5.3 情形 b） |

## 6. 失败条件（结果作废的情形）

- 四臂的当期持股数若相差 >5%，说明权重机制写错，作废重跑。
- `rand` 的组规模分布与真实行业相关性 <0.99，说明负控没对齐，作废重跑。
- 任一臂在某年 cohort 数 <5，该年不参与"逐年为正"计数（并在结果里标出）。
