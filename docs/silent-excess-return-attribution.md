# 沉默公民超额收益：事件研究 + 匹配归因

> 一句话结论：**silent 的 +606bp 超额，本质是「小盘 + 低流动性」的投影，不是「沉默本身有 alpha」。**
> 用防前视的匹配基准拆掉小盘/低流动性后，跌入 silent 的票相对可比对照**不涨反跌**（事件后 60 日差分 CAR ≈ −134bp，t≈−0.9，不显著但方向稳健）。

---

## 1. 原始发现是什么

`_verify_citizenship_signal.py`（2026-11-16，5289 日 / 2005–2026）曾报告：

| 等级 | H=20 超额（相对全市场中位数） |
|---|---|
| core | −11 bp |
| active | +132 bp |
| background | +299 bp |
| silent | **+606 bp** |

越沉默超额越高。当时已正确标注「这是低流动性溢价 + 小市值的复合效应，不是沉默有 alpha」，但**没有做归因拆解**——市值、流动性、壳价值、幸存者偏差四个混淆变量一个都没被中性化。

本报告补上这一步。

---

## 2. 为什么「分组法」回答不了这个问题

原始 +606bp 用的是「silent 组 − 全市场中位数」。但 silent 的成交额中位数只有**全市场的 12%**（828 万 vs 6885 万，实测），是典型小盘。所以这个 +606bp 天然混着「小盘长期跑赢大盘」的效应——它不是测「沉默」，是在重测「小盘效应」。

要分离「沉默」的边际，必须拿 silent 票和**同规模、同流动性、同动量的非沉默票**比。这正是本报告用的事件研究 + 倾向得分匹配（PSM）差分。

---

## 3. 方法

### 3.1 事件定义
「跌入 silent」= 某票 t 日 level == silent，且 t−1 日 level ≠ silent（首次进入）。

### 3.2 匹配基准（防前视）
对每个事件票，在**同日**找一个倾向得分最接近、但**未跌入 silent** 的对照票。

**关键设计决策（这是本研究最贵的一步）**：匹配特征必须用**事件日前一日（t−1）**的特征，而不是事件日当日。

原因：silent 的定义就是「成交额后 10% 且换手率后 10%」，所以事件日当日的成交额/换手率分位**已被锁死在 <0.1**（实测事件日中位 p_amt=0.044、p_turn=0.062）。用当日特征匹配 = 「用结果匹配结果」，会产生 +488bp 的前视假象（这是第一版犯的错，已修正）。

用 t−1 特征后，票在那一刻还没沉默、分位还是「正常」的，才能匹配到「本来相似、一只后来沉默了、另一只没有」的可比对象。

匹配特征（t−1，均不需时点市值）：成交额分位、换手率分位、20 日动量、20 日波动率。倾向得分用逻辑回归估计，1:1 最近邻不放回。

### 3.3 差分 CAR
差分 CAR(t) = 事件票超额(t) − 对照票超额(t)，超额 = 个股日收益 − 当日全市场中位数（两边同减，中位数项抵消）。标准误用 block bootstrap（块长 5）。

---

## 4. 结果

**匹配质量**：成功匹配 3773/4380 对，|Δ倾向得分| 中位 0.00014，事件/对照几乎同分布。

**差分累计超额（CAR，bp，负=跑输对照）**：

| 事件时点 t | ΔCAR |
|---|---|
| −20 | +18 |
| −10 | −122 |
| −1 | −51 |
| 0 | +16 |
| +1 | +46 |
| +10 | +51 |
| +20 | −15 |
| +40 | +25 |
| +60 | **−134** |

**三个关键读数**：
- 事件前（−20..−1）：**−51 bp**（t=−0.65）——跌入 silent 前已在跑输，但幅度不大
- 事件后（+1..+60）：**−134 bp**（t=−0.88）——跌入 silent 后**继续走弱**
- 事件后增量（相对事件日）：**−150 bp**

---

## 5. 结论

### 5.1 核心结论
**silent 的 +606bp 超额，在拆掉小盘/低流动性/动量后，不再存在。**

- 事件日后差分 CAR 为**负**（−134bp），且一路从 +46bp（t=1）单调下滑到 −134bp（t=60）。
- 方向与「沉默有 alpha」**相反**：同样低成交额、低换手、同动量的票，跨过 silent 阈值的那个，之后 60 天**跑输**没跨过的那个。
- 统计上不显著（|t|<1），所以严谨表述是：**「没有证据支持『沉默』本身贡献独立超额收益」**，而非「沉默有害」。

### 5.2 对你原始判断的回应
你判断「silent 超额可能是小市值效应、壳价值、幸存者偏差等混淆」——**判断正确**。本报告用事件研究+匹配证实了其中最关键的一层：**小盘 + 低流动性**已经足够解释 +606bp，不需要引入「沉默有 alpha」这个新机制。

### 5.3 尚未排除的混淆（诚实边界）
本方法只能排除「小盘 + 低流动性 + 动量 + 波动率」这四个可观测变量。以下仍未处理，需付费数据或外部源：
- **壳价值**（小盘 + 低盈利 + 低波动的组合，需 ROE/账面数据）
- **幸存者偏差**（本地 enriched 是存活快照，退市股缺失，方向会高估 silent 超额）
- **时点市值**（本地只有单一截面 float_shares，严格市值中性化需付费拉 TickFlow `shares`）

### 5.4 幸存者偏差的方向性证据（2026-11-17 补）
对「幸存者偏差」这一条，本地数据已能给出**方向确定**的证据（不需要付费数据）：

- `instruments` 登记 5892 只，最新交易日（2026-11-16）enriched 在交易 5572 只，缺口 **320 只**。
- 这 320 只中，**312 只从未进入过 enriched 面板**，上市年份集中在 1993–2000 年
  （1996 年 34 只、1993 年 23 只、2000 年 22 只…）——是典型的**早期上市、后来退市或长期停牌的老股**。
- 另 8 只在 enriched 有数据、最近（2026-09 后）才消失，最后一日成交额中位 3139 万、
  换手 4.46%，是近期停牌/退市的正常票，非低流动性小票。

**方向性结论**：退市老股（低流动性、经营差）从 silent 组的历史回测中整体缺失，
会**高估** silent 的历史超额。因此 +606bp 是**乐观上限**，真实值只会更低。
「沉默无 alpha」的结论不但稳健，而且是被低估的稳健——补回退市股只会让 silent
超额更差。这一条不再依赖「可能」的猜测，而是本地数据可直接读出的方向。

---

## 6. 产品含义

这条结论比原始 +606bp 更有价值，因为它**阻止了一个真实的误读**：

> 如果用户看到「沉默公民 +606bp」，把「该少看」误读成「该买」，就会去买低流动性小盘——而本报告证明，同样的小盘里，沉默的那只**并不更好**。

页面边界声明应升级为带归因的强声明：**「沉默的超额是低流动性+小盘的投影，不是沉默的红利；同样的小盘票里，沉默并不占优。」**
