# 预注册：已实现波动的期限结构 → 未来回撤

> 2026-11-25 12:05 冻结，跑数前写成。前两轮（密度 → 收益、密度 → 回撤）均判决不成立。
> 本轮换变量：**波动率的期限结构**（短期已实现波动 / 长期已实现波动）。
>
> **结果见 `docs/vol-term-structure-result.md`：主假设 A 被否定（Q5−Q1 = −2.40pp，方向相反）。
> 期限结构是干净的波动预测器（t=+4.16），但不预测方向、不预测回撤中位 ⇒ 无方向含义，方向关闭。**
> 本文件此后不再修改。

## 0. 为什么这个变量不一样

前两轮失败的共同原因是 **N_effective = 1**：HOT 只在 2015 年 4–6 月出现过极值，20 年只有一次泡沫。
波动的期限结构不存在这个问题——它每个月都在变，2007、2008、2015、2018、2020、2022、2024 都有独立的极值。
而且它不需要 36 个月的分位历史，样本从 2005 年开始就能用，**2007 与 2008 都进得来**。

## 1. 两种互斥的机理，必须事前选定一个方向

| 机理 | 含义 | 符号 |
|---|---|---|
| **A 均值回复（主假设）** | 短期波动远高于长期 = 恐慌已发生 = 抛压释放完毕 ⇒ 未来回撤更浅、收益更高 | Q5−Q1 **> 0** |
| **B 波动聚簇** | 短期波动高 = 高波动状态持续 ⇒ 未来回撤更深 | Q5−Q1 **< 0** |

**决策规则（事前固定）**：只有 **A 成立（显著为正）** 才算新信息。
若结果为 B（显著为负），则期限结构只是「波动水平」的另一种写法——
而波动水平已经证明能预测回撤（上一轮 VOL20 t = −1.63 ~ −2.92），**不构成增量，不采纳**。

这条规则是本轮的核心：它让两种结果都有明确含义，不给事后解释留空间。

## 2. 变量

| 变量 | 定义 |
|---|---|
| `V_k` | 等权全 A 指数过去 k 个交易日日收益标准差 × √252（年化） |
| **`R`** | **`ln(V20 / V60)`**（主口径） |
| `R5` | `ln(V5 / V60)`（更敏感、更噪） |
| `R120` | `ln(V20 / V120)`（更慢） |
| `MDD_k` | 未来 k 日最大回撤（相对窗口内滚动峰值） |
| `RET_k` | 未来 k 日收益 |
| 控制变量 | `ln(V60)`（水平）、`RET20`（过去 20 日收益，隔开与短期动量的机械相关） |

指数：等权全 A（含退市股，剔上市前 250 日与北交所），2005-01 ~ 2026-11。
**本地宽基指数只有 2025-11 之后的数据，无法做指数复检——这是已知限制，不掩饰。**

## 3. 判据（四条全过才算成立）

| # | 判据 |
|---|---|
| P1 | `R` 五分位对 `MDD_21` 的 Q5−Q1 ≥ **+2.0pp**，block bootstrap 95% CI 全为正，NW t ≥ **2.0** |
| P2 | 控制 `ln(V60)` 与 `RET20` 后，`R` 对 `MDD_21` 的 t ≥ **1.5**（方向不变即可） |
| P3 | 安慰剂（block 重排 `R`，2000 次）p < **0.05** |
| P4 | 收益侧同向：`R` 对 `RET_21` 的 t ≥ **1.5**。若只有回撤侧成立而收益侧不成立，说明只是尾部效应，不能用于仓位 |

## 4. 稳健性（同时报，不用于挑选）

- `R5`、`R120` 替代 `R`
- 窗口改成 `MDD_63` / `RET_63`
- 日频建仓（5000 个观测）作为功效对照
- 逐年、逐极端事件（2007-10、2008-10、2015-06、2018-12、2020-03、2022-04、2024-01）
- 剔除 2015

## 5. 已知会假通过的方式

- `R` 与 `RET20` 机械负相关（近期跌得多 → V20 高 → R 高），若不控 `RET20`，
  「恐慌后反弹」会被短期反转（reversal）冒充。**P2 的 `RET20` 控制是必须的。**
- `V20` 与 `V60` 共享 40 个交易日的数据，`R` 有构造性自相关；分位要在全样本上算，别rolling。
- 2008 与 2015 的极端 R 会主导均值；必须看中位数与剔除后。
