# 日内做T × 公民阶层迁移：升格改善「低吸」，降格什么也不改

> 一句话：**做T在任何阶层状态下都不成立**（毛收益 0.1–17bp vs 往返成本 12bp）。
> 阶层**迁移**唯一改变的是「亏多少」：**升格把正T从 −10bp 抬到 −2~+5bp（Δ +7~+17bp，t 3.2–6.8），降格 Δ ≈ 0**。
> 而且只有**正T（低吸）**改善，**负T（高抛）毫无改善** —— 这个不对称本身就是「升格=上行趋势」的证据。

---

## 1. 口径（先钉死，再跑）

| 项 | 定义 |
|---|---|
| 做T | 底仓 T+0 日内等量往返，收盘股数不变。收益 = 卖出/买入 − 1 − 成本 |
| 规则 | 正T`r1`：跌 d% 买、回锚卖；负T`r2`：涨 d% 卖、回锚买；14:55 强制回锚 |
| 成交价 | 只用 bar 的 `open`/`close`。**绝不用 high/low**（bar 内路径未知，且高估幅度随波动上升，会按等级精确反向） |
| 成本 | **12bp 往返**（佣金双边 + 印花 5bp + 滑点）。主表已扣 |
| 迁移 | `tr = level(T-2) → level(T-1)`，**T 日开盘前可知**。绝不用 `level(T)`（当日收盘才成立） |
| 统计 | 每笔（票日）等权；t 用按 **492 个交易日** bootstrap（B=500），有效样本 = 天数 |
| 差分 | Δ = 迁移组 − **同目标等级停留者**；并补 Δ_source = 迁移组 − **源等级停留者** |

样本：`data/_probe_t0/panel.parquet` + `trades.parquet`，2024-11-06 ~ 2026-11-16，492 日，
2,654,902 个带标签票日，10,619,608 笔。

## 3. 差分：迁移的边际，方向完全不对称

d=1%，正T。Δ_target = 迁移组 − 目标等级停留者；Δ_source = 迁移组 − 源等级停留者。

| 迁移 | Δ_target | t | Δ_source | t |
|---|---|---|---|---|
| **升格** | | | | |
| background→active | +10.0 | **4.52** | +7.4 | **3.24** |
| **active→core** | +11.3 | **3.62** | **+17.0** | **6.83** |
| silent→background | +9.1 | **3.70** | +4.5 | 1.93 |
| silent→active | +40.9 | **3.22** | +28.1 | **2.26** |
| background→core | +64.1 | **4.09** | +73.2 | **4.45** |
| **降格** | | | | |
| active→background | −0.5 | −0.26 | +2.1 | 0.97 |
| core→active | +2.2 | 1.09 | −3.5 | −1.29 |
| background→silent | −1.8 | −0.83 | +2.8 | 1.25 |

**升格组 5/5 显著为正，且同时跑赢旧同伴和新同伴**（Δ_source 也正）——
所以这不是「新进者 vs 老居民」的新老差异。
**降格组 3/3 为零或负**（|t| < 1.3）——被抛弃不改变日内可做T的程度。

### 3.1 不是振幅的投影

d=1%，按 T-1 日内振幅五分位，Δ_target：

| 迁移 | Q1 | Q2 | Q3 | Q4 | Q5 |
|---|---|---|---|---|---|
| background→active | +8.5 | +4.6 | +4.5 | +6.2 | +9.2 |
| active→core | +13.5 | +15.7 | +6.6 | +5.5 | +9.6 |
| silent→background | +8.7 | +8.6 | +15.4 | +8.0 | +6.4 |
| active→background | +1.3 | −1.5 | −2.0 | −3.3 | +8.4 |

升格的三行**五个分位全为正**，不随振幅单调 —— 与「升格只是波动变大」不相容。

### 3.2 不是流动性的投影

控制 T-1 成交额五分位（A1 最小 … A5 最大），Δ_target 为正的分位数：

| 迁移 | d=1% | d=2% |
|---|---|---|
| background→active | **4/5** | **5/5** |
| silent→background | **3/3** | **3/3** |
| active→background | 2/5 | **0/5** |
| core→active | 2/2 | 2/2 |

`background→active` 在最贵的 A5 档 Δ = +30.5bp，在最大额档反而更强 ⇒ 流动性解释不通。
（`active→core` 全部样本落在 A5：升到核心必然伴随成交额暴增，这一点无法跨档验证，是本文最大限制。）

### 3.3 事前 vs 事后

| | 事前（T-2→T-1） | 事后（T-1→T） |
|---|---|---|
| background→core | +65.7 (t=4.44) | +80.8 (t=4.14) |
| active→core | +5.0 (t=1.28) | **+24.6 (t=4.69)** |
| active→active | −11.9 (t=−2.69) | −13.1 (t=−2.79) |

事前版仍为正 ⇒ 不是纯未来函数。但 `active→core` 事后放大 **5 倍**（5.0 → 24.6）
⇒ **这个格的大部分信息藏在该股当日自己的价格里**，只有小部分能用。

### 3.4 其它判据

- **前后半（切点 2026-04-10）**：升格 3/3 同号（background→active 8.0/12.5、silent→background 9.2/8.6、active→core 7.2/15.4）；降格 0/3 同号。
- **置换负控**：按日打乱迁移标签 200 次，实际 Δ 极差 **11.8bp** vs p95 **7.4bp** ⇒ 通过。
- **对照（不看迁移，按 T-1 等级）**：core −4.0(t=−0.77) / silent −5.4 / background −9.2 / active −10.7。等级本身有梯度，但**全部为负**。

## 5. 结论

**1. 做T 在 4 个等级 × 12 种迁移 × 2 方向 × 4 个阈值上，几乎全为负。**
不是参数问题：10/12 格的**毛收益**就低于往返成本。这与此前 `docs/intraday-friction-law.md`
的恒等式一致 —— 你赚到的均值回复就是别人付的价差。

**2. 阶层迁移不改变做T的符号，只改变斜率。**
最好的一格 `active→core` 是 +5.0bp（t=1.28），在 12bp 成本下 —— 和 0 分不开。
按最乐观成本假设（万一双边佣金 + 印花 5bp = 7bp），它变成 +10bp，
`background→active` 变成 +3bp。**这是一条极窄的缝，不是一条路。**

**3. 唯一显著为正的是「跳级升格」`background→core`：+65.7bp（t=4.44）。**
但 n=535 / 492 天（约 1.1 笔/日），是 136 格里挑出来的最大值，Bonferroni 只是勉强通过。
它更像「连板/暴涨股的日内回抽被买回」，不是一个可推广的策略。

**4. 方向不对称是内生的，不是发现。**
升格改善正T（低吸，+10bp）而**完全不改善负T**（高抛，Δ≈0）。
机制：升格 = 边际买盘持续进入 ⇒ 日内下跌有人接 ⇒「跌 d% 买、回锚卖」能兑现；
高抛则买不回来（趋势向上）。**所以这个不对称正是「升格=上行趋势」的指纹**，
和 `docs/citizenship-transition-signal.md`（background→active H=20 +49.5bp/t=8.87）同源。

**5. 对「做T能不能赚钱」的回答：不能。**
阶层迁移能解释「谁亏得少」，不能造出「谁赚得到」。
要让它翻正，需要的不是更好的分层变量，而是**更低的成本结构**（佣金、冲击、印花）
或**更粗的时间粒度**（放弃日内，回到隔夜/日频，那里才携带持续性）。

## 7. 已知限制

1. **`active→core` 无法跨成交额档验证** —— 所有升到核心的样本都在最大成交额档，流动性混杂排不掉。
2. **`background→core` n=535**，是极值格，Bonferroni 勉强通过，不应作为策略依据。
3. **底仓成本未计** —— 只算做T的增量。持有底仓本身的机会成本/风险敞口不在表内。
4. **5min 频率**：日内路径在 bar 内不可观测，`d` 只能按 bar close 触发，实际触发点位比真实路径更粗。
5. **`kline_5min` 有 64/532 天价格被常数缩放**（见 `docs/tick-regime-control.md`）——
   常数缩放不改日内收益，故不影响本表，但 `ampl` 分层用的振幅受轻微影响。
