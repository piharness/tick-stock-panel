# 非对称假设的独立审计

对被审计对象：[asymmetry-playbook.md](asymmetry-playbook.md)、[asymmetry_probe.py](../analysis/asymmetry_probe.py)。

审计的唯一问题：**「payoff 形状是出场规则的可搜索属性」这个推断，能不能在加上零信号对照后仍然成立。**

结论先说：**探针的六个数字逐位复现，但它的三个核心推断都站不住。**

| # | 结论 | 证据强度 |
|---|---|---|
| P1 | 探针的四个组合标签全部左右颠倒，`[E]` 表说的「动量高 top20」实际是动量**最低**的 20 只 | 决定性（可复算） |
| P2 | 偏度随出场规则变化是**算术恒等式**：止损截左尾、止盈截右尾，形状由「哪个闸门先合上」决定，与股票无关 | 决定性（零信号对照） |
| P3 | 一旦把均值换成可下注的效用（CRRA 确定等价），并按重叠调仓的真实样本量做**配对块自助**，样本里**没有任何一种出场结构**显著优于「同日等权全市场 + 同一出场规则」；反而是两个正偏样板之一**显著更差** | 方向成立、强度不成立（[第二轮](asymmetry-round2.md)：MDE 204–305bp ＞ 观测最大效应 105bp；12/12 符号一致但仅 1 个 cell 跨口径稳定） |

## P1：选股方向反了

`pick_daily(df, factor, ascending=True)` 内部是 `rank(descending=not ascending)`，即 `descending=False` —— 给**最小值**排第 1，再取 `rk <= 20`。

`_diag_rank.py` 的输出：

```
mean cross-sectional percentile of picked mom20 = 0.002   (1.0 = highest momentum)
pick_daily(..., ascending=True ):  picked mom20 mean = -0.3141
pick_daily(..., ascending=False):  picked mom20 mean = +1.0251
```

第 0.002 分位：`momentum20_high` 取的是**动量最差**的 20 只（均值 −31.4%）。四个组合全部倒置：

| 探针标签 | 实际组合 |
|---|---|
| `momentum20_high` | 动量**最低** 20 只 |
| `momentum20_low(reversal)` | 动量**最高** 20 只（均值 +102.5%） |
| `low_vol20` | 波动率**最高** |
| `high_turnover20` | 换手率**最低** |

后果不是数字变小，是**经济叙事整体反转**：

- `[E]`「动量高 top20 在止损止盈下的形状」实际是「**最超跌**的 20 只」。
- `[C]`「反转组合 strong +109.2bp / weak −153.8bp」实际是「**动量组合**强势期赚 109bp、弱势期亏 154bp」——这比原标签自洽得多，也说明探针其实抓到了一个真实信号，只是标错了名字。

顺带修正报告里一句话的事实错误：原文称「同一信号在不同 regime 下**偏度符号翻转**」，但它自己打印的两个值是 −0.40 与 −0.46，**同号**。翻的是均值符号，不是偏度。

## P2：正偏是钳位的算术，不是市场的性质

报告 §6 主张把「payoff 结构」当第一搜索对象。问题是这个空间的形状几乎是闭式的。看 `[E]` 表自己的分位数：

- `SL5%` 的 `p5_bp` 恰好 `-500.0`；
- `TP10%` 的 `p95_bp` 恰好 `1000.0`；
- `SL3%+TP30%` 的 `p95/p5` = `3000.0 / -300.0`，尾部比 10.0 是 30/3 算出来的。

也就是说：只止损 ⇒ 左尾被截断 ⇒ 偏度必为正；只止盈 ⇒ 右尾被截断 ⇒ 偏度必为负。**−1.43 → +3.00 不是发现，是一次钳位方向的更换。** 报告写的「偏度变了 4.4 个标准差单位」在量纲上也不成立：4.43 是偏度单位，不是标准差单位。

更要命的是，这件事对**任何**股票集合都成立。零信号对照（同日同池随机抽 20 只，300 次重抽，同一出场规则），主动偏度的零分布中位数：

| 出场规则 | 随机 20 只的主动偏度中位数 |
|---|---:|
| 无止损无止盈 | +0.52 |
| SL5% | +0.89 |
| TP10% | −0.13 |
| SL5%+TP10% | +0.12 |
| SL3%+TP30% | +0.56 |
| SL10%+TP5% | −0.12 |

**随便抽 20 只股票、只加一个 5% 止损，就能得到 +0.89 的主动偏度。** 报告验收标准第 1/2/3 条（bootstrap 下界 > 0、尾部比 ≥ 1.5、去掉最好 5% 仍正）在这种情况下会被**随机数**通过，因此不具备判别力。

## P3：换成可下注的量，结论消失

报告用偏度、尾部比、`mean_ex_best5` 排序。这三者都不是可下注的量。改成两件专业上更硬的事：

1. **主动口径**：同日同一出场规则下，组合收益减去全市场等权收益，逐 cohort 序列。
2. **CRRA 确定等价**：`CE = (E[(1+r)^{1-γ}])^{1/(1-γ)} − 1`，γ=1/2/5，用**块长 20 的移动块自助**给区间——因为每天开仓、持有 20 天，327 个 cohort 只有约 16 个独立观测，交易级重抽会把标准误低估约 √20 ≈ 4.5 倍。

**12 个 cell × 3 个 γ = 36 次配对检验：0 次显著为正，3 次显著为负（`bottom20/SL5%` 的 γ=1 与 γ=5、`bottom20/无出场` 的 γ=5）。**

三个读法：

1. **0 胜 3 负。** 36 次配对检验没有一次显著优于全市场；`SL5%`（偏度 +3.00，全样本最正）在 γ=1 下显著低于全市场 73.2bp（P=0.02），γ=5 下低 89.1bp（P=0.00）；`无出场` 在 γ=5 下低 181.5bp（P=0.01）。所谓「左尾截断、右尾保留」的样板结构，在可下注口径下是**负价值**。
2. **唯一偏向正的是 TP10%**（Δ=+26.9bp，P=0.90），而它是**负偏**（原始偏度 −1.43）——正是报告要避开的形状。正偏是拿均值买来的，而均值才是能下注的东西。
3. **主动偏度对选股方向不稳**：同一个 SL3%+TP30%，在 bottom20 上主动偏度落在零分布 1.00 分位（强于全部 300 次随机），在 top20 上落在 0.00 分位（弱于全部随机）。一个「信号特有的不对称」不该换一组股票就翻到另一端——它更可能是排序方向与 regime 的交互，而不是结构本身的可迁移性质。

第 3 条同时解释了为什么报告的 `[D]`（Sharpe 排序 vs 偏度排序不一致，n=4）没有信息量：4 个组合的排序本来就有一半概率不一致。

## 保留什么

以下成立，不依赖上面任何一条：

- **A 股横截面天然右偏**（均值 3.94 / 中位 2.84），因此「策略偏度为正是没有信息量的」。这条被独立复现，而且比报告意识到的更强——它直接否定掉报告自己 `[E]` 表的读法。
- **系统的手工先验与自动目标方向相反**：25 个内置种子全部只有止损（−5%..−8%）、无一个止盈；挖掘模板写死 `STOP_LOSS=-0.08 / MAX_HOLD_DAYS=30`；`robust_score = 0.6×median + 0.4×worst`；`alpha_search` 门槛走 IC/ICIR/Newey-West t/BH q。逐条核对属实。
- **「稳健分防负偏不追正偏」** 这个观察是对的，`robust_score` 只惩罚最差段。
- **试验数合并校正的必要性**：成立，但**远不是主要约束**。真正的约束是有效样本量——327 个重叠 cohort ≈ 16 个独立观测。480 组结构搜索会把试验数乘 480，而独立观测数不会增加一个。

## 修正后的下一步

原第一步（「25 个种子策略的 payoff 形态扫描，零新代码，一天出结果」）现在不成立：它产出的就是一张会被随机数复制的形状表。

替代的第一步，仍然零新模型、一天量级，但产出可判决：

1. 对 25 个种子策略逐一回测，取**主动口径**（同日同出场规则减全市场等权）逐 cohort 收益序列；
2. 每个策略同时跑**同池随机 20 只**的零分布（现有的 `analysis/asymmetry_control.py` 直接改 `ARMS` 即可）；
3. 只在「主动 CE 对全市场的配对块自助 P(ΔCE>0) ≥ 0.975，且零分布分位 ≥ 0.95」的策略上，才继续做出场结构搜索；
4. 出场结构搜索的搜索空间从 480 缩到「止损 ∈ {3,5,8,10,15,20}% × 无/止盈 = 同倍数 × 非重叠持有期 {10,20,40}」，并且必须**先在随机组合上跑一遍**，把结构性形状作为基准扣掉。

预计后果：能通过第 3 步的策略会很少，甚至为 0。那不是失败——那是第一次有人在这个仓库里把「信号」和「结构」分开量。

## 第二轮修正（2026-11-09）

本文档的 P3 已被第二轮检验限定，完整证据见 [asymmetry-round2.md](asymmetry-round2.md)、[ce_path_audit.py](../analysis/ce_path_audit.py)。改动不是推翻，是降级：

- **上方验收标准第 1 条（`P(ΔCE>0) ≥ 0.975`）必须同时规定块长。** 块自助的覆盖性取决于块长是否 ≥ 该结构的依赖长度：SL5%（全市场平均持有 12.1 日）在 block=5/10/20 的零信号误报率是 1.5%/1.5%/2.5%（名义 2.5%，校准），只有 block=40 升到 4.5%。本文档统一用 block=20，对平均只持有 1.9–2.7 日的快出场结构是**过度保守**——压低的是功效，不是水平。
- **本文档的"0 正 3 负"是功率报告，不是证据。** 同一口径的 MDE(80%) 在无出场下是 305bp/20d、在 SL5% 下是 204bp/20d，而本文档观察到的 |ΔCE| 最大值为 158.6bp、候选正面结构只有 +1.6~+26.9bp。正确表述是"这份样本不可判定"，不是"结构没有价值"。
- **换成真实权益曲线（20 个重叠 cohort、现金按 0 计）后，12 个 cell 的 ΔCE 符号 12/12 与每 cohort 口径一致**，所以本文档的方法方向站得住；但**按每日暴露归一化后有 4 个 cell 翻正**，因此"正偏在可下注口径下是负价值"只在 bottom20/SL5% 一个 cell 上成立，不能推广。
- 三个"显著为负"里只有 `bottom20/SL5%` 经得起检验：跨块长 P=.000/.005/.010/.007，满仓等价口径 P=.04，方向稳定；`bottom20/无出场` 的 −105.4bp 则对块长敏感（P=.013→.043→.095→.138），块长一换就消失。且这两个效应量级都远小于 MDE，**能被判出方向，不能被估准大小**。

仍然完全成立、不受第二轮影响的部分：P1（选股方向颠倒，已独立复核）、P2（正偏是钳位算术，零信号对照可复制）。**P2 是第一轮唯一的硬结论，也是唯一不依赖 CE 口径的结论。**
