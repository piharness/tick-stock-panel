## 0. 估计量与预注册

**估计量换掉了 CE。** 前两轮用 CRRA 确定等价，本轮用**每 cohort 主动收益的均值**：

```
a_h(d) = mean_{picks} fwd_h(d) − mean_{pool,benchmark} fwd_h(d),   fwd_h = close[d+h]/open[d+1] − 1
```

理由：均值的 SE 是 `sd/√n_eff`，CE 的 SE 不是。功率预算必须建立在**能写出 SE 的那个函数**上，否则算出来的 MDE 和实际在测的检验不对应（§6 就是这个错的量级）。

**预注册（先写规则，后跑数）：**

- **R3-A**：若 `max_h t_net(h) < 2`（c=20bp），撤回第二轮 §7.2 的建议。
- **R3-B**：若 `|t(h=5)|/|t(h=20)| < 1.5`，「压短持有期换来功效」判为**被证伪**（该主张要成立至少需要 1.5 倍才值得成本上升）。
- **R3-C**：若某 h 的零信号安慰剂在 |t|≥2 上的拒绝率超过名义值 2 倍，该 h 的行不作为证据。

**c=20bp** 取仓库自己的模型形状（`backend/app/backtest/engine.py`：`fees_pct=0.0002`、`slippage_bps=5.0`）再加上卖出印花税，即 2.5bp/边佣金 + 5bp 卖出印花 + 5bp/边滑点 ≈ 20bp 一次往返。

**Parity（本轮一切的前提）：**

- `fwd_grid(h=20)` 与 `ce_path_audit.ret_grid` **数值逐位相等**（`max|diff| = 0`）。
- 用第二轮自己的网格复算 h=20 的主动收益序列：**n=326、sd=439.7bp**，与 `ce_path_audit_result.json` 的 `power.hold20` 完全一致。
- 顺带修掉一个存在了三轮的**差一天**：`exit_paths` 的 `range(T-hold-1)` 从不计算最后一个合法 cohort（d=T-hold-1）。本轮完整网格是 n=327，第二轮是 326。这一行不影响任何结论，但它是 parity 报告里唯一需要解释的差异。

## 2. 三处攻击：这个 h=1 边缘是不是假的

## 3. 边缘在哪：日内，隔夜，还是都没有

h=1 是「`open[d+1]` 买、`close[d+1]` 卖」。**A 股 T+1 不允许当天卖出**——这一格在任何成本下都不是可执行的交易。合法的最近邻只有：

```
open[d+1] → open[d+2]     一夜 + 一整段日内，可卖
open[d+1] → close[d+2]    h=2，t=1.39~1.56
```

所以把 h=1 拆成「能拿到的」和「拿不到的」：

| arm | 日内 open→close | 隔夜 close→open | 24h open→open |
|---|---:|---:|---:|
| top20（全市场基准） | **+61.6bp (t +4.57)** | **−68.6bp (t −9.57)** | −7.6bp (t −0.48) |
| top20（匹配基准） | +55.9bp (t +4.71) | −56.9bp (t −8.50) | −1.5bp (t −0.11) |
| bottom20（全市场基准） | +14.9bp (t +2.07) | −8.4bp (t −2.29) | +6.0bp (t +0.78) |
| bottom20（匹配基准） | +13.3bp (t +2.11) | −1.9bp (t −0.57) | +11.0bp (t +1.55) |

恒等式校验：`open→open` 与「日内+隔夜」之差只有 **−0.5 / −0.6bp**，拆分是自洽的。

**这就是终局：这个边缘 100% 在日内，隔夜原样退回，而 T+1 恰好强迫你持有退回的那一段。**

合法的 24 小时持有，毛收益 −7.6bp（匹配基准 −1.5bp），再扣 20bp 往返成本，净约 **−22 至 −28bp/次**。

**它是真信号，不是噪声**——用同结构的一期收益做零信号安慰剂（200 次随机 20 只篮子）：

| 段 | 零信号主动均值 | sd(零信号均值) | 零信号 t 的 sd |
|---|---:|---:|---:|
| 日内 | −0.2bp | 3.1bp | 0.95 |
| 隔夜 | +0.0bp | 1.6bp | 1.06 |
| open→open | −0.1bp | 3.7bp | 1.03 |

单期收益没有重叠依赖，所以这里的 iid 随机抽样**就是正确的零假设**，而且它校准完美（均值 0、t 的 sd ≈ 1）。相比之下，用同样的 iid 抽样去校准**重叠 h 期**的估计量是错的：测出来的 `sd(零信号 t)` 恰好等于 `1/√h`（1.00 / 0.71 / 0.56 / 0.45 / 0.32 / 0.23 / 0.16 / 0.12），那是「随机篮子每日重抽 → 相邻 cohort 换了一批股票 → 序列近乎 iid」的产物。真实信号相邻 cohort 几乎是同一个组合，协方差是三角核的，`Var(mean) ≈ Var(a)·h/n`，所以 `sd/√n_eff` 才是对的。**同一个事实从两面看到。**

### 机制：开盘跳空

| arm | 入场日开盘跳空 | t |
|---|---:|---:|
| top20 | **−46.4bp** | −5.51 |
| bottom20 | −23.7bp | −4.53 |

动量赢家系统性**在开盘低开 46bp**，日内把它补回来 62bp，第二天开盘再低开 69bp。这不是「动量延续」，这是**开盘竞价段的一次性错价**——而且是两端都有（bottom20 也低开 24bp、日内补 15bp），只是强度差 4 倍。

数据质量核查：`open` 落在 `[low, high]` 之外的比例是 **0 / 2,000,524**，`open` 恰好等于前收盘的比例 13.5%（A 股零跳空开盘的正常量级）。所以拆分不是坏 `open` 造成的。

**但「是不是坏 open」和「能不能拿到」是两件事。** 一个毛收益 155%/年、在 20 只有流动性的 A 股上、跨 18 个月大牛市、扛过所有稳健性检查的边缘，本身就已经说明问题：约束不在统计里，在开盘集合竞价的成交里。

## 5. 两处方法学修正

### (1) 第二轮 §3 的 MDE 用错了 SE

第二轮的 MDE 是 `2.802 × sd(收益序列)/√n_eff`，但它所评判的决策规则是**每 cohort CE 的配对块自助**。CE 是非线性泛函，它的 SE 不等于收益序列的 `sd/√n_eff`。把它和 `ce_path_audit_result.json` 里真实的自助 SE 放在同一张年化尺子上：

| cell | 均值口径 SE | CE 自助 SE | 比值 | 第二轮 MDE | CE 隐含 MDE |
|---|---:|---:|---:|---:|---:|
| bottom20 / 无出场 | 13.7%/年 | 12.5%/年 | 1.10 | 305bp/20d | **278bp/20d** |
| bottom20 / SL5% | 9.2%/年 | 4.5%/年 | **2.04** | 204bp/20d | **100bp/20d** |

- 「无出场」那一行的 MDE 大致正确（305 vs 278）。
- **「SL5%」那一行高估了 2.04 倍**：正确的 MDE 约 100bp/20d，而观测到的最大效应是 158.6bp。「MDE 比最大的观测效应还大」这句话对无出场成立，**对 SL5% 不成立**。
- 结论方向不变（这份样本仍然判不了 30bp 量级的效应），但第二轮 §3 表里 SL5% 那一行要改。

### (2) 止损族「块长要跟持有期走」的结论，和 R3-C 一致

第二轮 §4 的正确部分：块长 40 对平均持有 12 日的序列过度平滑，误报率升到 4.5%。本轮独立确认了同一机制的另一面——**块太长会让 SE 失真到不可用**（§1 第 4 条：h=40/60 的块自助 SE 反而是 107.2 / 49.9bp，比 `sd/√n_eff` 的 231 / 252bp 还小），所以长 h 的行一律按「不可判定」处理。

## 8. 这份样本下真正可判的问题（替换第二轮 §7）

前两轮问的是「哪种出场结构更好」。本轮证明这个问法在这份数据上没有可估的对象。还能判的只剩两类：

1. **制度/结构参数的估计**（不是结构的假设检验）：把出场参数当情景，估计「给定信号，持有 1 日 / 5 日 / 20 日的条件收益映射」，报出点估计和 CI，不判优劣。这正是仓库 `alpha_search` 的 IC/NW-t 路径在做的事。
2. **执行段的问题**（本轮无意中发现的真问题）：动量赢家开盘低开 46bp、日内补 62bp、隔夜再低开 69bp，两端都有。这个错价属于**开盘集合竞价的流动性供给**问题，属于执行/做市，不属于因子。它可判、可估、可复现，而且和「哪个出场结构更好」完全无关。

第 2 条是本轮唯一值得继续的方向，但它已经出了「因子研究」的边界。
