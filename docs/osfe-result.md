# OS / FE 结果：上方筹码真空度与浮筹枯竭度对 60 日被拉升概率的条件增量

> 预注册见 [`osfe-prereg.md`](osfe-prereg.md)，写于任何条件概率被计算之前。
> 本文件只记录实测数字与裁决，不改口径。产物：`data/_osfe/panel.parquet`、
> `data/_osfe/result.json`、`data/_osfe/test.log`。

## 0. 结论（一句话）

**主判据通过显著性、未通过预注册的 +3pp 门槛，并且在三重证伪下归零**：
双 Q5 状态的全匹配增量 +1.11pp（基准 19.06%，相对 +5.8%），但同设计安慰剂本身
就有 +0.52pp，两个构念各自对既有特征正交化后增量 −0.16pp / +0.68pp（后者 CI 含 0）。
**OS 是"获利盘比例 + 振幅"的重新表述，FE 是"低换手 + 低振幅"的重新表述且方向与民间
模型相反**。效应只存在于 ADV ≤ 0.93 亿的票，Q5 档为负 ⇒ 不可投资，裁决 **REJECT**。

## 1. 样本实数（PIT，含退市，不剔 ST）

| 项 | 实测 |
|---|---|
| 观测格（symbol × 每 5 交易日） | 2,113,490 |
| 股票数 / 日期数 | 5,670 / 517（2016-01-07 ~ 2026-08-21） |
| 退市/缺口股（`src=gap`）行占比 | 3.62%（250 只有观测格） |
| 标签窗口不完整被剔除 | 3.70%（78,303 / 2,113,490）：其中 **83% 是样本末端**（2026 年之后还没有 60 个未来交易日），退市/缺口股只占 5.7%（4,488 格） |
| ST：**剔除**了吗 | 没有。ST 名全程留在池内 |
| ST：PIT 标记覆盖率 | 32.1% 行（1,718 只）；已覆盖行里 3.7% 为 ST 日 |
| 基准率 `pump30` | 19.06%（基础样本）/ 22.06%（全面板） |
| 基准率 `pump20` / `pump50` / `fast30` | 31.42% / 8.02% / 23.90% |

ST 标记只到 32%：baostock `isST` 逐票拉取时被并发限流（8 并发全部 `login_fail`，
3 并发仍失败）。**这不影响主结论**，因为主结论建立在"没有剔除"而非"正确标注"上；
受影响的是 ST 分层结论，本文件不据此下判断。

换手率单位自检：`turnover_rate ≈ volume(手) × 10000 / 流通股`，中位比值 98.7，
p10–p90 = 42.8–100.8 ⇒ 口径正确，缺口股用历史流通股本（`fin_shares`，按公告日 as-of）换算。

筹码内核等价性：向量化路径 vs 生产内核 `levels.py::_profit_split`，59 个真实样本，
`OS/FE/profit` 最大绝对差 **4.4e-16**。构建时是硬闸门，不通过直接中止。

## 2. 主判据（一格，预注册）

`pump30 × OS&FE 双 Q5 × 全匹配`，n = 63,120 事件，状态 run-length 中位 **5 个交易日**。

| 估计量 | Δ (pp) | block 95% CI | n |
|---|---|---|---|
| 对照 1：同日非处理组均值 | **−1.04** | [−2.69, +0.50] | 63,120 |
| 对照 2：同日 × 同行业 | +0.12 | [−1.03, +1.20] | 63,120 |
| **对照 3：+ 同市值/动量/换手/振幅孪生（3 近邻）** | **+1.11** | **[+0.54, +1.69]** | 63,120 |
| 安慰剂（OS&FE 双 Q3，同设计） | +0.52 | [+0.19, +0.89] | 84,098 |

- 置换零分布（同日内打乱标签 200 次）：均值 −0.006pp，sd 0.182，p95 +0.265 ⇒ 实测 +1.11 约 6.1 个 sd。
- MDE（80% power）= 2.802 × 0.293 = **0.82pp** ⇒ 功效足够，这不是"没测出来"。
- **但安慰剂不为零**：同一匹配机器对任何"被选中的组"都给 +0.52pp。扣掉后净增量 ≈ **+0.59pp**，相对基准 3.1%。

注意方向：naive 是**负的**（−1.04），匹配后才转正。含义是"高 OS + 高 FE 的票本身
比同日全市场更不容易被拉升（更小、更冷）"，只有跟自己的孪生比才略高。

## 3. 三重证伪：+1.11pp 不是新信息

### 3.1 竞品对照（单一既有变量即可复现或超越）

| 单变量 Q5/Q1 | Δ (pp) | block 95% CI |
|---|---|---|
| `profit_q5`（获利盘比例最高） | **+1.63** | [+0.87, +2.40] |
| `profit_q1`（获利盘最低） | −1.30 | [−1.79, −0.79] |
| `to20_q1`（换手最低） | −0.71 | [−1.32, +0.02] |
| `amp20_q1`（振幅最低） | **−4.86** | [−5.72, −3.98] |
| `to20_q5`（换手最高） | −0.40 | [−1.13, +0.27] |

一个不需要任何筹码模型的 `profit` 就把 OS 单独的效果（+1.41）压过去了。

### 3.2 正交化（决定性）

| 处理组 | Δ (pp) | block 95% CI | 判读 |
|---|---|---|---|
| OS 单独 Q5 | +1.41 | [+1.04, +1.78] | 表面有效 |
| **OS 残差 Q5**（扣 profit/amp20/to20/mcap/r20/r60/dist_hi250） | **−0.16** | **[−0.52, +0.25]** | **归零** |
| FE 单独 Q5 | −0.42 | [−1.24, +0.27] | 无 |
| `to20_q1` 内 FE Q5 | −0.23 | [−0.98, +0.63] | 无（FE 只是换手） |
| **双残差 Q5（OS⊥ & FE⊥）** | **+0.68** | **[−0.04, +1.57]** | 与安慰剂 +0.52 不可区分 |

嵌套双排序会骗人：`profit_q5 内 OS` 给 +1.46、`amp20_q5 内 OS` 给 +2.90，看着很强；
但在同一层内按 OS 排名仍然在往上挑 profit 水平（两者相关 0.40）。真正扣干净之后是 −0.16。

### 3.3 民间模型被反向证伪

"浮筹枯竭 ⇒ 容易拉升"在数据里方向相反：
- `fe_only` = −0.42pp；`fe_hi × os_lo` = **−0.66pp**（[−1.23, −0.15]，显著为负）
- FE 与 `to20` 相关 −0.45、与 `amp20` 相关 −0.40 ⇒ 高 FE ≈ 冷门 + 低波
- 低波本身就是最强的负向变量（`amp20_q1` −4.86pp）
- LPM（同日 FE）：`os` +0.78pp (t=7.7)、`fe` **−0.92pp (t=−6.8)**、`amp20` +5.88 (t=26.7)

单调衰减，最流动的一档为负 ⇒ 这不是"规模大一点也能做"，是"只有小票有，且小票做不大"。
单票 1% ADV、20 只等权 5% 权重 ⇒ 组合容量 ≈ 0.2 × 0.93 亿 ≈ **1,900 万元**封顶。

## 6. 其他诊断

- **组内（同一只股票）**：+0.77pp（s.e. 0.31，3,657 只）⇒ 不是纯横截面构成差异，但未做日块校正，t≈2.5。
- **条件于已启动（r20 ≥ 8%）**：+1.31pp（[+0.61, +2.05]）；同触发样本里"双低"组 −0.28pp（负控正确）。
- **剔除退市/缺口股**：+1.10pp（[+0.53, +1.71]）vs 全样本 +1.11pp ⇒ **退市股不改变结论**。
  上一轮面板的 100% 生存偏差对这个问题不是约束；但也说明补齐退市并没有把效应放大。
- `fast30`（起点不早于 t 的 20 日窗口涨 30%）：+1.46pp（[+0.94, +2.00]）。
  旧定义 `max_h C[t+h]/C[t+h−20]−1` 给 +4.72pp，**是污染的**——它把信号日之前
  已经在涨的那一段算进了"未来的拉升"。

## 7. 裁决（逐条对照预注册第 9 节）

| 条件 | 要求 | 实测 | 通过 |
|---|---|---|---|
| 全匹配 Δ | ≥ +3.0pp | +1.11 | ✗ |
| block CI 不含 0 | — | [+0.54, +1.69] | ✓ |
| 设计期/外样本同号 | — | +1.68 / +0.70 | ✓ |
| top-3 ADV 档 Δ | ≥ +1.5pp | Q1–Q3 均 ≥1.45 | ✓（勉强） |
| 预注册否决线 | Δ < +1.5pp ⇒ REJECT | +1.11 | **触发** |

⇒ **REJECT**。按预注册，Δ < 1.5pp 直接否决；此处还有三条独立证据支持否决
（安慰剂 +0.52、双残差 CI 含 0、容量只在小票）。

## 8. 局限

1. **ST 标记 32% 覆盖**（限流）。ST 未被剔除是硬事实，但无法给出可靠的分层结论。
2. 行业为**当前**同花顺一级，历史行业不可得 ⇒ 行业匹配含轻微前视。
3. 缺口股 raw 价无分红记录，除权日假跌；方向固定（压低），已用剔除检验确认不影响结论。
4. "拉升"只能从价格路径识别，无法识别意图/资金性质；60 日最大涨幅对停牌复牌跳空敏感。
5. 观测网格每 5 交易日一格，60 日标签重叠 12 格 ⇒ 有效样本远小于 63,120；区间已按 L=12 保守化。
6. 状态 run-length 中位仅 5 个交易日 ⇒ OS&FE 双高是**瞬时状态**，不是可持续的"持仓结构"。
