# 「首阴战法」事前可交易性检验：负期望，反抽是逃命点不是买点

> 一句话结论：**「首阴战法」（强势股首次收阴后次日低吸）整体是负期望，不可交易。**
> 唯一的小赚头是次日开盘的低开反抽（H=1 约 +16bp），但胜率不足 50%、H=3 起显著转负；
> 阴线越深、越放量，后续越差——「首阴」是见顶信号，不是上车点。

---

## 1. 命题

首阴战法是 A 股短线经典说法：连续上涨（连板/大涨）后的第一根阴线是「洗盘」而非「见顶」，
次日低开高走或反弹，是低吸买点。

## 2. 方法

两个信号定义（覆盖主流理解）：
- **A 连板首阴**：T 日收阴，且 T-1 日 `consecutive_limit_ups >= 1`（断板首阴）。
- **B 大涨首阴**：T 日收阴，且 T-1 日前 3 日累计涨幅 >= 20%。

纪律：防前视（T 日收盘可知）、T+1 开盘买入、扣印花税 0.1% + 佣金双向万2.5、
剔除停牌。数据 2005–2026，`open`/`close` 均前复权。

## 3. 结果

### 3.1 连板首阴（n=87,651）

| 持有期 | 净收益 | t | 胜率 |
|---|---|---|---|
| H=1 | +15.7bp | +2.85 | 47.6% |
| H=3 | −44.1bp | −5.46 | 45.0% |
| H=5 | −46.6bp | −4.76 | 45.0% |
| H=10 | −63.1bp | −4.98 | 44.0% |

### 3.2 大涨首阴（n=53,005）

| 持有期 | 净收益 | t | 胜率 |
|---|---|---|---|
| H=1 | +25.8bp | +3.43 | 45.0% |
| H=3 | −37.2bp | −3.62 | 42.9% |
| H=5 | −37.1bp | −2.53 | 43.5% |
| H=10 | −63.0bp | −3.64 | 43.9% |

### 3.3 洗盘 vs 出货（量能分辨，H=3）

| 阴线量能 | 净收益 | t | 胜率 |
|---|---|---|---|
| 缩量（量比<1） | −51.8bp | −3.69 | 47.3% |
| 放量（量比≥2） | −39.3bp | −4.27 | 43.5% |

**「缩量=洗盘」不成立**：缩量阴线同样是负期望，放量阴线甚至没有更差。

### 3.4 阴线幅度（H=3）

| 阴线 | 净收益 | t |
|---|---|---|
| 小阴（>−3%） | −27.4bp | −3.49 |
| 中阴（−7%~−3%） | −65.2bp | −6.74 |
| 大阴（<−7%） | −109.8bp | −6.27 |

**单调恶化**：首阴跌得越狠，后续越差——「首阴大跌是黄金坑」被证伪。

## 4. 结论

1. **首阴战法整体负期望**：H=1 微正（+16~26bp）但胜率 <50%，H=3 起显著转负（t≈−5）。
2. **H=1 的正收益是「低开反抽」**，但反抽是**逃命点**不是买点——不跑就亏。
3. **阴线越深越危险**（大阴 −110bp），「首阴大跌抄底」是亏钱策略。
4. **「缩量=洗盘、放量=出货」的经典口诀在数据里不成立**，两者都是负期望。

## 5. 与前几轮结论的闭环

一路追问下来的每个「民间直觉/战法」都被数据证伪：

| 命题 | 结论 |
|---|---|
| 沉默有 alpha | ❌ 小盘+低流动性投影 |
| 牛市/轮动期沉默补涨 | ❌ 真凶是动量，无 alpha |
| 动量强+沉默可交易 | ❌ 动量无区分度 |
| 沉默爆量上涨 | ⚠️ 曾有效，近 5 年衰减 |
| 首阴战法 | ❌ 负期望，反抽是逃命点 |

**贯穿规律**：这些「战法」的共同点是把**幸存者叙事**（你只记得首阴后反弹成功的案例）
当成了**统计规律**。样本外全量检验后，它们要么是小盘/市场状态的投影，要么是负期望。
