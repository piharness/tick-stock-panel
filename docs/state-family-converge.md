# 状态变量族：收敛裁决（最后一个口子）

> 结构：第 1–5 节是**预注册**（写于任何收益侧数字被计算之前），第 6 节起是**结果**。
> 判据一旦写死就不因结果修改；若改过，会在第 6 节显式标注。

> 判据写于任何收益侧数字被计算之前。上一轮 `state-family-screen.md` 留下唯一开口：
> `dist_lo250` 的 +1.87pp 概率增量，折成钱还剩多少。
> **本文是这条线的最后一步。判完即关，不论正负。**

## 1. 待判对象（单一，不再扩大搜索）

`dist_lo250` Q5 的**正交化残差**（对 `profit/amp20/to20/log_mcap/r20/r60/dist_hi250`
取残差后再取五分位）。这与筛查里通过 G1–G4 的那一格完全一致，不再换构造、换尾。

## 2. 为什么要测收益侧而不是继续测概率

概率增量 +1.87pp 不等于钱。可能的三条路径，只有第一条值钱：

| 情形 | 特征 | 含义 |
|---|---|---|
| A 右尾加厚、左尾不变 | ΔE[ret] > 0，Δ 左尾 ≈ 0 | 真增量 |
| B 两侧同时加厚 | ΔE[ret] ≈ 0，Δ 左尾 < 0 | 只是方差，不是收益 |
| C 右尾加厚但左尾更厚 | ΔE[ret] < 0 | 反向 |

`footprint-20d-significance.md` 已经吃过一次这个亏：尾部 lift 1.3–1.65，但左尾更大。

## 3. 口径（报告必带）

- 收益：`fwd_ret60 = close[t+60]/close[t] − 1`（**同股同 rn，精确 60 个交易日**）
- 可执行：`fwd_ret60_oc = close[t+60]/open[t+1] − 1`（次日开盘进场，避开"信号日收盘抢不到"）
- 左尾：`fwd_min60 = min(close[t+1..t+60])/close[t] − 1`
- 幅度：`fwd_max60`（已有）
- 事件：`pump30`（主）、`pump20`/`pump50`/`fast30`（敏感性）
- 匹配：同日 × 同行业，6 维标准化特征 8 近邻取 3（与筛查同一套图，不重算）
- 区间：日块自助，L=12，500 次

## 4. 裁决规则（先写死）

| 闸门 | 阈值 |
|---|---|
| **E1 钱存在** | `ΔE[fwd_ret60] ≥ +1.0pp` 且 95% CI 不含 0 |
| **E2 可执行** | `ΔE[fwd_ret60_oc] ≥ +0.5pp`（次日开盘进场后仍为正） |
| **E3 左尾不恶化** | `ΔE[fwd_min60] ≥ −1.0pp`（不能靠承担更大回撤换收益） |
| **E4 付得起成本** | 单次 60 日持有的净超额 ≥ +0.5pp（扣 0.5% 双边）⇒ 年化 ≈ 4.2 次周转 |
| **E5 稳健** | 4 个替代构造（`dist_lo120/200/300`、40/80 日期限）里 ≥3 个同号 |
| **E6 容量** | 收益侧在 top-3 ADV 档内仍 ≥ +0.5pp |

六条全过 ⇒ 记为「值得单独做纸面跟踪」；任何一条不过 ⇒ **关闭整条线**。

## 5. 关闭意味着什么

关闭 = 「日频量价 + 换手衰减筹码 → 60 日拉升」这条路线到此结束：
- 34 个候选、68 个检验全部在闸门外或经济上不成立
- 不再接受"换个窗口/换个阈值/换个尾"的重试
- 面板（211 万格、62 列）与匹配流水线保留为资产，供**非拉升类**问题复用

# 结果（判据之后填写）

## 1. 概率侧：增量是真的

| 口径 | Δ | 95% CI |
|---|---|---|
| `pump30`（主） | **+1.88pp** | [+1.35, +2.51] |
| `pump20` | +2.19pp | [+1.51, +2.96] |
| `pump50` | +1.15pp | [+0.73, +1.57] |
| `fast30` | +4.44pp | [+3.82, +5.16] |
| `pump30_40`（40 日） | +1.85pp | [+1.41, +2.33] |
| `pump30_80`（80 日） | +1.77pp | [+1.14, +2.48] |
| `fwd_max60`（最大涨幅） | **+1.30pp** | [+0.85, +1.80] |

n = 391,048 配对事件。概率增量在阈值、期限、构造三个方向都稳（`dist_lo120/200/250`
分别 +1.83 / +2.01 / +1.88）。**这一格不是噪声。**

## 2. 收益侧：增量是负的

| 口径 | 全样本均值 | 1–99% 截尾 | 配对中位数 |
|---|---|---|---|
| `fwd_ret60` | −0.40pp [−0.92, +0.14] | −0.43pp | **−2.20pp** |
| `fwd_ret60_oc`（次日开盘进场） | −0.38pp [−0.91, +0.16] | −0.42pp [−0.93, +0.09] | **−2.19pp** |
| `fwd_min60`（左尾） | **−1.43pp** [−1.68, −1.17] | −1.39pp | −0.80pp |
| `fwd_ret40` | −0.19pp | −0.25pp | −1.61pp |
| `fwd_ret80` | −0.59pp | −0.61pp | −2.75pp |

中位数比均值更负 ⇒ **不是极端值主导**，是典型结果本身更差。

## 3. 钱去哪了：多买的不是涨，是跌

| | P(拉升) | E[ret\|拉升] | E[ret\|未拉升] | E[ret] |
|---|---|---|---|---|
| 处理组 | **21.6%** | +34.2% | **−6.2%** | +2.5% |
| 对照组 | 19.7% | +33.8% | −4.7% | +2.9% |

- 多出的 1.88pp 拉升，每次值 **+34.2%**，与对照组的 +33.8% **没有区别** ——
  买到的不是"更肥的涨"，只是"同样的涨多买 1.9% 的概率"。
- 没拉升的那 78.4% 里，处理组比对照组**差 1.5pp**。
- 算术：`0.0188 × 34.2% ≈ +0.64pp`，`0.784 × (−1.5%) ≈ −1.18pp`，净 ≈ **−0.5pp**，
  与实测 −0.42pp 一致。

这是教科书式的方差交易（预注册里的情形 C）：右尾加厚，左尾更厚，中位数变差。

## 4. 容量与经济

| ADV 分位 | ΔE[ret60_oc]（截尾） |
|---|---|
| Q1 | **+0.85pp** [+0.08, +1.69] |
| Q2 | −0.13pp |
| Q3 | −0.65pp |
| Q4 | −0.85pp |
| Q5 | −1.36pp |
| top-3 合并 | **−1.01pp** [−1.65, −0.34] |

唯一正的一档是最不流动的 Q1（中位 ADV 0.21 亿），扣 0.5% 双边后 ≈ +0.35pp/次，
年化 ≈ +1.5%，且只在那 20% 的票里成立。**top-3 档为负 ⇒ 有规模的账户拿到的是负号。**

分段：2016–2021 −0.47pp，2022–2026 −0.38pp，两段都负。

## 5. 裁决

| 闸门 | 结果 |
|---|---|
| E1 `ΔE[ret60] ≥ +1.0` | **FAIL**（−0.40） |
| E2 `ΔE[ret60_oc] ≥ +0.5` | **FAIL**（−0.38） |
| E3 左尾 `≥ −1.0` | **FAIL**（−1.43） |
| E4 扣成本净 `≥ +0.5` | **FAIL**（−0.92） |
| E5 替代构造 ≥3/4 同号 | **FAIL**（0/3 为正） |
| E6 top-3 ADV `≥ +0.5` | **FAIL**（−1.01） |

⇒ **关闭整条线。** 「日频量价 + 换手衰减筹码 → 60 日拉升」到此结束：
34 个候选、68 个检验，唯一活到收益侧的那个，在收益侧是负的。

## 6. 这条结论最有用的一句话

**"拉升概率"这个因变量本身是陷阱。** 一个状态变量能不能提高 P(拉升)，
和它能不能赚钱，是两个几乎无关的问题——本例里前者稳定 +1.9pp，
后者稳定 −0.4pp，而同组的 E[ret|拉升] 完全相同。
以后任何以「提高 P(某形态)」为卖点的提案，第一句就该问：
**形态发生时的收益率变了吗？没变的形态概率，一分钱不值。**
