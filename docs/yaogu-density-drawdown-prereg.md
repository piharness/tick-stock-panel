## 0. 为什么还值得测

上一轮否掉的是「密度 → 收益方向」。但一个变量可以不含均值信息、只含方差信息——
这正是「热度」类指标最可能的真实角色：它标记的不是「接下来涨还是跌」，而是「接下来会不会急跌」。
如果成立，它的用途不是择时买卖，而是**仓位/风险预算**，那是另一类决策。

## 1. 必须先排除的那个混淆

**高密度 = 刚涨过 = 位置高 = 未来回撤天然更大。** 这只是「涨多了会跌」，
和「妖股炒作退潮」是两件事。同理，高密度月份往往伴随高波动，而波动本身有持续性，
**波动就能预测回撤**——如果密度打不过波动，它什么都不是。

所以两个硬控制：
- `RET12`：过去 250 日市场收益（位置）
- `VOL20`：过去 20 日已实现波动（当期风险状态）

**只有同 `VOL20` 做对照后仍剩增量的密度，才算新信息。**

## 2. 变量

| 变量 | 定义 |
|---|---|
| `HOT_t` | 上月 `frac(rmax60≥150%)` 均值（沿用上一轮，已 point-in-time） |
| `MDD_{t,k}` | 等权全市场指数在未来 k 个交易日内的最大回撤（相对窗口内滚动峰值，含起点） |
| `RET_{t,k}` | 未来 k 个交易日指数收益 |
| `VOL20_t` | 过去 20 日等权指数日收益标准差 ×√252 |
| `RET12_t` | 过去 250 日指数收益 |
| 指数 | 全 A 等权（含退市股），剔除上市前 250 日与北交所 |

k ∈ {21, 63, 126}，主口径 **k = 63**（约 3 个月，与妖股生命周期同量级）。

## 3. 判据（四条全过才算成立）

| # | 判据 |
|---|---|
| P1 | 按 `HOT` 五分位，`MDD_{63}` 的 Q5 − Q1 ≤ **−3.0pp**，且 block bootstrap 95% CI 全为负、NW t ≤ **−2.0** |
| P2 | 控制 `VOL20` 与 `RET12` 后，`HOT` 对 `MDD_{63}` 的系数 t ≤ **−1.5**（方向不变即可） |
| P3 | 安慰剂（block 重排 `HOT`，2000 次）p < **0.05** |
| P4 | **区分性**：`HOT` 对 `RET_{63}` 的系数 \|t\| < **1.5**。若收益也可预测，那它只是又一个择时器，回到上一轮已否掉的那条路 |

判据 P4 是本轮的核心设计——它把「预测风险」和「预测方向」分开。
如果 P1–P3 过而 P4 不过，结论只能是「波动率的另一个代理」，不采纳。

## 4. 稳健性（同时报，不用于挑选）

- k = 21 / 126
- 指数换成中证 1000（000852）
- 目标换成 `P(MDD_63 < −15%)` 的 logit
- 剔除 2015 年
- 用 `frac(lu>0)`（涨停占比）替代 `HOT`

## 5. 已知会假通过的方式

- 2015 年两个窗口（6 月、8 月）能满足任何「高位必有大回撤」的叙事；必须看逐年与剔除后。
- MDD 恒为负且右偏（大多数月份回撤小），均值检验功效低；故同时报中位数与分位。
- 重叠窗口（63 日）使有效样本 ≈ 214/3 ≈ 70，任何 t 值都要按这个尺度读。
